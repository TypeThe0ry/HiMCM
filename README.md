# HiMCM research archive

Research data, source evidence, algorithms, model iterations, and historical paper/figure library live here. The manuscript and Overleaf synchronization remain in [TypeThe0ry/HiMCM](https://github.com/TypeThe0ry/HiMCM).

- `research/2026-a/`: data, scripts, model reports and working figures.
- `library/`: reference papers and figure atlases.
- `docs/migration/overleaf_split_manifest.json`: SHA-256 inventory of the complete local pre-split working tree, including ignored assets.
- `docs/migration/README.before-split.md`: original navigation and reproduction instructions.

The inherited root manuscript files are historical snapshots; edit the live manuscript in HiMCM. V8 files are unfinished research work retained during migration, not a validated model release.

The generated 109,741,560-byte `maps_and_style_guide.zip` remains preserved locally but is excluded from GitHub; its source assets remain in this archive. Git history is preserved without rewriting.
