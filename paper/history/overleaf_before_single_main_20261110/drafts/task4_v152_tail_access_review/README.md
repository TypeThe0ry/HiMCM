# V152：历史通学机会的最低20%效用

Istanbul 2012的已恢复高中生样本表明，保留全部通学时间缺失和成员不确定性后，效用最低20%学生的加权平均效用上界为**0.153352**；整体平均效用下界为**0.315003**。因此，在这个历史条件经验集合的每一种补全中，整体平均与最低20%平均之间的差距至少为**0.161651效用单位**。该下界是由两个边际界推出的保守证书，不宣称联合最紧。

这项结果将“资源或平均值充足是否意味着人人可用”转化为可计算的通学分布问题。它补充现有Shanghai区级学校资源案例：前者衡量恢复样本内个人旅时效用的低端分布，后者是区级同质学校供给情景；两者不合并成城市公平性排名。

## 对象、来源与分母

使用已存档data/task4_v116_ibb/aggregate_results.json的2012高中生年龄14–18汇总，未重新抓取、未新增当前城市数据。来源为官方CKAN经Exa提供的投影表示，尚非原始CSV字节。效用保持q=exp(-t/30)，t单位分钟，权重保持kisi_agirlik。已知成员2463人，其中1811人具有符合既有表单／时钟规则的观测旅时，其权重499950；已知成员中未知旅时权重177066；15位可选成员总权重4487。极值分母为681503。可选成员包括可能属于目标人群的未知年龄记录，与既有成员规则一致。

未知旅时继续取q∈[0,1]，不删掉没有观测旅程的学生。源日期和抽样设计没有支持向2025或今天迁移；当前年份最低20%效用仍取[0,1]。结果是条件经验识别界，不是总体置信区间、年龄偏好、设施实际使用或政策因果效应。

## 定义与界的证明

给定一个可行补全，总学生权重为N。按效用从低到高取αN权重；若边界记录／同效用组超过剩余质量，就按质量分数纳入。以取入质量乘效用之和除以αN，得到Lα。这也等于在线性规划中最小化Σqᵢzᵢ/(αN)，约束0≤zᵢ≤wᵢ、Σzᵢ=αN；分数纳入描述加权分布的尾均值，不把它误称为整个人数。

固定成员时，Lα对每一个效用单调不减。增加一个q=0成员不能提高Lα，增加一个q=1成员不能降低Lα：归一化后的分布分别在一阶随机序上向低端／高端移动。因此全局下界由所有未知效用取0且纳入全部可选质量给出；全局上界由全部未知效用取1且纳入全部可选质量给出。q=0是无限旅时的闭包端点；边界不自动代表有限正旅时实测记录。

20%尾部的上界目标质量为136300.6。所有未知质量取高效用后，最低部分来自观测旅时的长端；40分钟组只取其权重的0.584329053，其余较长旅时组全取。未知质量181553已超过20%目标质量，故下界为0。仅在观测旅时记录内重算最低20%会得0.120389，但其分母与所选尾部都改变，不能冒充保留缺失后的全体估计或用来代替[0,0.153352]。

均值下界保持214675.20461984503/681503=0.315002582。对每个补全，均值≥该下界且L20≤0.153351917，故二者差≥0.161650665。这一证书无需假定两个端点同时实现。它证明该保留集合内有可量化的通学机会差距，不把最低20%当成固定身份群体；不同补全中尾部成员可以不同。
