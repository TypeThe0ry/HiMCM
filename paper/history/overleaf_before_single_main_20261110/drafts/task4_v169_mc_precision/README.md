# V169：现有模拟均值的数值误差支持材料

V154三类冻结模拟导出共37组、每组16城及10,000次抽样，含2,064个基础均值。按每组跨draw为IID的声明模拟设计，对全部选定均值提供同时至少95%的保证：频率半宽2.37921个百分点、平均名次半宽0.356882。

有界响应的Hoeffding双侧界结合union bound，取ε=sqrt(log(2×2064/.05)/(2×10000))；频率支持[0,1]，名次支持[1,16]。并列分摊允许分数credit；城市或情景之间的共享draw不要求独立。固定PRNG序列未作经验独立性认证。数学原始来源为[Hoeffding 1963，定理2，式(2.6)，第16页](https://doi.org/10.1080/01621459.1963.10500830)。

[五个论文数值示例](published_examples.csv)与原CSV逐项相符，包括Zurich三项假设冲击频率100.00%、96.85%、97.72%，以及κ100基线Oslo／Zurich平均名次2.1092／2.2620。显示位数表示样本均值，并不认证对应模拟期望也达到该精度。两城的通用平均名次界重叠，不用于证明期望名次严格先后。

本界限描述声明模拟分布下的MC积分误差；现实城市夺冠概率、预测校准、数据误差和识别区间覆盖率另需相应证据。基线差值未重复计入均值族，未来得分分位数未纳入。原始draw未重放，未增加模型或数据。最终固定权重推荐规则保持，Zurich为保守推荐、16可能／0必要冠军。
