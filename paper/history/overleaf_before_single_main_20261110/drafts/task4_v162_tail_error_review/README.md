## 全域最小值的有限证明

令α=0.2，q_i为49个已观测旅时组的效用，w_i为其质量，z为低端均值阈值。均值与低端均值之差的阈值表达式中，每份效用的贡献为

φ(q,z)=(q−z)+(z−q)₊/α，

即q≥z时为q−z，q<z时为(α⁻¹−1)(z−q)。该项非负。给定z，原未知质量及允许修正的质量均可设q=z，使贡献为0。其余保留质量k_i满足0≤k_i≤w_i、Σk_i=(1−δ)W；以最低单位φ成本填满这个质量就是全局最优的保留方式。可修正“最多”δW不改变解，因为非负成本下允许用满预算。

随着z变化，φ的斜率只在q_i处改变；两个旅时组的单位成本次序只会在z=αq_high+(1−α)q_low处互换。相邻这些断点之间，单位成本次序固定、最优保留质量固定，目标是z的仿射函数。因此全局最小值可在全部1227个断点（含0、1）中取到，不以有限网格近似连续优化。总分母取Nmax=681503：最小非负分子与可选质量无关，纳入全部可选质量使差距最小。

在这一质量松弛中，要使差距恰为0，保留观测必须都处于同一效用值。最大同效用组质量107866，故代数阈值为1−107866/499950=0.784246425；在30分钟组达到。此为固定其余假设时的数学阈值，不是数据真实性、人口推断或可容许实际错误率的认证。
