# V158：共享缺失补全下的通学机会差距

在已恢复的Istanbul 2012高中生14—18岁条件经验集合中，整体通学效用均值与最低20%均值之间的差距至少为 **0.226686**。这个下界在保留集合内可以达到；V152分别计算两个均值端点所得证书为0.161651。联合计算使证书提高0.065035效用单位，数据、权重与效用函数均保持。

## 联合约束带来的判断

均值和低端均值来自同一批学生，必须共享未知旅时和成员选择。将均值压至最低所需的补全，不必同时将低端均值推至最高。直接求二者之差的最小值，就能回答：即使按最能缩小差距的方式解释缺失数据，分布差距是否仍然存在？

本例中答案为是。通学效用仍为q=exp(-t/30)，t以分钟计，权重为kisi_agirlik。已观测质量W=499950，已知成员未知旅时质量177066，可选成员质量4487，最大分母N=681503。纳入全部可选质量、令全部未知旅时为45分钟时，整体均值为0.374445，最低20%均值为0.147759，差为0.226686。这是识别界的可行见证，不是对缺失学生实际旅时的估计。

## 证明：所有补全都满足，且存在达界补全

令Lα为按质量分数取最低αN权重的均值。对任意固定补全，有

Lα = max_{0≤z≤1} [z − Σᵢwᵢ(z−qᵢ)₊/(αN)]。

因此D=均值−Lα等于以下表达式对z的最小值：

[Σᵢwᵢ(qᵢ−z) + α⁻¹Σᵢwᵢ(z−qᵢ)₊] / N。

对任意未知效用q及固定z，其贡献(q−z)+(z−q)₊/α非负，并在q=z时为0。故可将全部未知效用共同设为z，达到所有未知贡献的全局最小值；任意异质赋值也不能更低。剩下观测部分的凸分段线性函数，在观测加权α分位数z达到最小。若观测部分的加权均值和低端均值分别为μ_obs、Lα,obs，则

min D = W(μ_obs−Lα,obs) / (W+U+B)。

其中U为已知成员未知旅时质量，B为实际纳入的可选质量。分子非负且与B无关，故全域最小值取全部可选质量。三个达界z都在(0,1)内，对应有限正旅时；无需用无限旅时闭包来实现本次最小差距。分数边界沿用加权分布定义，并不把权重份额当作整个人数。
