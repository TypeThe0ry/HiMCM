# V53：Istanbul高中项目覆盖修订

同一份官方2025/26统计中，普通高中以外还核实了271015名职业技术高中生和72103名Imam Hatip高中生。排除开放教育后，覆盖学生由408480增至751598。教师存在高中与初中的分配不明，保留区间后，Istanbul决策名次从第10变为第15，6城名次改变；Singapore仍推荐，Phoenix仍第24，可能冠军仍25城。

这是课程覆盖扩大与教师分配假设修订，不表示Istanbul教育状况在现实中下降。普通高中旧点值不能代表所有新增项目，也不能用一个更窄的假定教师区间维持原排名。

## 实际数据与公式

普通高中已核实教师28436名；职业技术教师池20156名，Imam Hatip教师池9871名。后者明确包含附设初中教师；职业初中新项目也设在高中内，但未识别Istanbul的教师分配。全国27所职业初中及556名学生仅为共享校舍线索，不作为Istanbul人数。

$$N=751598,\quad T=28436+V+H,\quad V\in[0,20156],\quad H\in[0,9871],$$
$$u_E=\frac{15T}{N+15T}\in[0.3620458724,0.5384843999].$$

V、H表示相应教师池中可归属高中阶段的教师人数。区间不声称所有教师都教初中；它保留当前未识别的分配。教师仍是人数而非FTE，学生按课程阶段而非实际14—18岁筛选，跨城口径条件继续保留。

评分方法保持不变：

$$S_i(u)=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad
L_i=S_i(l_i),\ U_i=S_i(h_i),$$
$$R_i=\max(0,\max_{k\ne i}U_k-L_i),\qquad i^*=\arg\min_iR_i.$$

八主指标各(1−α)/8、两辅助指标各α/2。已重新运行连续推荐证书：修订后的整个偏好范围仍唯一推荐Singapore。可能冠军定义为U_i≥max其他城市L，推荐稳定不意味着识别唯一实际冠军。
