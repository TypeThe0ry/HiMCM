# V41：补齐真实考试分母与Phoenix教师记录

本轮获得实际学校级观测：Toronto两项高中考试的学生分母，以及Phoenix33所高中报告教师数。Toronto的统计从学校等权中位数推进到真实参测人数加权，并对不完整参测者保留未知结果。主城市排名仍沿用V38：Singapore首选、Phoenix第24、可能冠军25城；新增资料尚不支持完整城市、同定义的指标替换。

## Toronto：从学校中位数到学生分母及缺失结果界

[EQAO原件、字段定义及精确学校匹配](../../data/task4_v41_toronto/README.md)得到：

| 项目 | 数学Grade9 | 首次资格OSSLT |
| --- | ---: | ---: |
| 可报告学校 | 108 | 109 |
| 达标/通过人数Y | 12395 | 16775 |
| 完整参测人数P | 21604 | 19756 |
| 同校资格/登记总数E | 23101 | 21180 |
| 真实参测人数加权率Y/P | 57.3736% | 84.9109% |
| 不完整参测者E−P | 1497 | 1424 |
| 同考试完成条件下的潜在结果界 | [53.6557%,60.1359%] | [79.2021%,85.9254%] |

V40报告的55.5%、84%是有报告学校的等权中位数，不能与上述加权率之差解释为成绩提升。新分母解决了学校规模不同的问题；缺失结果界避免默认未参测者与参测者成绩相同。

若完整参测者结果已知，而其他同资格学生在相同考试完成条件下的潜在二元结果未知，则

$$Q\in\left[\frac YE,\frac{Y+E-P}{E}\right],\qquad 0\le Y\le P\le E.$$

这是条件性的潜在结果界，不是官方实际通过率或因果效应。仍仅涉及相同108／109所报告学校，不覆盖抑制、未匹配学校；不反推受保护的隐藏值。OSSLT另报的28名豁免者未在E实际分解中，未加入分母。逐校检查资格、完整参测与各未参测类别加总一致，详见数据说明。不同国家考试标准不可直接当成同一教育质量量尺。

## Phoenix：同校比较教师口径

[实际ADE教师响应](../../data/task4_v41_phoenix_education/README.md)与34个已知纯9–12学校的NCES ID精确匹配，33校有有效FY2025教师响应。同校40474名学生、1961名报告教师；同一学校集合的CCD教师FTE为1999.17。对应比率为20.63947和20.24540。

不能把这差异直接称为FTE到人数的修正：总人数反而小于FTE，提示报告范围、时间或角色口径尚未统一。跨校重复、未覆盖学校及私校没有被假定为零。新的教师记录是实际补数，但尚未缩小城市教育缺失界。

## 当前城市模型与复核

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad L_i=S(l_i),\quad U_i=S(h_i).$$

$$R_i=\max(0,\max_{k\ne i}U_k-L_i),\quad\mathcal C=\{i:U_i\ge\max_{k\ne i}L_k\}.$$

八主指标各0.1125、两辅助各0.05，推荐最小R。新考试诊断没有偷偷替换原有师资指标。运行`python3 research/2026-a/scripts/task4_intake_v41.py`核验原件并重算[25城结果](ranks.csv)。[摘要](summary.json)记录输入哈希不变及0项城市准入。

Phoenix缓存重算、Toronto聚合重算、独立总量及区间复核均通过。共用准入验证器仅增加显式目录参数，默认V40输出复现且无文件变化。论文未改动。
