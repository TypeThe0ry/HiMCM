# 校级缺失分开保留：London师资分配指标诊断

本轮新增一个不同于全市汇总PTR的学生加权校级指标，并用London411所学校的实际Year12/13人数及407所匹配学校的全学段归属教师数运行。新指标条件界为[0,0.7896637042]；772名未匹配学生占0.727986%，完整保留未知效用[0,1]，没有删去或赋零。

**当前主模型仍为V34的delhi_bounds()。** 该诊断评价的是校级统计归属师资的未知高中分配，不能直接替换全市PTR，也不能解释为每名学生实际接触的教师数。其他城市尚无同定义可用界，在诊断中教育项统一保留[0,1]，没有沿用旧指标点值。

## 公式与实际数据

学校s有高中学生S_s，总人数N；教师统计给出的全学段归属人数为T_s。令H_s表示在同一归属规则下分配给高中阶段的教师等价数量，对匹配学校只规定0≤H_s≤T_s。学生加权指标为

$$E=\sum_s\frac{S_s}{N}\frac{15H_s}{15H_s+S_s}.$$

在独立分配约束下，其界为

$$E\in\left[0,\sum_{s\in M}\frac{S_s}{N}\frac{15T_s}{15T_s+S_s}+\frac{N_{missing}}N\right].$$

匹配学校贡献上界0.7823838445，加上未匹配学生权重0.0072798597，得到0.7896637042。式中未知学校的权重直接进入上界；无需假设它们与已匹配学校相似，也不需要为它们编造教师数。这是矩形约束下的锐界或闭包端点。

定义限定于London公立资助中学的学校sixth-form。T来自November2024，S来自January2025；这是两快照下的历史配置指标，不是同日服务量。DfE主合同归属规则不等于实际跨校授课暴露；若研究对象改为实际任课教师，该包含关系需另证。H的分配并非实测工时或FTE。

同定义对照上界下降1.132168分，25城排名未变、Kendall tau=1，Singapore仍推荐。连续辅助权重[0.05,0.20]也保留25城。旧主模型的London第17不能与此处第15直接解释为补数据改善：重定义指标后，其他城市旧教育信息也被撤回。主模型结果仍未改变。

评分保持

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad L_i=S(l_i),\ U_i=S(h_i),\quad R_i=\max(0,\max_{k\ne i}U_k-L_i).$$

推荐最小R_i，可能冠军满足U_i≥max_{k≠i}L_k。八主指标各0.1125、两辅助各0.05。原主模型教育效用仍15/(15+PTR)，通学仍exp(-t/30)；仅本诊断教育维度使用E。
