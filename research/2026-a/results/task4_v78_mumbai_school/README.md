# V78：用校级教学类别修订Mumbai教育区间

Mumbai教育效用从[0,1]收紧为[0.238460,0.268468]，总分区间宽度减少17.6%。全部25城决策排名保持不变，可能冠军仍有25城。改进来自真实校级人数及教学类别；兼教和零在校生学校的教师分配仍保留未知。

## 数据如何改变模型

[校级原始镜像、schema与提取脚本](../../data/task4_v78_mumbai_school/README.md)给出2024–25年XI–XII学生280,140人、高中专任教学类别教师5,887人、初高中共同教学类别教师967人。31所高中在校生为零的学校仍报告39名高中专任及44名兼教教师。保守地只将有高中学生学校的5,848名专任教师计入资源下界，其他分配留作未知：

$$N=280140,\qquad T=5848+\theta,\quad 0\le\theta\le1006,$$
$$u_E=\frac{15T}{N+15T}\in[0.2384602838,0.2684684685].$$

这是报告学校的教学资源分配界，包含兼职人数，不能解释成FTE或教学效果。年龄14—18岁高中子集为275,499人；这里使用与教师资源口径相配的全部XI–XII在校生。数据按学校所在地统计，不是学生居住地普查。

社会类别与年龄类别独立加总后，逐校四个高中年级／性别单元完全相符；教师九类逐校加总等于教师总人数。两个导出的学校键无交集。校级比值280140/6854≈40.87248，与[官方经济调查公布的高中PTR41](../../data/task4_v78_mumbai/README.md)一致。OpenCity镜像与官方微数据逐字节一致性未验证，故继续保留条件准入标记。此次人数与V77 DSER人数相差1,602，未跨来源拼接分子分母。

另外单独运行了官方整数41的报告精度情景：把41当精确值会让Mumbai与Dhaka互换第22、23名；允许±0.5或±1个比值单位后，排名恢复。误差范围是假设敏感性参数，并非来源提供的置信区间。这些情景未进入当前模型；真实校级计数和教师分配未知共同支持主区间。

## 当前数学公式

8项主指标各取权重$(1-\alpha)/8$，2项辅助指标各取$\alpha/2$。通学效用为$\exp(-t/30)$，单位分钟；教育效用如上。令各指标效用$u_{ij}\in[\ell_{ij},h_{ij}]$，则

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},$$
$$L_i=S_i(\ell_i),\quad U_i=S_i(h_i),\quad R_i=\max(0,\max_{k\ne i}U_k-L_i).$$

按$R_i$由小到大给出决策排名；$U_i\ge\max_{k\ne i}L_k$的城市仍可成为冠军。这是矩形证据范围下的可能性，不是夺冠概率。
