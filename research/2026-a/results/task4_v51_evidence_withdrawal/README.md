# V51：推荐依赖多少证据？

固定权重α=0.10下，逐一撤回115个有信息的城市—指标单元，Singapore都保持唯一最小最大遗憾推荐。穷举6555对单元后，12对会使推荐转为Tokyo，全部涉及Singapore。因此，固定权重下改变推荐至少需要撤回2个单元；允许α∈[0.05,0.20]且选择其中某个偏好时，最少只需1个。

| 假设审计 | α | 推荐 | 可能冠军数 |
| --- | ---: | --- | ---: |
| 当前数据保留 | 0.10 | Singapore | 25 |
| 仅撤回Singapore凶杀率 | 0.10 | Singapore | 25 |
| 仅撤回Singapore凶杀率 | 0.05 | Tokyo | 25 |
| 撤回Singapore凶杀率及PM2.5 | 0.10 | Tokyo | 25 |
| 撤回Singapore教育及通学 | 0.10 | Singapore | 25 |

撤回意味着恢复为[0,1]，不是观测到错误或认定来源不可信。一个单元可能合并多个资料，同一来源也可能支持多个单元，因此单元数量不是独立来源数量。保留原始数据时，V50的整个偏好区间推荐证书仍成立；它不能扩大解释为任意撤回证据后仍然稳定。

## 数学定义

对撤回集合W，将其中每个单元恢复为[0,1]，其余输入不变。评分与遗憾仍为

$$S_i(u;\alpha)=100\frac{\sqrt{\sum_jw_j(\alpha)u_{ij}^2}}{\sqrt{\sum_jw_j(\alpha)u_{ij}^2}+\sqrt{\sum_jw_j(\alpha)(1-u_{ij})^2}},$$
$$L_i^W=S_i(l_i^W),\quad U_i^W=S_i(h_i^W),\quad R_i^W=\max(0,\max_{k\ne i}U_k^W-L_i^W).$$

定义改变推荐所需的最少撤回单元数：

$$b(\alpha)=\min_W\{|W|:\arg\min_iR_i^W(\alpha)\ne\{\mathrm{Singapore}\}\}.$$

穷举给出b(0.10)=2。V50证明无撤回时全区间唯一推荐Singapore；本轮在α=0.05找到单格反例，因此该偏好区间内b的最小值为1。这表示存在某个偏好会切换，不表示所有偏好都会切换。

在单格反例中，Tokyo遗憾35.07431053分，Singapore为35.74061932分。撤回Singapore教育及通学仍不改变固定权重推荐，提示安全等输入的核实也影响推荐可信度；这里没有估计资料错误概率或据此修改观测值。
