# 学校重叠敏感性：排名提升依赖去重假设

固定相同V7输入、相同新增毕业成果权重beta=0.10，允许跨校记录重叠后，Phoenix决策排名由“不重复”情景的22，变为最多重复2次或3次时的23；不限制重复上限时为24，与毕业成果全未知的基准相同。全部情景可能冠军仍25城。当前没有证据指定m=1、2或3，主模型不准入这些条件界。

## 当前数学模型

设学校s的毕业人数下界为g_s，未毕业人数下界为f_s，最多一人出现在m所学校。不同学校的并集人数下界为：

G_L(m)=max(max_s g_s, ceil(sum_s g_s/m))，F_L(m)=max(max_s f_s, ceil(sum_s f_s/m))。

重复次数完全未知时，只保留max_s g_s和max_s f_s。若学校内人数去重、毕业状态与州级同届一致且属于目标地理集合，则利用州级总毕业Gs与未毕业Fs得到条件界：

q_L=G_L/(G_L+F_S)，q_U=G_S/(G_S+F_L)。

这些是保守有效界，不声称已经解决全部联合约束并给出最紧界。跨校毕业状态是否一致、历史空间位置及学校内去重仍须核验，故即使m不限也不是已验证城市观测。

评分：B=(1-beta)sum_j w_j*u_ij²+beta*q_i²；A=(1-beta)sum_j w_j*(1-u_ij)²+beta*(1-q_i)²；S=100sqrt(B)/(sqrt(A)+sqrt(B))。本次固定旧模型辅助总权重alpha=0.10，以隔离重复假设影响；其他城市成果q=[0,1]。

m=1/2/3/不限对应Phoenix条件成果界分别为[0.344135,0.957268]、[0.207828,0.978161]、[0.148865,0.985338]、[0.031347,0.996471]。未改写任何观测值。

## 验证与规则线索

穷举4个合成人在3所学校的4096种成员关系，检查人数下界不超过真实并集；重复上限放宽时，成果区间按预期包含原区间。此验证只支持数学实现，不证明实际学生去重。
