# V96：Warsaw实测师资界改变固定偏好下的补数下界

本轮在当前V96模型上重算12种精确补数情景、300个城市证书。与V92的V91输入相比，固定α=0.1下，全部城市教育＋通学精确揭示后的不可排除城市数下界从8变为9，新增Warsaw。再加PM2.5为6→7；再加生活成本或房价收入比为8→9；再加宽带为7→8。所有变化均为新增Warsaw，没有城市退出这些集合。连续偏好α∈[0.05,0.20]下的各组名单保持，教育＋通学下界仍22。

这些数字是对所有允许的精确补数结果均成立的、逐城市不可排除下界，不一般等于可同时达到的最少冠军数。实际数据的可能冠军仍25城。新证据给Warsaw设定了正的师资下端，也排除了原先允许的极低资源情景；因此改善数据并不保证上述补数下界下降。

令B为将精确测量的单元。对目标城市i，把B内值取其下端，其他未知保留上端，得$a_i$；对对手把B内值取上端，其他未知保留下端，得$b_k$。若

$$D_i(\alpha)=S_i(a_i;\alpha)-\max_{k\ne i}S_k(b_k;\alpha)\ge0,$$

则即使目标经历最不利揭示、对手经历最有利揭示，它仍可能第一。固定偏好检验α=0.1；连续检验允许每城有不同α见证。这些假设揭示值没有进入真实模型。
