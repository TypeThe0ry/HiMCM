# V97：验证补数下界能否被同一组结果达到

[联合可达性分析](../task4_v97_joint_acquisition/README.md)把逐城市下界与同一补数矩阵所得的候选数配对。当前V96的12种补数范围、两类偏好共24个案例均匹配，因而这些案例的模型内最小候选数得到数值认证。以前的逐城市证书本身不能保证这一点。

| 补数范围 | 固定偏好模型内最小数 | 连续偏好模型内最小数 |
| --- | ---: | ---: |
| 全城教育 | 25 | 25 |
| 全城通学 | 24 | 25 |
| 全城教育＋通学 | 9 | 22 |
| 仅Phoenix教育＋通学 | 25 | 25 |

这是独立效用闭区间模型内的最佳情景能力。每个情景对所有城市、整个偏好范围使用同一组揭示值；固定与连续案例可使用不同组值。端点可能只是原变量转换的极限，实际指标也可能相关，因此不能承诺现实补数会产生这些组合。没有将假想值写入城市数据。

令$\mathcal C_A(x)=\bigcup_{\alpha\in A}\mathcal C(x;\alpha)$，$K$为既有证书证明在所有允许补数下仍可能第一的城市集合。对于实际构造的同一情景$x^*$：

$$\max(1,|K|)\le\min_{x\in\mathcal X_B}|\mathcal C_A(x)|\le|\mathcal C_A(x^*)|.$$

只有左右端相等才报告最小值；否则保留未决区间。五项测试包含错误锚点和非空K下仍不能达到逐城市下界的反例。独立审计核对1404个假想单元、600个城市判定、300条下界证书及312个存活城市见证，全部一致。

## 当前数学模型

通学$u_t=\exp(-t/30)$，师资$u_E=15T/(N+15T)$。八项主要指标各占$(1-\alpha)/8$，两项辅助指标各占$\alpha/2$；固定α=0.1，连续范围[0.05,0.20]。

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad L_i=S_i(l_i),\quad U_i=S_i(h_i),$$
$$R_i=\max(0,\max_{k\ne i}U_k-L_i),\qquad \mathcal C(\alpha)=\{i:U_i\ge\max_{k\ne i}L_k\}.$$

按最小$R_i$推荐。本轮改善的是补数能力判断的可证明性，没有宣称预测精度或实际冠军范围改善。未修改Overleaf论文。
