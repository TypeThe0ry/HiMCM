# Conditional Prague bus-node crosswalk

The exact cross-snapshot join yields **942 distinct PID node values** with at least one witness meeting the filters below. This is a candidate for review, not an admitted facility count or score. Of the previously proposed 57 metro node IDs, 47 occur in these 942, so the counts must not be added. One PID node may contain stops with different names; native node IDs are not automatically distinct physical facilities.

For each archived 2026-11-09 Prague-only list link, match the native `node`, exact stop-list/group name and exact passenger-visible line name to the official PID stop data generated at `2026-11-10T04:12:17` (no timezone specified). Require a unique matching group, a matching pole line whose type is exclusively `bus` for that triple, a visible route number in 100–250, `inprague=1`, no disruption or temporary flag on the archived link, and no matched explicit `isNight=true`. Select one deterministic witness per node. The range is a conservative subset of the 100–299 range described by the archived [PID bus page](https://pid.cz/autobusy/); it is not used as the proof of mode, which comes from the pole line type. The 11-10 data cannot by itself establish that mode or service was identical on 11-09.

All 942 selected witnesses have `isNight` **absent**, not false, in the later stop data. This missing field is not interpreted as proof of daytime service. An unflagged list link is not an operating calendar, proof that a timetable is valid on a particular day, or evidence of student access. City membership comes from the archived list and `inprague=1`; all selected current groups also say `municipality=Praha`, but the administrative scope and facility definition still need independent acceptance. The original population is for 2025, so any eventual combination would mix years.

`witness.csv` provides one source locator, timetable URL and current pole/line JSON locators per candidate node. `link_diagnostics.csv` retains all 7,326 archived link occurrences, including mismatches and the first applicable exclusion; it does not merge names or proximity. There are 397 occurrences with no exact current route, 62 with no exact current group, 1,669 whose matched line is non-bus, 2,263 outside the chosen range, and 617 with flags after earlier exclusions; 2,318 pass the conditional filters. These are occurrence counts, not counts of distinct routes, days or places; repeated responses are retained. `receipt.json` records input hashes and counts. Run `python research/2026-a/results/current_prague_bus_crosswalk/extract.py` to reproduce; no new retrieval is needed.
