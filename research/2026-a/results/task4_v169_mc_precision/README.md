## 数学依据与适用条件

[Hoeffding原论文](https://doi.org/10.1080/01621459.1963.10500830)定理2、式(2.6)，印刷第16页，给出独立有界变量样本均值的单侧偏差界。原扫描件从RPI课程页取得，PDF第5页已渲染实看；获取记录及哈希见[source.json](source.json)。本轮将同一定理分别用于变量及其负值，再对所选均值作union bound。

记第j个均值的单次响应在[a_j,b_j]，R_j=b_j−a_j，n=10,000，m=2,064，α=.05。对全部j，取

    ε = sqrt(log(2m/α)/(2n)) = 0.023792100139243058
    P(存在j使 |样本均值_j − 声明模拟分布的期望_j| > R_j ε)
      ≤ 2m exp(−2n ε²) = α.

频率及分数并列credit均在[0,1]，不要求Bernoulli；名次在[1,16]，故范围R=15。最终上下端点裁切到变量支持区间。偏好表的并列平均秩和未来表的competition rank定义不同，但均满足所用支持范围；此证书不把两者视为相同统计量。

每组跨draw的IID是假设模拟设计。城市、情景、证据臂和偏好之间可共享draw，union bound无需不同均值之间独立。固定PRNG种子的既有结果可复现；95%保证针对理想化的重复IID抽样机制，不是对固定序列做出的经验独立性证明。原始draw未重放，完整生成链和原表哈希已保存。

## 对论文中数值的具体解释

[五个已发表数值示例](published_examples.csv)全部与原CSV逐项一致：

| 设定及统计量 | 既有样本均值 | 同时误差界裁切后的期望范围 |
| --- | ---: | ---: |
| Zurich，资源扩张，固定权重／条件证据，推荐频率 | 100.00% | [97.6208%,100%] |
| Zurich，生活压力，同上 | 96.85% | [94.4708%,99.2292%] |
| Zurich，均衡改善，同上 | 97.72% | [95.3408%,100%] |
| Oslo，基线偏好κ=100，平均决策名次 | 2.1092 | [1.7523,2.4661] |
| Zurich，同上 | 2.2620 | [1.9051,2.6189] |

100.00%是样本频率；该证书不将其模拟期望认证到0.01个百分点。两城平均名次的区间重叠，本通用界不认证其模拟期望的严格先后；这不改变既有样本均值的描述。若要在同一事件下推导两个均值的差，可用[L₁−U₂,U₁−L₂]，无需跨均值独立；本轮未生成差值或分位数的新置信区间。

这是声明随机权重／假设冲击下的MC积分误差，保留数据区间、模型和模拟分布为条件。现实城市夺冠概率、未来预测误差、来源测量误差及识别区间的统计覆盖率不在此保证内。通用最坏情形界不表示实际误差达到该宽度，也不证明10,000次抽样不足以支持所有比较。最终推荐规则仍为固定权重的最小最大遗憾；Zurich为保守推荐，16可能／0必要冠军。
