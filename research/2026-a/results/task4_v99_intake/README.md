# V99：定位推荐依赖，并检验Tokyo新年度真实统计

本轮在当前V96上加入逐项来源撤回诊断，取得Tokyo2026官方学校统计速報，并将同口径2025/26数据实际代入模型。真实主模型的250格仍保持；Singapore第1、Tokyo第2、Warsaw第8、Phoenix第16，固定与连续可能冠军均25城。没有人为缩小缺失区间。

## 哪些证据最值得优先核查

[单格诊断](../task4_v99_cell_stress/README.md)表明，117个含信息的单元分别向外放宽不超过0.20时，α∈[0.05,0.20]均保持Singapore推荐。另133格本来就是[0,1]，其扩张不产生变化，应单独计数。

完全撤回某一格为[0,1]后，Singapore凶杀率、PM2.5、生活成本、固定宽带四项可改变推荐。凶杀率或宽带撤回在整个偏好范围推荐Tokyo；PM2.5或成本撤回在部分偏好范围切换，四个边界数值未决叶保留。其余246格逐一撤回后均认证原推荐保持。这里“逐一”不代表多格同时撤回。

相较此前全城或单城统一扩张，本轮进一步定位具体来源依赖，帮助安排核查顺序；它不提供实际错误概率，也不能代替缺失数据采集收益分析。V98的多格扩张0.043反例仍然成立，单格0.20稳定不证明联合误差稳定。

五项针对性测试通过；独立longdouble审计核对1500个点情景、250行失效排名、1040个前缀矩形叶与555个撤回区间叶，验证每个目标的域覆盖、无内部重叠及4个未决叶保留。

## 新数据如何影响排名

[Tokyo2026速報](../../data/task4_v99_tokyo/README.md)普通高中及六年制后期学生合计308362人，普通高中本务教师19580人，六年制全校教师565人的高中部份额继续未知。[同口径2025/26情景重跑](../task4_v99_tokyo_year/README.md)的25城名次完全相同，Kendall τ=1，两者可能冠军均25城。

这组新表尚缺当前主模型所需的教师职能与更广学段细分，因此单独作为较窄资源口径的年份检验，未替换V96。不能将范围变窄所得的窄界称为精度改善。

Phoenix本轮新查的官方MAG FY2025学区成绩服务覆盖3–8年级；学校主表没有高中测试人数或通学时间，新增准入为0。不重复归档早先排除资料。仍需目标高中阶段与实际单程旅时的联合证据，或同范围完整师资分母。

## 当前数学模型

通学效用$u_t=e^{-t/30}$；师资效用$u_E=15T/(N+15T)$。八项主要指标各占$(1-\alpha)/8$，两项辅助指标各占$\alpha/2$；默认α=0.10，连续范围[0.05,0.20]。

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad L_i=S_i(l_i),\quad U_i=S_i(h_i),$$
$$R_i=\max(0,\max_{k\ne i}U_k-L_i),\quad i^*\in\arg\min_iR_i,\quad\mathcal C(\alpha)=\{i:U_i\ge\max_{k\ne i}L_k\}.$$

本轮诊断仅对选定单元q令$l'_q=\max(0,l_q-\epsilon)$、$h'_q=\min(1,h_q+\epsilon)$，其他格保持；ε=1代表信息完全撤回。真实区间与论文均未修改。
