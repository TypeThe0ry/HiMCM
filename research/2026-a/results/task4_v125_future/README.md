## 相同压力设计与两种随机来源

复用V122纯函数，保持以下条件变化：资源扩张为高教、公共交通、泳池密度各增加10%；生活压力为生活成本、房价收入比和通学／通勤时长各增加10%；均衡改善为学生／教师比、PM2.5和通学／通勤时长各降低10%。每一情景都直接从相应证据臂基线变换，沿用原指标锚点。

未来冲击模拟每设置10,000次，`seed=20261108122`。每draw共同强度`C~Uniform[0,1]`，每城独立强度`I_i~Uniform[0,1]`；`δ_i=.05*C+.05*I_i`。相应原始量乘`1+δ_i`或`1-δ_i`，同城受影响指标共享强度。权重在这一模拟中固定。另以`SeedSequence([20261108,100])`抽`Dirichlet(100*参考权重)`，在确定倍率下检查偏好敏感性，不同时抽未来冲击。

这两个分布均由分析者设定，未经城市历史趋势校准。推荐频率描述对应分布下的条件模型敏感性；它不是未来事件概率或真实城市胜率，没有调查产生的AHP权重。全缺失格不随机填补，并在每一个未来draw中仍为`[0,1]`。

V125新增同draw配对的Singapore历史代理撤回MC臂。两个臂的未来冲击数组和权重样本完全相同；额外的`evidence_arm`列区分两臂。旧V122随机模拟只有`conditional`臂，控制复现和跨版本随机结果比较均限定该共同臂。确定性情景原有的两个臂保持不变。

共同conditional臂中，V124与冻结V122的未来MC、仅权重MC的推荐频率和可能冠军频率逐城保持一致，但平均决策名次发生变化：未来MC有10行变化，最大幅度0.2471；仅权重MC有120行变化，最大幅度0.7851。新资料提高部分城市的保守得分，从而改变相对决策次序，未改变这次模拟的首选频率。得分端点变化分位数是压力分布下的端点变化，不是未知真实得分的置信区间。

## 单城推荐切换阈值

保持V122覆盖范围：仅保留历史代理的conditional臂。每个城市依次将学生／教师比、PM2.5和通学／通勤时长共同乘`r∈[0.5,1]`，其余城市保持V124基线。比较焦点城市的最大遗憾与所有其他城市中的最小最大遗憾；交点处为并列，再越过才成为严格推荐。

固定权重的交点仍为Oslo降低5.6850%、Singapore10.3086%、Stockholm28.8745%、Prague31.8491%、Berlin40.3318%；Zurich基线已获严格推荐。等权除基线Zurich外，Oslo在降低37.1232%时达到交点。这些交点与V122相同。Madrid和Tokyo的遗憾差距缩小，但在扫描降低50%以内仍无交点；不能外推为永久无法切换，也不能把切换阈值解释为确定冠军或现实政策因果效果。

通学处理沿用V122矩界：对已给均值，时长倍率r对应Jensen下界`exp(-r*mean/30)`、上界1；对Singapore平均效用界`[L,U]`，`r<1`使用`[L,U**r]`，`r>1`使用`[L**r,U]`。不能把平均效用端点当成个体通学时长来同时做幂变换。矩外包一般不可逆；普通原始量的正逆缩放验证与此分开。

## 复现、控制与输出

在仓库根目录执行：

```bash
.venv-v120/bin/python research/2026-a/scripts/task4_v125_future.py
```

脚本接受同一runner下的V121和V124两个factory。V121控制生成的6张表经相同CSV序列化后，全部列逐项精确等于冻结V122的`ranks`、`utility_bounds`、`thresholds`、`threshold_scan`、`future_mc_city_summary`和`weight_mc_city_summary`；summary情景与阈值也精确复现。旧脚本与旧结果不重写。V124基线的仅权重MC在两臂、两参考权重下均精确匹配V124主结果浓度100的逐城推荐频率、可能冠军频率及平均名次。

独立审计从普通效用端点反解原始量后缩放，不依赖复用函数的有理式；检查确定性全矩阵及每个随机设置的draw0、1、9999。这三个draw分别以逐城市标量距离与`k!=i`循环复算遗憾、排名、可能冠军和并列推荐份额。额外反例检验排除自身高上界及并列各半份额；全部10,000个未来冲击draw均检查全缺失格保持不变。全32组阈值的3,232个扫描点另以独立原始量变换复算，交点两侧检查严格切换。源CSV、准入表、旧脚本／结果与依赖的运行前后SHA保持一致。

兼容输出6张表和`summary.json`；4张`*_v121_comparison.csv`以相同键匹配新旧值，便于区分资料变化与模型变化。`summary.json`记录输入哈希、两格新增界、随机分布、种子、检查范围、全部情景和阈值。脚本只写本结果目录；本轮不改主注册表、CSV、V124准入、旧结果或论文。
