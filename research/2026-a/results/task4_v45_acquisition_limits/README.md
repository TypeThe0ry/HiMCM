# 只补教育与通学，无法缩小当前连续偏好下的冠军集合

**即使把25城的教育与通学全部补成精确值，在当前模型、证据区间和允许权重范围内，25城仍全部可能夺冠。** 这是对所有区间内补数结果成立的数学证书，不是一次模拟或把缺失值填成均值后的结果。补数仍能改变得分和决策名次，但只补这两类数据无法完成缩小冠军集合的目标。

固定默认权重时，全城两项完美补数后至少20城仍无法排除；仅补Phoenix两项则至少25城。当前实际输入未改，重跑仍为Singapore第1、Melbourne第4、Cape Town第5、Phoenix第24，可能冠军25城。

## 为什么这次能证明，而不必猜未来数据

设M为准备采集的城市—指标单元。假设新测量沿用相同人群、年份、地域和指标定义，结果x位于已有区间[l,h]内；完美测量将这些单元缩为点，其余单元保持原区间。对要检查的城市i，取一次最不利补全：i的所有待测值取下端点，所有对手的待测值取上端点。

定义a_i为城市i原有上界向量，但待测单元改取下界；b_k为对手k原有下界向量，但待测单元改取上界。评分对每一效用单调，因此任何允许补全x都满足：

    U_i(x;α) ≥ S(a_i;α),   L_k(x;α) ≤ S(b_k;α).

若S(a_i;α)≥max_{k≠i}S(b_k;α)，即便在这个最不利补全下i仍不能被排除，其他补全同样不能排除它。反之，这个端点补全本身就是能够排除它的见证。因最不利补全不依赖α，对连续偏好α∈[0.05,0.20]，只需检验是否存在α满足全部比较不等式。

这等价于针对单一城市判断“所有允许补数后，仍存在允许偏好使它可能夺冠”。比较延用已有二次多项式根分区算法，不以离散权重网格代替连续判别。各城市最不利补全可能互相冲突，所以必然保留城市数只是联合冠军数量的下界，不能称为可实现的最少数目。

## 结果与可核验余量

| 完美补数范围 | 固定α=0.10必然保留城市数 | 连续α∈[0.05,0.20]必然保留城市数 |
| --- | ---: | ---: |
| 全25城教育 | 25 | 25 |
| 全25城通学 | 24 | 25 |
| 全25城教育和通学 | 20 | 25 |
| 仅Phoenix教育和通学 | 25 | 25 |

更直接的共同权重证书是α=0.20：全城两项完美补数的最不利补全下，25城都满足冠军可能条件；最小比较余量为Istanbul的+0.049194分，明显高于数值容差。固定α=0.10下，Phoenix相应余量为+3.530619分。未获得固定权重必然保留证书的5城是Nairobi、Lagos、Istanbul、Mumbai和Dhaka；不意味着存在一组观测能同时排除这5城。

这改变了补数方向：在继续核实高中阶段教育和真实通学的同时，需要补其他尚未识别的维度。对全城教育、通学再加一类完美数据的诊断，连续偏好下仍必然保留的城市数分别为：凶杀风险11、公共交通密度9、公共泳池密度6；研究型高教密度没有单城必然保留证书。后者不代表已经能确定唯一冠军，也不是对这些来源可获取性或调查收益的预测。新增数据的实际数值仍决定结果。

本证书依赖现有矩形区间、归一化和权重范围，不涵盖改变指标、发现跨指标约束、新证据超出现有范围或换测量人群。没有为减少冠军数调权重，也没有把情景值写进真实数据。

## 当前模型公式

八个主指标权重各(1−α)/8，两个辅助各α/2，默认α=0.10。通学效用为exp(−t/30)，教育资源效用为15/(15+PTR)。

    S_i(u;α)=100 sqrt(Σ_j w_j(α)u_ij²) /
             [sqrt(Σ_j w_j(α)u_ij²)+sqrt(Σ_j w_j(α)(1−u_ij)²)]
    L_i=S_i(l_i), U_i=S_i(h_i)
    R_i=max(0,max_{k≠i}U_k−L_i)
    C={i: U_i≥max_{k≠i}L_k}

按R_i升序给出决策排名。最新实际数据入口仍是V44 `melbourne_bounds()`；V45新增采集能力边界，未修改城市输入。当前人群与跨城市限制见[模型定义](../../design/task4_current_model.md)。
