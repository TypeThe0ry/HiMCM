- [Madrid原件与提取](../../data/task4_v124_madrid/README.md)：CRTM官方2026-05-29地铁登记记录，省28／市079筛选，240条具名线路记录按网络站代码合并为191个市内站群。51条市外记录和2条无名称无线记录排除，两个多名称联通站群各合一次。保留原人口3,527,924（2025），交通效用由[0,1]成为[0.09770010874891687,1]。这是库存子集，非实时营业或全模式普查。
- [Tokyo原件与提取](../../data/task4_v124_transport/README.md)：练马区官网五个不同地址室内公共游泳设施；当前闭馆的平和台排除，三原台2027年计划闭馆与当前状态区分。保留原人口9,983,365（2026），泳池效用[0.04769460950753885,1]。其余区／提供方未知，上界1保留。
- [教育拒收](../../data/task4_v124_education/README.md)：11条路线没有取得城市、学段、提供方和FTE匹配的分母。Zurich州域公共资助FTE、BFS公共学校人头、Dublin不公开的学校层FTE、Helsinki成人学时均未强行准入。旅行与Tokyo交通也无新增准入；失败不生成数值。

所有准入源的实际HTTP原件、SHA256及提取脚本均归档。Tokyo较大体育设施PDF的提供方文字转换存在错序且原件403，完全未进入计数。准入清单为`design/task4_user_v124_admissions.json`，当前入口为`task4_user_v124_revision.revised_bounds()`。
