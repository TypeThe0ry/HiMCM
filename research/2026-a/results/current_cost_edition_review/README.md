# Source-edition sensitivity for the sixteen-city cost inputs

The complete two-indicator check covers 32 original CLI/PIR points and all 96 corresponding values in three archived Numbeo editions. Twenty-eight original points match at least one checked edition. The four without an exact match are Zurich CLI 117.8, Paris CLI 73.3, Oslo CLI 92.9 and London PIR 11.8. Absence of a match in these snapshots does not prove an input error or identify another extraction date. The original CSV is retained.

Each alternative selects both cost and property indices for every named city from one common edition, holding the other 128 utility ranges, weights, anchors and fixed ideal points constant. The annual 2026 alternative actually changes 31 points, Mid-Year 32 and archived Current 4. This is a source-edition comparison against retained V203, not a calendar-year or time-trend experiment.

Stable conservative choices do not mean that every rank is stable. All alternatives continue to admit sixteen possible champions and no necessary champion.

Compared with retained V203, mean score-interval width changes by -0.006880/-0.009776 fixed/equal score points for annual 2026, -0.042234/-0.047016 for Mid-Year and +0.000480/+0.000468 for Current. These are nonlinear responses to changed point inputs, not improved uncertainty estimates. Actual primary admissions and primary width reduction are zero.

Current means the copy whose archive access date is recorded as 7 November 2026, not a live table. Annual2026 identifies a publisher edition, not a full-calendar-year measurement.
