# 实测高中数据改变补数门槛：Delhi从4项降至3项

基于当前V34已准入数据重算25城补数诊断；V35被否决的London教师上界仍不使用。Delhi最少额外指标数从V31的4项降至3项，共7组最少方案；固定权重下为2项。连续辅助权重[0.05,0.20]的检验要求更强，因此本报告优先列3项结果。

这个变化来自此前已补入的真实高中师资数据，本轮没有新增城市评分输入。它表示在足够不利的测量结果下，排除Delhi冠军可能所需的最少额外项数降低，不表示采集3项必然排除Delhi。

指标仍采用原定定义和权重。方案按城市本身的未知指标逐项测量，检验极限为这些指标准确落在当前效用下界；没有把假想结果写回实际输入。实际采集若只得到宽区间或较有利数值，可能仍不能排除。

Phoenix仍需至少4项、25组方案，原97.145%证据强度门槛保持；只补教育和通学两项仍不足。所有城市实际排名逐项复现V34：Singapore推荐、Delhi第14、Phoenix第24、可能冠军25城。

## 公式与验证

$$u_{education}=15/(15+PTR),\quad u_{travel}=e^{-t/30},\quad S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}}.$$

$$L_i=S(l_i),\quad U_i=S(h_i),\quad R_i=\max(0,\max_{k\ne i}U_k-L_i),\quad \mathcal C=\{i:U_i\ge\max_{k\ne i}L_k\}.$$

八主指标各0.1125、两辅助各0.05。对补数集合B，将该城市选中指标的假想上界置为对应下界，寻找使其在整个偏好范围内都不再可能夺冠的最小|B|；这是假想结果可行性，不是预测采集回报。

将原V31运行器改为接受显式基准、结果目录及比较版本，复用同一算法，避免后续诊断误用旧模型。验证默认参数重建的V31所有CSV逐字节一致、JSON值一致；新运行的25城固定权重与退化连续区间结果一致，输入数组未变化，并逐项复现V34排名、得分和遗憾。
