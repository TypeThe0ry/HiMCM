# V94：Phoenix 实测空气界如何改变补数要求

当前 V91 输入下，Phoenix 在指定低端补数情景中仍至少需要5项指标才能排除第一可能。与 V80 的 V79 输入相比，最佳5项、6项组合允许的残余比例增加，7项全选的比例却减少。实际排名仍第16、可能冠军仍25城；这里没有新增实测值或修改原有缺失区间。

| 选中指标数 | V80：V79 输入阈值ρ | V94：V91 输入阈值ρ |
| --- | ---: | ---: |
| 0—4 | 即使ρ=0也不能排除 | 即使ρ=0也不能排除 |
| 5 | 0.0622021 | 0.1599210 |
| 6 | 0.2590797 | 0.3188000 |
| 7 | 0.3854010 | 0.3390596 |

本轮重新计算全部128种指标组合。假设选中指标的 Phoenix 区间变为 `[l_j, l_j+ρ(h_j−l_j)]`，其余城市和指标保持当前值。ρ同时规定测量结果靠近现有下端的位置以及剩余宽度，不是单独的测量精度或补数成功概率。取得任意5项数据不保证排除 Phoenix。

## 实测信息的两种作用

Phoenix PM2.5效用已由 `[0,1]` 变为 `[a,b]=[0.5644209361,0.6805357740]`。这是 V91 市内已观测合格监测网络的条件界，仍非居民或高中生暴露界。其他249格在本次两个输入版本之间不变。

- **组合不选择空气指标时**，它仍使用现有上端；实测上限从1降至b，降低 Phoenix 的乐观分数。64个此类组合中，低端精确结果可排除的组合由3增至7，原有3个可比较阈值全部上升。
- **组合选择空气指标时**，旧情景把该效用上端设为ρ，新情景设为 `a+ρ(b−a)`。两者在 `ρ*=a/(1−b+a)=0.6385682` 相交。在本轮相关阈值附近，新上端更高：实测证据排除了原先假想的极差空气结果。64个此类组合中，可排除组合由16减至7，仍可排除的7个共同组合阈值全部下降。

因此，最少项数不变，最佳组合和阈值会改变。实测证据既限制过度乐观，也限制过度悲观的补数假设。把全部阈值变化称为“精度改善”会混淆结果位置和残余宽度。完整一一对应对照见 [128组合比较](comparison_v80.csv)。

## 模型与数值验证

当前评分为

\[
S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}}.
\]

八项主要指标各占 `(1−α)/8`，两项辅助指标各占 `α/2`，连续偏好α∈[0.05,0.20]。令 `L_i=S_i(l_i)`、`U_i=S_i(h_i)`，只要存在一个允许α满足 `U_Phoenix ≥ max(k≠Phoenix)L_k`，Phoenix 就仍可能第一。两城评分比较化为α的二次多项式，按全部实根划分偏好区间。

每个阈值运行40次二分，保存“排除／仍可能”的两端，算法括区间宽度不超过2^-40。此宽度是给定1e−12多项式容差下的数值分辨率，不表示经验精度或形式化证明。独立 `audit.py` 从保存的250格出发，以长双精度直接构造二次系数并使用解析根，核对128个精确结果分类及28个临界两端，全部一致，没有端点算术歧义；另检查两端各外移2e−9后的分类。4项相关测试通过。
