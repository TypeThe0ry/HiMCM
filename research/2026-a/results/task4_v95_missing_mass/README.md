# V95：让未知测试人数进入整体成绩描述

Phoenix 已有108所学校的319条学科记录。ELA、数学、科学分别有12、13、12条测试人数未知，其中2、2、3条仍公布成绩百分比。此前已知人数子集的描述区间适用于该子集；缺失学校占比不能替代缺失测试人数占比。

令已知测试人数子集的百分比描述界为[a,b]，未知人数记录占全部测试记录的比例为γ，其成绩描述界为[c,d]。则全部覆盖记录的区间为

$$[(1-\gamma)a+\gamma c,\ (1-\gamma)b+\gamma d].$$

已公布百分比的未知人数记录保留原值；其余记录保留[0,100]。本数据三科均存在未知人数且未知成绩的记录，因此未知人数部分的可行范围仍为[c,d]=[0,100]。γ缺少可验证的上限时，整体描述的保守闭包为[0,100]，不能将已知人数子集的窄界称为108校整体成绩界。

| 学科 | 已知人数子集区间 | 假设γ=10%时的整体描述区间 |
| --- | --- | --- |
| ELA | 35.842–44.426 | 32.258–49.983 |
| 数学 | 26.989–39.468 | 24.290–45.522 |
| 科学 | 16.009–35.081 | 14.408–41.573 |

第二列与V94相同；第三列仅为指定未知人数比例的情景，不是观测到的缺失比例、城市通过率或置信区间。不能把12/107、13/108或12/104这样的学校记录比例代入γ。原始百分比的舍入规则仍未知，结果是对公布百分比的加权描述，不重建实际通过人数。

`analyze.py`校验三个输入文件哈希、319条唯一学校—学科记录和FY2025/11年级筛选，计算18个情景。另以每校权重为变量建立36个线性规划，独立核对区间端点，最大差异小于4e−16。未知记录权重采用非负连续放松，不凭空规定人数；γ=0或1可以是闭包极限，不声称这些缺失记录实际为零人或无限多人。

没有将此描述量替换进师资指标，全部主模型区间保持。下一项有用数据是匹配同一考试、同一筛选范围的测试人数或其可信界，而不是其他统计日的注册学生人数。

```sh
python3 research/2026-a/results/task4_v95_missing_mass/analyze.py
```
