# V103：共享补数下的最小可能冠军集合

本分析使用V102真实输入，假设全城安全、教育、通学三指标被精确测得。原先仅用必存城市构造的算法给出[3,5]，没有证明最小值。新增集合枚举后，数值认证最小值为4：Phoenix、Copenhagen、Singapore、Jakarta。实际模型仍25城可能冠军；这里是最有利假想补数极限。

## 为什么可从连续数值优化改为集合枚举

令K容纳补数后整个偏好范围内的全部可能冠军。若某共享揭示值z能排除K外城市，则每个α的最大下界一定由K内城市取得；否则取得最大下界的K外城市本身就是可能冠军。故必须有

$$U_i(z,\alpha)<\max_{k\in K}L_k(z,\alpha),\quad i\notin K,\quad \forall\alpha.$$

评分逐指标单调。在所测单元格中令K内城市取原上端点、K外取原下端点，右侧不降、左侧不升。所以存在任意可行的共享补数值，当且仅当这个端点构造可行。未测单元格保留原区间；全部α共用同一构造，不允许随偏好更换数据。

已有必存证书给出M={Phoenix,Singapore,Jakarta}。枚举含M的K：大小3仅1个，大小4共22个。唯一3城集合存在严格反例；22个4城集合中只有加入Copenhagen的集合通过。故模型内最少4城，不是“找到4城就宣称最优”。成功集合排除其余21城，连续比较按全部二次比较根分割，包含端点。近零反例留为未决，不用认证失败替代不可能证明。

## 数据与算法各改善了什么

V96旧输入时该情景已证明最少5城；V102新增Copenhagen高教资源下界后，简单构造给出3—5。新枚举找到并验证4城完成，同时排除3城完成：证据变化使最优值5→4，算法变化消除了新输入下的证明缺口。

这依赖独立闭区间、单调评分和所选单元格可精确揭示假设。端点可能是效用极限，不保证现实能同时达到；数值证书也不是定向舍入的形式化证明。不能据此宣称已经识别真实四强。
