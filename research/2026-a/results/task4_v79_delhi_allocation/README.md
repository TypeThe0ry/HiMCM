# V79：统一Delhi与Mumbai的高中教师分配规则

Delhi决策排名由13变14，Santiago由14变13，其他排名不变；固定和连续偏好下仍有25城可能第一。修订解决了同一UDISE来源被不同处理的问题：此前Delhi将兼教教师全部计入，Mumbai则保留其高中资源分配未知。

## 真实数据及模型含义

[Delhi校级数据与逐校核验](../../data/task4_v79_delhi/README.md)覆盖5,556所报告学校。XI–XII学生603,437人，高中专任类别教师26,766人、兼教初高中教师3,420人；这些总量均与V34保存的官方报告一致。校级新信息是18所高中在校生为零的学校仍记录105名专任和14名兼教教师。年龄与社会类别两种汇总逐校、逐年级、逐性别吻合。

采用与Mumbai一致的名义教学资源分配约定。令D为专任类别人数、M为兼教人数、Z为高中零在校生学校的专任人数：

$$T=D-Z+\theta,\qquad 0\le\theta\le M+Z.$$

Delhi对应D=26766、M=3420、Z=105，因此

$$T\in[26661,30186],\qquad u_E=\frac{15T}{603437+15T}\in[0.3985789633,0.4286862578].$$

专任教师按一个名义资源单位计，兼教及零在校生学校岗位的目标群体归属留作未知。这是明确的分配模型，不是FTE、实际授课时数或抽样置信区间。若指标仅定义为“参与高中教学的教师人数”，旧30186人仍是正确的报告人数；改变的是评价模型采用的资源分配定义。此次统一的是两地同源UDISE规则，未宣称各国教师统计已完全同口径。

采用全部XI–XII在校生，与教师阶段对应；年龄14—18岁子集597,603人不单独配上全部教师。地理为Delhi NCT，按学校所在地统计。OpenCity镜像与官方文件字节一致性未核验，保留条件准入。

## 当前核心公式

8项主指标各权重$(1-\alpha)/8$，2项辅助指标各权重$\alpha/2$，默认$\alpha=0.10$。通学效用$u_t=\exp(-t/30)$，分钟为单位；教育效用如上。其余效用区间及来源保持。

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},$$
$$L_i=S_i(\ell_i),\quad U_i=S_i(h_i),\quad R_i=\max(0,\max_{k\ne i}U_k-L_i).$$

按最坏遗憾$R_i$升序排列；满足$U_i\ge\max_{k\ne i}L_k$的城市仍为可能冠军。这是指定证据范围下的可能性，不是概率。
