# 苏黎世师生比口径补充结果

州学校所在地数据提供 2024/25 学年 63,925 名 Sek II 学生的宽范围材料，其中 Mittelschule 14,618、Berufsfachschule 46,872；完整分类及公私立承办划分见 `extraction.json`。它为未来上界提供有来源的候选数，而完整目标嵌套和城市教学 FTE 下界尚未证实，因此无新 PTR、效用或主要模型准入。州公立义务教育教师就业分析包含市镇维度，但未公布目标高中分母。本次结论不否定 BFS T10 已有覆盖证据。

`verification.json` 保存原件及相关历史依据的 SHA-256、下载回执完整性和离线提取的复核结果；失败的 404 响应只记录检索过程。此为有边界的两条官方路线核查，非穷尽检索或未公开数据不存在的证明。
