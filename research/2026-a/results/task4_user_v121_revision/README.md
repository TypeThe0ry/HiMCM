## 数学规则未改动

收益效用`u=x/(a+x)`，成本效用`u=a/(a+x)`；锚点见`task4_v5_model.SPEC`。固定权重为8个主指标各0.1125、交通与泳池各0.05；等权对照各0.1。

`Dminus=sqrt(sum(w*u²)); Dplus=sqrt(sum(w*(1-u)²)); S=100*Dminus/(Dminus+Dplus)`。权重在平方距离只乘一次。`L=S(lower), U=S(upper)`；`R_i=max(0,max_{k≠i}U_k-L_i)`，保守推荐最小R；可能冠军满足`U_i≥max_{k≠i}L_k`。闭区间平局保留可能，推荐不等于确定冠军。

只有通勤均值时保留Jensen界`[exp(-mean/30),1]`；分箱按端点积分、不取中点、不封顶开放尾部；全缺失[0,1]。本轮未改任何通学界。区间为条件数据界而非抽样置信区间。
