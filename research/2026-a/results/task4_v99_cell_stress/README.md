# V99：逐项撤回来源，定位推荐依赖

当前V96下，任意一个城市—指标的效用区间单独向外放宽不超过0.20，Singapore的最小最大遗憾推荐在整个α∈[0.05,0.20]仍成立。250个单元的1040个矩形证书全部通过，其中117格含信息、133格原本就是[0,1]，后者放宽不产生变化。

当一格的全部信息被撤回为[0,1]时，结果有实质区别：Singapore的凶杀率或固定宽带来源单独撤回后，Tokyo在整个偏好范围获得推荐；PM2.5或生活成本来源撤回后，Tokyo在较低α范围获得推荐，较高α仍推荐Singapore。其余246格撤回均认证Singapore保持推荐。PM2.5与成本的切换附近共4个数值未决叶被保留。

| Singapore单独撤回指标 | α=0.10推荐 | 原推荐比新推荐多出的最大遗憾（分） |
| --- | --- | ---: |

这是来源核查优先级：推荐对哪些现有证据依赖较强。它不同于“补哪个缺失值能缩小冠军集合”的问题，也不证明这些来源实际有错。V98已显示Singapore多格同时放宽0.043即可出现反例；本轮单格0.20稳定不能替代联合误差检验。

## 检验定义与复算

对目标格q=(i,j)，仅令该格

$$l'_q=\max(0,l_q-\epsilon),\qquad h'_q=\min(1,h_q+\epsilon),$$

其他249格不变。ε=1等于完全撤回该格信息。主评分、权重与最小最大遗憾规则不变。每个目标分别验证矩形[0,0.20]×[0.05,0.20]，利用端点分数单调性计算遗憾包络；只有所有矩形叶均严格支持原推荐才报告整域稳定。单独在ε=1验证连续α，未认证ε∈(0.20,1)的行为，不报告首次失效阈值。

数值证书使用1e−9分数余量、1e−8严格差值、最大深度12。两处撤回切换的未决α范围约为PM2.5 [0.113794,0.113867]、生活成本[0.114673,0.114746]；边界以CSV完整精度为准。这些是数值未决区间，不是置信区间。
