# V22：可能冠军需要多少有利假设

本轮没有新增可纳入的 Phoenix 高中生通学观测。四种 V21 情景的 25 城排名、得分区间与可能冠军集合保持不变，每种仍有 25 个可能冠军。新增诊断解释这些候选者需要多大的有利假设，而不修改数据区间。

## 实际结果

Phoenix 在十指标情景中的共同插值门槛为 0.464457；加入权重为 0.1 的毕业结局指标后为 0.415997。两个人群口径的结果相同，见 [thresholds.csv](thresholds.csv)。这是在竞争城市取各自下界、辅助指标权重可在 0.05—0.20 中选择时的结果。0.464457 表示 Phoenix 每个不确定指标从下界向上界共同移动约 46.45% 的区间宽度；不表示 46.45% 的数据错误、46.45% 的学生或夺冠概率。

新增毕业指标也改变了其他城市的下界，两个门槛不能解释为 Phoenix 实测表现改善。当前诊断的作用是公开“可能冠军”的成立条件；真实数据覆盖和可能冠军数量本轮均没有改善。

## 数学定义

对城市 i 的效用区间 [l_i,h_i]，设 u_i(t)=l_i+t(h_i-l_i)，0≤t≤1。固定其他城市处于下界，求

`t_i*=inf{t: 存在 alpha∈[0.05,0.20]，S(u_i(t);alpha,beta)≥max_(k≠i) S(l_k;alpha,beta)}`。

十指标距离为 A=Σw_j(1-u_j)²、B=Σw_j u_j²；八个主指标各重 (1-alpha)/8，两个辅助指标各重 alpha/2。加入毕业结局 q 后，A_beta=(1-beta)A+beta(1-q)²，B_beta=(1-beta)B+beta q²，S=100√B_beta/(√A_beta+√B_beta)。十指标 beta=0；十一指标 beta=0.1。

效用逐项单调使可行性随 t 单调。脚本对 t 二分 45 次；每一步通过比较二次多项式 B_i A_k−B_k A_i 的所有实根划分 alpha 区间，检查共同可行区域。门槛计算采用零多项式松弛，避免固定正容差在理想端点造成约 1e-6 的门槛偏差。计算仍受浮点与求根误差影响，二分次数不构成数学真值的误差证明；直接得分残差保留在 CSV 中。

该情景采用独立矩形不确定集合，允许各指标同时朝有利端变化。尚未施加实证跨指标依赖，也未给端点分配概率。t=0 表示在某个允许权重下，本城市下界足以达到其他城市下界；不表示确定冠军。若 t=1 仍不可行，脚本返回不可行而不填假门槛。
