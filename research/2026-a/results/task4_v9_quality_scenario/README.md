# 教育成果覆盖界：条件情景，不准入主模型

州级与学校队列可比且学校记录互斥时，记州毕业总数Gs、未毕业总数Fs，已观测学校毕业界[gL,gU]、总记录N，则目标城市毕业率条件界为：

qL=gL/(gL+Fs)，qU=Gs/(Gs+N-gU)。

本次数字给出[0.344135,0.957268]。数学依据是把所有州未毕业者纳入目标集合得到最小率，把所有州毕业者纳入且只保留已知最少未毕业者得到最大率；前提包括观察集确实属于州同届去重总体。该前提现在未获证明：旧技术手册明确允许部分双重在读者在两校记G，且实体详情返回FY2026而非请求FY2025。因此这是未获验证假设下的诊断，不是可准入的Phoenix全市成果界。

B=(1-beta)sum(w*u²)+beta*q²；A=(1-beta)sum(w*(1-u)²)+beta*(1-q)²；S=100sqrt(B)/(sqrt(A)+sqrt(B))。
