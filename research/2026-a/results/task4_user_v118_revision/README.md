## 六个原缺失格

- **Oslo交通站点**：官方市政GIS与市界核验89个市内命名地铁站，186条平台记录按站名合并。仅计地铁子集，避免全模式别名重复；实际快照为2026年7月，沿用附件人口727797。未知其他模式与总量保留上界1。
- **Zurich泳池**：官方现行目录7个公共室内泳池场馆；2026目录使用附件2025人口440935，年份差异明确保留。
- **Milan泳池**：2025官方公共室内泳池票价表列17个不同场馆，沿用附件人口1399079；其他运营方与室外泳池仍未知。
- **Singapore交通站点**：复用已核实LTA2026目录5205个唯一公交站代码；没有把轨道交通或代码重复加进总量。沿用附件2024人口6036900。代码清单未作50米聚类或独立运营状态普查，与既有目录下限规则相同。
- **Singapore泳池**：复用2025官方7个已核实名公共泳池场馆，使用相同附件人口；部分名录不假定完整。
- **Warsaw学校资源比率**：复用已准入官方2024/25六类青年学校资料。学生119740，教师FTE保留[2487,8148]；成人教师分配与向外取整不确定性不变，效用区间[0.2375434,0.5051248]。这是学校资源FTE口径，不是教师人数点值或学习质量。

新增供给数据不等于高中生实际可达性。新增年份允许明确的混合年份情景；附件人口不重新核验或更新。Amsterdam总部跨校区归属、London仅公立全中学FTE等新候选不自动填成全市点值，失败路线已跳过。没有为缩小冠军集合人为调整权重或删去不利数据。

`ranks.csv`、`utility_bounds.csv`包含原基线、六个单项新增、合并修订、六个逐项撤回和全部撤回，共15场景×两组权重。恰好6格变化，其余154格不变；附件已有112点值和12个均值导出的部分区间全部逐元素保留。全部撤回恢复原榜，逐项撤回用于定位每项证据的贡献。

`mc_city_summary.csv`、`mc_comparison.csv`及`mc_summary.json`给出与基线相同seed20261108、两权重中心、k=20/100/500各10000次的60000次权重扰动。固定中心k=100时，Oslo推荐频率86.88%→69.31%，Singapore2.12%→15.30%，Zurich8.24%→15.06%。新增证据提高了其他城市的竞争力，不能把推荐频率下降说成数据质量变差。这些是指定Dirichlet权重分布下的条件频率，不是真实夺冠概率；缺失值未赋概率或点插补。固定权重下冠军集合仍为16。

## 当前模型

主分析入口为`../../design/task4_user_current_model.json`，指向本16城V118模型；原25城registry仅保留为历史研究对照。固定权重仍为八项各0.1125、站点密度与泳池密度各0.05。附件公共交通分担率原值保留，但不当成站点密度。

    S(u)=100 sqrt(Σw_j u_j²)/(sqrt(Σw_j u_j²)+sqrt(Σw_j(1-u_j)²))
    L_i=S(lo_i), U_i=S(hi_i)
    R_i=max(0,max_{k≠i} U_k−L_i), 推荐=argmin_i R_i
    可能冠军条件：U_i≥max_{k≠i}L_k

新设施下限按原公式x=100000×数量/附件人口，u=x/(a+x)，其中站点a=50、泳池a=1，上界保持1。所有已有均值通勤的Jensen区间保持不变。
