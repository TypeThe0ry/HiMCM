# V163：Helsinki原始学生API与全国FTE估算范围

本轮取得Helsinki一般高中学生的直接官方API响应，并识别全国教师FTE的变量专门估算说明。城市学生分子已有可追溯原响应，但全国FTE发布值尚不是城市真实教师数的已证明上界，因此不填师生比，也不生成上端效用界。新增入模0、评分区间收窄0，当前V154模型与V160稿件保持。

## 直接取得的真实数据

Statistics Finland表11c4使用地区KU091（Helsinki，2025地区分类）、教育部门20（一般高中）、指标op_4a（学生总数）。2022、2023、2024三年值为17789、18177、18661。其地区含义是教育所在地，学生定义为统计年9月20日具有课程学习权者；不转称居民14—18岁人数，也不把2025地区分类当成2025观测年。请求JSON与原始JSON-stat响应分开保存。

已归档的Helsinki2025年鉴表7.14在2022与2023行都列18177；直接API2023值与之相符，2022值则不同。本轮没有推断差异来自排版、修订或其他统计处理，也没有改写旧原件或用户CSV。原始API使分子有了直接复核路径，不需要靠两行相同就猜哪一年应当采用。

Eurostat educ_uoe_perp02按FI、ED3、sex=T、worktime=TOT_FTE、unit=NR选择，API时间标签2023／2024的全国总量为19586／19825。2024公立16198、私立3628，合计比发布总量多1，均保持原值；没有自行修正。PRV_IND为缺值且带m，未转为0。TOT_FTE选择不可与全职人数FT或总人数TOTAL互换；unit=NR单独不能说明是否FTE。

## 为什么暂不构成城市教师上界

国家总量可以用于城市包络的前提是已证明T_city≤T_upper，而不是把全国师生比当城市点值。芬兰国家元数据的来源概述指向就业登记数据，但原始附表15.2.2的F10进一步说明：从2022/23学年起的全职／兼职划分及FTE数量涉及估算，采用地方政府工资资料与私立教育提供者资料。18.1!B29记录登记来源，并不取消这个变量层面的估算说明。

估算值可以是有效的官方统计；本轮需要的却是有一侧误差保障的教师上界。所检查材料没有建立全国估算误差的一侧包络，不能仅因全国范围更大或数值未带状态标记就认定它保证大于城市实际教学FTE。随意加一个单位的舍入余量也不能覆盖未量化估算误差。因此city_PTR_bound保持null，observations为空。

此外，Eurostat时间标签、UOE采集年、学年起止及原始学生统计日须逐项区分；元数据不支持把日历标签2024简单改称2024/25学年，更不支持自动迁移到2025基线。此处没有在参考期未核合前计算条件比率或假造误差范围。
