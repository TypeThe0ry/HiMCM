# 用户附件：16 城市评分场景

按用户“无需核验、直接使用”的选择，以附件数值作为本场景输入依据。所有非空数值直接使用，不按 STALE / SUSPECT / MODELLED / NATIONAL 等标记剔除，不依据附带分子、人口重算或修正值。原 CSV 不变，原 25 城模型与 registry 不变。本结果是独立 16 城场景，不是同候选集下的补数前后对比。

沿用原十指标及固定锚点。固定权重：站点密度与泳池密度各 0.05，其余八项各 0.1125；另列十项等权对照。成本效用为 a/(a+x)，收益效用为 x/(a+x)。高教每百万人密度除以 10 转每十万人；泳池原值已是每十万人。附件 PTR 作为用户学校师生比场景输入，不宣称已证实高中阶段。附件 commute_min 作为通勤均值场景，经 Jensen 规则给出 [exp(-mean/30),1]，不宣称高中生实际通学。transit_share_pct 无法直接转换为站点密度，因此该指标保留 [0,1]；early_leavers 不新增指标或权重。空值保留 [0,1]。

TOPSIS 沿用固定理想点 0 和 1：D+ = sqrt(sum(w*(1-u)^2))，D- = sqrt(sum(w*u^2))，S = 100 D-/(D+ + D-)。分数上下界分别代入效用上下界。decision_rank 按最大遗憾 max(0,max其他城市上界−本城下界) 从低到高排序；possible_champion 表示本城上界不低于其他城市下界的最大值。midpoint_illustrative_rank 仅展示效用区间中点情景，不代表缺失值真实取中点。

结果：两套权重下 16 城均仍可能夺冠，无必然冠军；最小最大遗憾选择为 Oslo，中点情景第一为 Dublin。固定权重平均分数区间宽 18.8108，等权 22.2567。共 112 个点值、12 个部分区间、36 个完整缺失区间。固定与等权完整榜单分别见 fixed_ranks.csv / equal_ranks.csv；逐项映射和原标记见 utility_bounds.csv。

复现：在 research/2026-a 运行 `python3 scripts/task4_user_city_indicators.py`。脚本校验输入非负、权重和、效用区间、中点分数落在上下界中，以及运行前后原 CSV SHA256 一致。

## 权重扰动

运行 `python3 scripts/task4_user_city_sensitivity.py` 可复现 mc_city_summary.csv 和 mc_summary.json。两个中心（固定/等权），Dirichlet(k×中心权重)，k=20、100、500 各 10000 次，共 60000 次；每组使用 SeedSequence([20261108,k])。所有原数值、缺失区间和转换规则保持不变。输出每城最小最大遗憾推荐频率、平均决策名次及可能/必然冠军频率；并列推荐均分、名次取平均。

Oslo 在六组中的推荐频率均最高：固定中心为 51.99%、86.88%、99.89%，等权中心为 69.80%、95.89%、99.99%（按 k 从小到大）。在两组 k=500 中，每次仍有全部 16 城可能夺冠。推荐稳定不等于实际冠军已识别；这些频率仅描述指定权重分布下的条件情景，未给缺失值引入概率或缩小区间。
