# São Paulo：以真实年龄对齐14—18岁高中生

V48使用既有OD2023原始记录中的实际年龄，将São Paulo通学从全年龄高中在读者调整为14—18岁当前高中在读者。旧样本1,778人中，88人为19—72岁；新目标样本1,690人，其中1,489人有核验通学，186人没有学校旅程、15人首次学校旅程非家庭出发。后201人的效用继续保留[0,1]。

这不是新一轮调查，也没有以年龄替代高中学段。字典分别确认`ESTUDA=4`为当前高中在读、`IDADE`为实际年龄（年）；两项同时满足才纳入。地域仍为São Paulo市域居民，代码36、IBGE 3550308，不混用整个都市圈。

## 保留缺失与配对抽样

每人只使用其首个学校目的旅程；必须确认家庭出发、时钟与时长一致且为工作日。无旅程或来源不明不会赋零分钟。实际记录中年龄和个人权重均无缺失，提取器遇到缺失年龄会停止而非静默排除。

两个年龄口径沿用同一套21,917户、329区，包括没有目标学生的家庭，以相同随机种子进行2,000次配对家庭抽样。旧全年龄识别界与抽样包络完整复现；原件、时长规则和个人权重均不变。因此差异可归于年龄范围，不混入另换算法或抽样随机数的影响。

抽样仍为固定最终权重的区内家庭重采样；缺少原始收入层和完整复杂调查设计信息。它是探索性敏感性包络，不是设计有效的95%置信区间。原DBF来自已固定版本的公开研究镜像；官方附件页本轮仍503维护中，未完成官方逐字节认证。相应来源条件继续保留，`main_admitted=false`。

## 当前公式

设E为同时满足当前高中在读、São Paulo市域居住和14—18岁的人员。可用通学记录取l_p=h_p=exp(−t_p/30)，未知取[l_p,h_p]=[0,1]：

    T_L=Σ_{p∈E} q_p l_p / Σ_{p∈E} q_p
    T_U=Σ_{p∈E} q_p h_p / Σ_{p∈E} q_p

每次家庭重抽样后重新计算两端点；取覆盖原样本识别界的2.5%/97.5%分位数外包络。主评分与决策保持：

    S_i=100 sqrt(Σ_j w_j u_ij²) /
        [sqrt(Σ_j w_j u_ij²)+sqrt(Σ_j w_j(1−u_ij)²)]
    L_i=S_i(l_i), U_i=S_i(h_i)
    R_i=max(0,max_{k≠i}U_k−L_i)
    possible_i ⇔ U_i≥max_{k≠i}L_k

八主指标各0.1125，两辅助各0.05；按R_i升序给出决策排名。本轮仅修改São Paulo通学单元，其他249格逐项保持V47一致。
