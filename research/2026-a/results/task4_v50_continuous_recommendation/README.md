# V50：整个偏好区间的推荐稳定性

在当前V48数据界、V49证据审计和辅助指标总权重α∈[0.05,0.20]下，Singapore始终是唯一的最小最大遗憾推荐。一次全区间包络即可给出至少4.0466285分的正分离余量，不需要抽取权重点或递归细分。这个余量是保守包络差，不是实际最小领先分差。固定α=0.10的25城排名与V49完全一致，可能冠军仍有25城；实际数据区间未改变。

新增能力是区分两个问题：哪些城市仍可能实际第一，以及当前证据下推荐谁承担的最坏损失最小。原连续求解器回答前者，本轮给后者增加整个偏好区间的稳定性证书。抽查几个权重点不足以证明区间内没有推荐切换。

## 评分端点为何足够

对于任一固定效用向量u，令

$$A(\alpha)=\sum_jw_j(\alpha)(1-u_j)^2,\quad B(\alpha)=\sum_jw_j(\alpha)u_j^2,\quad q=\frac{B}{A+B}.$$

八项主指标权重各(1−α)/8，两项辅助指标各α/2，因此A、B均为α的仿射函数；A+B≥1/2。q的导数具有常数分子和正分母，符号固定。评分

$$S=100\frac{\sqrt q}{\sqrt q+\sqrt{1-q}}$$

随q单调，所以任一闭偏好区间上的评分极值位于两个端点。该结论包含u全0或全1的情况。最大遗憾本身不必单调，不能直接取两个端点的遗憾当作其上下界。

## 推荐证书

在偏好区间I内，由端点评分得到各城得分下界L_i(α)的范围[L_i^−,L_i^+]，以及得分上界U_i(α)的范围[U_i^−,U_i^+]。因此

$$\underline R_i(I)=\max(0,\max_{k\ne i}U_k^- -L_i^+),\qquad
\overline R_i(I)=\max(0,\max_{k\ne i}U_k^+ -L_i^-).$$

若某城c满足

$$\overline R_c(I)<\min_{k\ne c}\underline R_k(I),$$

它在整个I上唯一最优。否则二分区间；达到深度限制仍未分离时保存未解决区间，平局不作唯一性判断。本次整个[0.05,0.20]已通过，无未解决区间。

[实现与复现](../../scripts/task4_continuous_recommendation.py)：`python3 research/2026-a/scripts/task4_continuous_recommendation.py`。计算使用1e−9分的端点评分外扩及1e−8分的严格分离容差，是附带显式容差的数值证书，不是任意精度区间算术。检查包含随机区间包络、完全平局、区间内部推荐切换和支配情形；独立agent验证了单调性证明及当前结果。
