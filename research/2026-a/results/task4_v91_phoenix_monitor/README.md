# V91：Phoenix真实市域监测数据进入条件模型

取得EPA2024年官方监测原件后，Phoenix的PM2.5从未知[0,1]改为市域内合格监测网络的效用区间[0.564421,0.680536]。只改这一格，其余249格及全部真实学生通学区间保持；Phoenix决策名次由24升至16，可能冠军仍25城。

## 新数据解决了什么

此前WHO条目为Phoenix–Mesa–Scottsdale都市圈，未作为Phoenix市域数据准入。本轮[官方EPA原件](../../data/task4_v91_phoenix_air/README.md)包含法定Phoenix市域6个站点、8个PM2.5 FRM/FEM监测器的2024年度汇总，全部满足相应完整性规则且已认证。保留异常事件，浓度范围为7.041457—11.575910 µg/m³。

未设定未知空间权重，也未把同站多个POC或不同年度标准重复平均。两条混合方法记录、一个稀疏定期监测记录均位于区间内部；去掉它们，端点相同。Observation Percent为93—100%，表示相应监测计划的完成比例，不等于全年每日覆盖。原始88101全部Phoenix监测器集合与选中集合一致，未因只选完整记录而静默漏掉其他88101监测器。

当前PM指标已有WHO城市监测汇总的条件比较。本轮对应量明确为**已观测合格市域监测网络的未知非负加权年度量**。这个区间不覆盖未监测街区、居民或高中生人口加权暴露，也不包含测量系统偏差。若要求这些更严格的目标，撤回此条件，Phoenix恢复未知界和原第24名。

## 当前数学模型

对8个已观测年度值 $x_m$，定义未知网络加权量

$$\theta=\sum_m\lambda_mx_m,\quad \lambda_m\ge0,\quad\sum_m\lambda_m=1,$$
$$\theta\in[\min_mx_m,\max_mx_m],\qquad
u_{PM}\in\left[\frac{15}{15+\max_mx_m},\frac{15}{15+\min_mx_m}\right].$$

这是允许所有非负权重的凸包，不是置信区间或假设各站等权。主评分保持

$$S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},$$
$$L_i=S_i(l_i),\quad U_i=S_i(h_i),\quad R_i=\max(0,\max_{k\ne i}U_k-L_i).$$

最小R决定推荐；$U_i\ge\max_{k\ne i}L_k$保留冠军可能。资源效用 $u_E=15T/(N+15T)$，通学效用 $u_t=e^{-t/30}$。8项主指标各权重$(1-\alpha)/8$，2项辅助指标各$\alpha/2$，默认α=0.1。
