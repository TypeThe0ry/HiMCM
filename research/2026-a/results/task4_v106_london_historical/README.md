# V106：真实Year10通学分箱的舍入与缺失界

新原件是DfES委托、NFER开展的London Challenge2006调查，London学校Year10受访人数22451。报告的5档到校时长与未回答比例为30%、36%、15%、7%、3%、8%，合计99%。这是真实年级学生的通学测量，但年份、学校所在地、自愿参加学校和未核实居民／精确年龄限制，使其不能作为当前London全市输入。

## 保留舍入和缺失，而非补一个平均分钟

以公布比例r为中心，条件性常规整数舍入范围为$r_b\pm0.5$个百分点，另检验±1个百分点。令

$$p_b\in[\max(0,r_b-\epsilon),\min(100,r_b+\epsilon)]/100,\qquad\sum_bp_b=1.$$

采用保守连续时间闭包[0,15]、[15,30]、[30,45]、[45,60]、[60,∞]。相邻分钟标签的间隙不人为当作不可能时间。按$u(t)=e^{-t/30}$得到每档效用$[a_b,b_b]$；未回答档取[0,1]，开放尾部下界为0。两个线性规划为

$$u_L=\min_p\sum_bp_ba_b,\qquad u_U=\max_p\sum_bp_bb_b.$$

没有按99归一化、反推精确人数或插补分箱中点。LP保留各档共享的合计约束；结果文件保存上下界各自可行的比例向量。报告Table15说明舍入可使总和不等于100，邻表明确nearest integer；±0.5仍作为条件解释，±1用于敏感性。没有据此宣称该表有调查权重，也不是置信区间。

**第13仅是把历史学校子群替进一格的诊断，不是当前城市新排名。**三个情景均25城可能冠军、Singapore连续推荐，其余249格不变。当前London通学仍[0,1]。年份与覆盖限制不能靠样本大或区间窄消除。
