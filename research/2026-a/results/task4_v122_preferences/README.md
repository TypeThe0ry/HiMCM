## AHP的主观性与一致性

原基准仍为8个主指标各0.1125、交通和泳池各0.05。教育优先只将学生/教师资源与高教密度的基准权重乘2，再归一化；独立生活优先只将通学/通勤时长效用与交通站点密度乘2，再归一化。乘2是明示的分析选择，现有资料没有真实学生调查、专家成对判断或14岁/18岁的实测偏好证据。

令基准权重为`w`、情景乘数为`m`，`w'_j=w_j*m_j/sum(w*m)`，再构造`A_ij=w'_i/w'_j`。矩阵正值、对角线为1、互反、秩为1，且满足乘法传递性。主特征向量恢复`w'`，`lambda_max=10`；以`RI=1.49`计算，三情景的CR均在浮点精度内为0。该一致性来自权重比的代数构造，不是对真实偏好的实证检验。

原始乘数与最终权重见[weights.csv](weights.csv)；矩阵、来源标签与诊断见[scenario_matrices.json](scenario_matrices.json)及三个`*_matrix.csv`文件。所有情景共用V121的160个效用上下界，见[utility_bounds.csv](utility_bounds.csv)。未替换用户CSV已有值，未重估人口、年份、效用锚点或缺失规则。

## Dirichlet权重敏感性

每个profile分别在浓度20、100、500下从`Dirichlet(k*w')`抽样10000次，合计90000次。每组重新以`SeedSequence([20261108,k])`初始化；只抽样权重，不抽样或填补数据区间。报告每城的最小最大遗憾推荐频率、平均决策名次、进入决策前三的频率及可能/必要冠军频率。边界平局按名额比例分摊，每次推荐频率和为1、前三频率和为3。

| 情景（浓度100） | Zurich推荐频率 | Oslo推荐频率 | Singapore推荐频率 |
|---|---:|---:|---:|
| 沿用基准 | 43.34% | 28.00% | 28.23% |
| 教育优先 | 6.83% | 45.62% | 42.11% |
| 独立生活优先 | 58.99% | 15.46% | 25.12% |

浓度100基准下，Zurich的前三频率为82.69%，Oslo为99.56%；平均决策名次分别为2.2305和2.1062。这些摘要不取代确定权重的区间最大遗憾主榜，主榜仍推荐Zurich。教育优先浓度20时，最常推荐的是Singapore（34.95%），而确定权重推荐为Oslo；浓度100/500时最常推荐恢复为Oslo。所有频率都是指定权重分布下的条件结果，不是实际夺冠概率或人群偏好比例。

完整144行和相对同浓度基准的变化见[mc_city_summary.csv](mc_city_summary.csv)。浓度只控制权重围绕中心的分散程度，不提供真实学生偏好的估计。

## 复现和核验

在仓库根运行：

```sh
python research/2026-a/scripts/task4_v122_preferences.py
```

唯一当前数据入口为`task4_user_v121_revision.revised_bounds()`及其准入清单。基准与V121的`after_conditional/fixed`逐项对齐，基准三组MC频率与V121原文件一致。脚本以独立广播平方距离核查权重仅乘一次，逐城排除自身复算遗憾、可能/必要冠军，并独立核查全部9组MC推荐、平均名次与前三频率；AHP矩阵性质也逐项验证。[audit.json](audit.json)记录检查，[summary.json](summary.json)保留源哈希、参数、结果与历史比较。
