# 从稳定榜单到可被证据支持的榜单：遗漏维度检验

日期：2026-11-07。承接真实25城V0/V1对照。研究问题：如果遗漏了教育、课外成长或学生独立出行，已有榜单的高稳定性还意味着什么？

## 1. 这次的实质发现

此前哥本哈根在20,000组限定偏好样本中第一名占比99.87%，但那是四项已知代理指标内部的稳定性。在固定这四项相对等权、允许缺失的学生生活维度取任意0—1效用的模型中，**缺失维度权重达到5.0674%时，已经存在迪拜与哥本哈根打平的补全；略高于该值就可反转。**

这不是迪拜实际教育更好的证据，不是估计出了缺失指标，更不是5%的数据有误。它是有明确假设的数学边界：当前数据能保证的结论比单看偏好模拟占比所暗示的更窄。

严格区分：前者探索四项权重，后者固定四项相对权重并加入遗漏内容。两项结果不矛盾，不能把99.87%与5.07%当同一个概率比较。

## 2. 创新定位与获奖论文的联系

14995队的MC-TOPSIS与Kendall检验给了我们处理排序波动的起点；11135队的Absolute-Top分析给了我们解释首选翻转的起点。现在追问的是更深一层：**尚未测量的重要内容，是否会让“稳定”的榜单失去依据？**

本轮贡献包括：

1. 将“教育数据缺失”从局限段的一句话，转化为可以计算的名次边界。
2. 在本TOPSIS结构下推导遗漏维度导致首选打平的解析阈值，避免把随机搜索的最小发现误称全局最小。
3. 区分“存在一种补全使它第一”与“所有允许补全下它都第一”。
4. 把结果转成具体取证条件：需要对哪座城市的缺失效用掌握到什么下界，才能支持首选。

必要/可能偏好的思想已有稳健多准则评价研究，本模型不等同于完整的稳健序回归，也不声称这些概念首次提出。应用贡献在于对本题高中生评价内容遗漏的识别、推导与数据检验。单纯重复“我们用了区间法”不构成足够创新。

## 3. 数学模型

已知四维效用z_ij及相对权重w_j，Σw_j=1。定义：

A_i=Σ_j w_j z_ij²，B_i=Σ_j w_j(1-z_ij)²。

令α是尚未测量的学生生活维度的总权重，原四维总权重变为1-α。令y_i∈[l_i,u_i]⊆[0,1]为该缺失维度的未知效用。当前全未知情景取[0,1]，**不将y填成0.5，也不抽样后伪装成真实城市数据**。

C_i(α,y_i)=sqrt((1-α)A_i+αy_i²) /
[sqrt((1-α)A_i+αy_i²)+sqrt((1-α)B_i+α(1-y_i)²)]。

当α=0，精确回到原V0。这里y代表预先定义的一个综合缺失维度，不预设教育与课外活动之间的实际聚合函数。若未来分别测量多个维度，应在原指标层扩展；不能直接假定“先平均再平方”等价于各指标距离平方相加。

α是规范性权重假设，不是缺失数据比例；y是未观测效用，不是人群比例。

### 3.1 精确区间

C_i对y_i单调不减，因此L_i=C_i(α,l_i)、U_i=C_i(α,u_i)。在城市之间的区间可独立取值这一假设下：

- i可能为并列第一，当且仅当U_i≥max_{h≠i}L_h。
- i必然为至少并列第一，当且仅当L_i≥max_{h≠i}U_h。
- 最好可达竞争名次=1+#{h≠i:L_h>U_i}。
- 最差可达竞争名次=1+#{h≠i:U_h>L_i}。

“竞争名次”按严格高于它的城市数量定义，并列第一都记1。每座城市的最差/最好情况可单独达到，但不代表所有城市能同时取到各自最好名次。若将来获得跨城市联合约束，应缩小允许补全集合，上述独立区间可能成为保守界。

### 3.2 首选打平阈值的推导

固定w，a为原首选，h为挑战者。在全未知区间下，最不利于a的设置为y_a=0、y_h=1。令t=α/(1-α)，比较两个TOPSIS分数等价于比较负理想距离与正理想距离之比。两城打平条件可化为：

A_a B_h=(B_a+t)(A_h+t)。

非负根为：

t_ah=[-(B_a+A_h)+sqrt((B_a-A_h)²+4A_aB_h)]/2，

α_ah=t_ah/(1+t_ah)。

若原来已并列则阈值为0；当前原首选唯一，24个根均为正。对所有h取最小值，即固定w及全区间假设下“首选不再保证严格领先”的精确临界值。这里是解析结论，不依赖蒙特卡洛是否碰巧抽中边界。α=1处用原公式连续处理。

α=10%时可能第一为哥本哈根、迪拜、墨尔本。α=20%时还包括多伦多、凤凰城、纽约、巴塞罗那、华沙、雅典、开普敦、东京、新加坡。可能第一不代表现实中等可能，更不代表这些城市的教育值已被测出。

全区间[0,1]很宽，结果必须做区间敏感性：若假设两城缺失效用都在[0.25,0.75]，迪拜打平阈值升至9.6594%；区间[0.4,0.6]时升至21.2160%。这些也是分析假设，没有来源支持时不宣称现实城市确实落在该区间。说明结论依赖的正是尚待取得的证据。

另计算五种分析者设定偏好：等权、偏重安全、环境、住房、通勤，主偏好权重0.55、其他各0.15。它们均首选哥本哈根，但首个遗漏维度打平阈值约为5.07%、1.02%、5.80%、2.18%、5.99%。这些不是五种经调查识别的学生群体，更不等于测得了群体公平性。

## 5. 将“缺数据”变成明确的取证目标

固定α，假设所有竞争城市缺失效用最高可能为1，求首选城市必须具有的最低y，使其仍不低于全部竞争者上界。

| α | 支持哥本哈根至少并列第一所需的y下界 |
| --- | ---: |
| 5% | 0 |
| 10% | 0.3624 |
| 20% | 0.6137 |
| 30% | 0.7194 |

这些是对所选效用定义的数学证据条件，不是给哥本哈根指定的分数。比如α=20%时，只有真实数据及透明效用转换能支持y≥0.6137，才可使用该保证；不能因需要0.6137就调尺度或填值达到它。

下一步按以下逻辑采集：先确定缺失维度究竟测什么及其转换，再查看可能冠军集合，优先补齐能区分这些城市的同口径数据。若把α限制在10%，先补哥本哈根、迪拜、墨尔本有明确决策依据；若团队认为α应为20%，仅补三城就不足以覆盖12个可能冠军。不给“调查哪条数据一定最有价值”的过度承诺，因为尚无数据获取成本、误差模型和真实先验。

## 6. 下一项有价值的实证机制：学生实际可用机会

根据UNICEF的儿童城市框架，服务的可获得、安全、参与和公共空间需要进入解释。建议选一个可核查的核心量：在给定课后时段、往返出行时间与费用预算下，至少能使用一项学习服务及一项运动/社交服务的学生居住人口比例。

这里的时间与费用预算应是明确情景或调查依据，不能凭空说“30分钟是公认标准”。需要：同版本城市边界、居住人口栅格（有年龄数据才称学生人口）、公共交通/步行路网、设施类别、费用/年龄资格和开放时间。无学生人口只能称居民覆盖代理；无开放时间不能声称放学后可使用；无费用数据不能声称可负担。

可定义单元r、情景s下的指示变量I_irs：是否同时满足学习服务和活动服务条件；城市覆盖率Q_is=Σ_r p_ir I_irs。这样能把交通与设施放入同一个可使用机制，避免学校多、通勤快分别加分却没人能到达的错配。该项尚未采集和运行，不将当前缺失效用y冒充Q。

## 7. 论文的修订链应如何写

V0：四项代理的单点排名。

V1：偏好变化下的低后悔推荐，发现原首选没有改变，不能虚构改进。

V2：公开遗漏内容的可识别范围，用精确阈值指出哪些推荐只是条件成立；保留V0/V1的主情景全排序以回应题面，同时给出证据支持的名次区间和可能冠军集合。

V3（待真实数据）：补入学生可用机会，收缩区间，检查是否减少可能冠军数量、改变首选或确认原首选。只有取得同口径数据后才可声称完成。

V2的改善是减少无依据的确定性、指出验证主张所需的证据；它不是提高生活质量预测准确率，也不是证明原冠军错误。要达到扎实的完整竞赛解答，V3的教育/机会测量仍然重要。不要把更多公式替代这项数据工作。
