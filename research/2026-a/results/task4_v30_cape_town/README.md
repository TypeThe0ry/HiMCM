# 真实高中通学修订：Cape Town 决策名次13→5

新增Cape Town官方GHS2023中159名14—18岁、当前10—12年级非远程学生的实际通学记录。保留分箱及抽样不确定性后，Cape Town得分区间从[33.019656,73.255944]收窄为[35.638820,72.191687]，宽度减少3.683422分；决策名次由13升至5。共9城名次变化，Kendall tau=0.946667。

Singapore仍为最小最大遗憾推荐，Phoenix仍第24，可能冠军仍有25城。新增信息减少了Cape Town通学指标的不确定性，但未识别唯一冠军。名次变化是证据更新引起的决策修订，不表示城市现实状况发生了同等改善。

## 模型及验证

评分、最大遗憾和可能冠军公式保持不变：

$$u(t)=e^{-t/30},\quad S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad L_i=S(l_i),\ U_i=S(h_i).$$

$$\mathcal C=\{i:U_i\ge\max_{k\ne i}L_k\},\quad R_i=\max(0,\max_{k\ne i}U_k-L_i),\quad i^*=\arg\min_iR_i.$$

八项主指标各0.1125，两项辅助指标各0.05；连续辅助权重[0.05,0.20]的可能冠军检验也保留25城。Cape Town使用分层PSU比率估计的近似抽样区间，完整公式及实际总体见[来源说明](../../data/task4_v30_cape_town/README.md)。调查不覆盖学生宿舍等集体住户，区间不能解释为全城市联合置信保证；全局`main_admitted=false`保持。

验证：核对原ZIP、问卷和代码本哈希，实际学生名册及时间分箱，无效权重与未知资格；两套独立实现复算分箱界。推断保留全部217PSU和14层，单元测试覆盖零目标PSU和权重缩放。模型检查只有Cape Town通学单元变化、区间嵌套和其余249项不变。
