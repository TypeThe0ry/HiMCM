# Tokyo：纳入3,435名高中部学生，保留教师分配区间

V47把六年制中等教育学校的高中部纳入Tokyo师资资源指标。官方同日数据确认新增学生3,435人，扩展后共306,903人；对应555名本务教师服务整所学校，不能全部认定为高中部教师。保留未知分配后，Tokyo仍第2，Singapore仍第1、Phoenix第24，25城均仍可能夺冠。

主修订没有改变任何城市决策名次，Kendall tau=1。固定权重和连续辅助权重α∈[0.05,0.20]下，可能冠军均25城；V45的全城教育/通学完美补数证书在本轮输入下仍给出20个固定权重、25个连续偏好必然保留城市。

本轮实际改善是增加高中阶段覆盖并显式保留跨学段教师归属不确定性。新旧总体不同，不能把旧点值与新区间取交集来制造精度提高。新增人数不意味着城市教育质量提高，区间扩大也不意味着教育资源实际恶化。

## 学段和人员为何可以合并

官方表9的8所中等教育学校包括2所国立、6所公立，脚注明确没有私立该类学校。其后期课程适用高中课程标准，3,435人按三个年级和性别合计核验；前期3,564人未进入高中分子。中等教育学校与普通高中分列为不同法定学校类别。

官方说明将本务人员按任命归属；不明确时依薪资来源、薪资高低及授课时数确定主要学校。因此在报告的主职归属口径下合并不同学校类别的教师池，避免重复累计兼务人员。该池中有多少人参与高中部教学未发布，使用H∈[0,555]，不按学生比例猜测分配。

通信制高中、特殊教育高中部和专门学校高等课程仍另列。新取得的通信制表含4所独立校、7所併置校，11,793名学生及244名本务教师；课程人群、校址和教师归属尚需单独审计，没有直接相加。本轮结果仍为范围明确的条件评价，`main_admitted=false`。

## 当前数学公式

本轮只改Tokyo教育单元：

    H∈[0,555]
    u_E(H)=15(19446+H)/(306903+15(19446+H))
           ∈[0.4872927014,0.4943254278]

复用已有教师分配区间函数；枚举556个整数分配值核验单调性和端点。其他249格不变，包括Tokyo高校资源下界以及所有真实高中生通学记录。

    S_i=100 sqrt(Σ_j w_j u_ij²) /
        [sqrt(Σ_j w_j u_ij²)+sqrt(Σ_j w_j(1−u_ij)²)]
    L_i=S_i(l_i), U_i=S_i(h_i)
    R_i=max(0,max_{k≠i}U_k−L_i)
    possible_i ⇔ U_i≥max_{k≠i}L_k

八主指标各0.1125、两辅助各0.05，按R_i升序给出决策排名。通学仍用exp(−t/30)及既有权重与缺失处理。
