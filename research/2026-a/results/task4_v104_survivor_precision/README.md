# V104：四城最优值需要多高的测量精度

V103在理想精确补数下证明：全城安全、教育、通学三项同时补齐，连续偏好下最少可保留4城。本轮把测量结果改为有规定宽度的区间，检查这个结论对残余不确定性的依赖。真实V102输入、排名及25城可能冠军不变。

## 结果

| 规定残余效用宽度δ | 理想补数后的最小候选并集 |
|---|---|
|0|4|
|0.001|4|
|0.005|4|
|0.00921630859375|4，已认证|
|0.00927734375|至少5，四城已有严格反例|
|0.01|5，另有五城完成证明可达|

四城阈值夹在[0.00921630859375,0.00927734375]，不是精确等号边界。δ=.01的五城集合为Phoenix、Copenhagen、Mexico City、Singapore、Jakarta。其余较大宽度仅证明四城不可能，未计算精确最小数。

δ是0—1效用轴上的**规定残余区间宽度**，不是“原始指标误差δ%”，不是置信水平，也不是“误差至多δ”。若只要求至多δ，仍可选择零宽，不能据此宣布四城不可能。

## 可复核的算法

选中单元格的规定宽度为$d_{ij}=\min(\delta,h_{ij}-l_{ij})$，未选格不变。对于可能冠军容纳集合K，构造

$$I^{K,\delta}_{ij}=\begin{cases}[h_{ij}-d_{ij},h_{ij}],&i\in K,\\[l_{ij},l_{ij}+d_{ij}],&i\notin K.\end{cases}$$

若存在任何同宽、共享测量区间能在所有α下排除K外城市，则最大下界必由K内城市取得；上述构造提高K内下界、降低K外上界，因此也能排除。这个证明涉及整个集合，不能解释为所有城市两两比较都改善。

V103已证明零宽时唯一四城集合K为Phoenix、Copenhagen、Singapore、Jakarta。任何正宽可行方案都能细化为共享点值，故正宽四城方案只能使用这个K。随δ增大规范区间嵌套扩大，局外城市更难排除；对这个唯一K夹逼阈值即可证明四城何时不可能，不必重新猜测所有连续数值。

所有偏好共用同一组区间；每次检查完整α∈[.05,.20]，按比较多项式全部实根分割。并列计入可能冠军，近零点保留未决。δ=.01额外加入严格反例城市Mexico City，独立检验五城集合可排除其余20城，于是下界5与可达上界5匹配。

## 实际含义和限制

创新改善的是**补数计划的可检验性**：从“精确补数理论上能剩4城”，进一步识别所需的残余效用宽度，并发现宽度0.01时最优值回到5。不能把4城当作现实数据收集承诺。高教与师资的效用上端1可能只是闭区间极限，有限原始数据未必达到；可行证书仍是矩形外模型的最有利情景。
