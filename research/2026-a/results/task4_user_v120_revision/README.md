## 为什么冠军集合未缩小

保留可能冠军的条件是U_i≥max_other L。当前证据提高部分下界、降低部分上界，但尚未形成任何城市的U_i低于其他城L的严格分离。补数优先审计显示，单格有3城排除潜力只是Singapore通学的极端理论界：排除第一座城需utility下界>0.871331，而真实历史阶段proxy下界仅0.210484。不把理论端点当真实观测，也不为追求小集合调整区间。
