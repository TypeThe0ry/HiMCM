# Tokyo：高中年份更新与大学总部资源下界

**Tokyo决策排名由第3升至第2，变化主要来自新增的高校资源下界。** 官方2025学校基本调查确认303,468名高中学生、19,446名本务教师；同一表的2024行精确复现旧模型。另一张官方表确认143所大学总部，配对同日東京都人口14,254,039人，为高校资源提供下界。其他高校类型未穷尽，上界仍未知。

## 数据范围决定解释

高中表覆盖東京都国立、公立和私立高中的全日制及定时制课程；本务教师是人数，不是FTE。通信制与另表中等教育学校未混入。2025年5月1日PTR为303468/19446=15.605677，对比2024年的15.648693，测量师资资源而非学习成绩。

143所大学=国立11+公立2+私立130。脚注按大学总部所在地计数，学生另按学部/研究科所在地统计。接受总部作为机构所在地时，它是经核验高校存在的保守下界，不是143个本地教学园区或可入读机会。未加入需另核分类和去重的短期大学、高专及专门学校，未把143作为全部高校总数。多地办学规则已明确写入[指标规范](../../design/task4_v5_indicator_spec.md)。

人口为同年同日東京都总量，使用原发布的2020人口普查基准估计，不宣称是后来重基准后的最新人口。跨城年份、教学覆盖、教师人数/FTE差异以及总部定位条件继续保留，`main_admitted=false`。拒绝总部定位时，表中“只更新师资”即资源证据撤回对照；拒绝两项范围条件时采用两格[0,1]的完整撤回。

## 当前公式

    u_PTR = 15 / (15 + students/teachers)
    d_HE = 143 / 14254039 × 100000 = 1.003224419
    u_HE ∈ [d_HE/(1+d_HE),1] = [0.500804807,1]

主评分及决策保持：

    S_i=100 sqrt(Σ_j w_j u_ij²) /
        [sqrt(Σ_j w_j u_ij²)+sqrt(Σ_j w_j(1−u_ij)²)]
    L_i=S_i(l_i), U_i=S_i(h_i)
    R_i=max(0,max_{k≠i}U_k−L_i)
    possible_i ⇔ U_i≥max_{k≠i}L_k

八主指标各0.1125、两辅助各0.05；通学继续按exp(−t/30)、已有人员权重及缺失区间计算。算法只修改Tokyo两个单元，其余248格逐项保持V44一致；没有用新资源数据替代真实高中生通学。
