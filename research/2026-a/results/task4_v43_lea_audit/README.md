# Phoenix：同年学区人数未提供可用上界

V43核对了NCES 2024–25完整学区学生文件。Hope Academy所属学区0403860的227条记录全部标为`Suppressed`，学生数为空。总人数及9—12年级人数均无法用于封顶该校人数。因此，本轮没有新增可纳入主模型的数值，复跑结果与V38一致：Singapore决策排名第1，Phoenix第24，Cape Town第5，25城均仍可能夺冠。

## 核查解决了什么

V42已找到Phoenix公校高中阶段的70,678名已知学生和2,512.97个已核对的学校教师FTE下界；Hope Academy人数是剩余未封顶项。如果存在同口径学区总人数D，且Hope学生包含在该学区总数中，就可采用保守上界S_U=70,678+D，而无需估算缺失学校人数。本轮完整读取3,822,460条官方记录后，确认公开文件没有提供数值D。抑制不等于零，也没有据此设定人数上限。

本轮贡献是核实并关闭这一补数路径，保存完整可离线复核的数据。它没有缩小证据区间，也没有改善排名确定性。V42的1,178人州级快照仍需核实与NCES的日期和人群兼容性，不能转为无条件事实。

教师分类与学校归属也需区分：学区按教学类别报告的FTE，不自动等于具体学校9—12年级可分配的FTE。本轮不依据网页索引中的分类数字改写已定义的学校资源指标。

## 当前模型及缺口

令每城每项效用为u_ij∈[l_ij,h_ij]，八个主指标各权重0.1125、两个辅助指标各0.05：

    S_i(u) = 100 sqrt(Σ_j w_j u_ij²) /
             [sqrt(Σ_j w_j u_ij²) + sqrt(Σ_j w_j (1-u_ij)²)]
    L_i = S_i(l_i), U_i = S_i(h_i)
    R_i = max(0, max_{k≠i} U_k − L_i)
    possible_i ⇔ U_i ≥ max_{k≠i} L_k

按R_i从小到大给出保守决策排名；“可能冠军”表示现有证据未排除其第一名，并非获胜概率。教育资源效用为15/(15+PTR)，通学效用为exp(−t/30)，t以分钟计。V42公校资源诊断的下界为15T_L/(S_U+15T_L)；当前无法从这些公开人数记录给S_U一个有限数值，因此不能据此证明严格正的效用下界。完整主模型见[公式与定义](../../design/task4_current_model.md)。

接下来有用的材料是：Hope同口径2024–25年10月1日在校人数，或可核验州级1,178人快照统计日期与覆盖范围的说明；Phoenix高中生实际通学时间、调查人数及覆盖范围。本轮[通学检索](../../data/task4_v43_phoenix_travel/README.md)没有取得符合条件的新观测。

Cape Town真实GHS 2023数据继续保留：14—18岁、当前10—12年级、正规学校非远程在读样本159人，使用官方权重和时间分箱，保留抽样误差。[原始数据与筛选](../../data/task4_v30_cape_town/README.md)已解决此前真人验证下载障碍。
