# V97：把逐城市下界验证为同一补数情景下可达到的最小数

在当前V96闭区间模型中，12种补数范围、固定／连续偏好共24个案例，都找到了一组**共同的精确揭示值**，使剩余可能冠军数量等于已证明的下界。此前只能说“任何补数结果至少留下这么多”；本轮进一步证明这些案例的下界在模型内确实能够同时达到。实际城市数据、排名和25城可能冠军集合没有改变。

| --- | ---: | ---: |
| 全城教育 | 25 | 25 |
| 全城通学 | 24 | 25 |
| 全城教育＋通学 | 9 | 22 |

最后八行的共同前两项均为教育＋通学，第三项分别变化。1表示存在模型内揭示值能留下唯一候选，不表示实际测量必然如此，也不评价取得数据的成本或概率。

## 共同情景与证明

令B为将精确揭示的单元，x为其中一组值，x必须在现有闭区间内；其他单元继续保持原区间。定义

\[
\mathcal C(x;\alpha)=\{i:U_i(x;\alpha)\ge\max_{k\ne i}L_k(x;\alpha)\},\qquad
\mathcal C_A(x)=\bigcup_{\alpha\in A}\mathcal C(x;\alpha).
\]

固定偏好目标是最小化`|C(x;0.1)|`；连续目标是最小化`|C_A(x)|`。连续案例中的x对所有城市和整个α范围保持不变；不同保留城市可以有不同α见证。固定案例与连续案例可以采用不同x。

既有逐城市证书给出集合K：每个i∈K在任意合法揭示后仍可能第一。因此所有x的候选数至少为`b=max(1,|K|)`；至少1来自有限候选中必有一个城市的下分数最大，其上分数不会更小。

本轮构造一个候选情景：B内，K中城市取当前上端，其余城市取下端；K为空时选Singapore作为上端锚点。接着从这**同一矩阵**重新计算全部25城的可能性。若该情景剩余c城，则`b≤真正的模型内最小数≤c`；只有b=c才报告最小数。24个真实输入案例均匹配。这个构造不是一般优化器，未匹配时必须保留区间，不能把c当作全局最优。

这些是独立效用闭区间模型的数学揭示值。端点可能只是原变量转换的极限，实际指标之间也可能有关联；模型内可行不保证现实中存在相应的一组有限原始数据。没有将任何假想值写入城市输入。

## 当前核心模型

\[
S_i=100\frac{\sqrt{\sum_jw_ju_{ij}^2}}{\sqrt{\sum_jw_ju_{ij}^2}+\sqrt{\sum_jw_j(1-u_{ij})^2}},\quad
L_i=S_i(l_i),\ U_i=S_i(h_i),\quad
R_i=\max(0,\max_{k\ne i}U_k-L_i).
\]

八项主要指标各占`(1−α)/8`，两项辅助指标各占`α/2`。按最小R推荐。主模型仍V96；本轮改变的是补数分析结论的可达性证明，而非真实排名、测量精度或城市评价指标。

```sh
python3 research/2026-a/scripts/task4_joint_acquisition_minima.py --output research/2026-a/results/task4_v97_joint_acquisition
python3 research/2026-a/results/task4_v97_joint_acquisition/audit.py
python3 -m unittest discover -s research/2026-a/scripts -p test_task4_joint_acquisition_minima.py
```

保存了1404个共同情景内的选中单元、600个城市判定和重新计算的300个下界证书。独立长双精度审计不导入模型函数，直接构造二次比较式及解析根，核验全部判定及312个正见证；最大固定分数差异3.23e−14。固定分数容差1e−10、连续多项式容差1e−12，属于数值认证而非形式化区间算术。

五项测试包括共享矩阵与原输入保持、精确并列、错误锚点导致未匹配、非空K仍不可据此声称其数量可达、非法输入。两个反例均保留`unresolved_gap`，防止把下界自动当作联合最小值。
