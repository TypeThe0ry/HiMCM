# 当前证据下：Phoenix 只补教育与通学仍不足以排除冠军可能

保持 V23 的其他证据不变，即使 Phoenix 的师生比与通学两项精确测得现有效用下界，其剩余得分上界仍为56.402679，高于竞争城市最高得分下界49.355873。因此，只补这两项无法把 Phoenix 排除出可能冠军集合。这个结论覆盖两项的所有允许取值：评分随效用单调，下界已是最有利于排除的情景。

本轮没有把假设端点写入数据。实际重跑仍推荐 Singapore，Phoenix 决策名次24，可能冠军25城；与 V26 的30分钟基准逐城排名和分数相同。新找到的 Phoenix Union 官方学区资料见[来源审计](../../data/task4_v27_phoenix_search/README.md)，因地域和教师分母口径未对应全市，不新增城市观测。

## 补数诊断的实际作用

| Phoenix 假设补齐内容 | 最有利于排除时的得分上界 | 竞争城市最高下界 | 能否排除 |
| --- | ---: | ---: | --- |
| 通学 | 63.766851 | 49.355873 | 否 |
| 师生比 | 63.766851 | 49.355873 | 否 |
| 师生比及通学 | 56.402679 | 49.355873 | 否 |

这里的教育专指现有师生比指标；新增毕业率指标会改变模型，不能套用本表。数据补齐仍可改善可解释性或分数精度，但不应承诺因此缩小冠军集合。

枚举本城全部不确定指标子集后，Phoenix 最少需要4项精确观测在有利端点同时实现，固定辅助权重0.1及连续范围[0.05,0.20]下均为4项。连续范围共有25组最小集合，例如 PM2.5、师生比、研究型高教密度、通学。这些是可行性条件，未考虑采集成本，也不保证真实结果足以排除城市。若要同时补教育与通学，可从完整集合表筛选含这两项的组合，而不是人为收窄它们的区间。

25城中，固定权重时仅 Istanbul 存在教育／通学两项组合的可排除情景；要求对连续权重范围全部成立时，没有城市满足。与旧 V8 诊断相比，New York 的连续偏好最少项数由5变4，其他城市不变；该变化反映当前证据输入更新，未新增评分方法。

## 公式与验证

采用[当前模型](../../design/task4_current_model.md)的单调 TOPSIS 分数 S。对城市 i 和拟采集集合 J，构造 v 的第 j 项为现有下界 l（j属于J），其余取现有上界 h。求：

$$m_i=\min_J |J|\quad\text{使得}\quad \forall\alpha\in[0.05,0.20],\ S(v_i^J;\alpha)<\max_{k\ne i}S(l_k;\alpha).$$

竞争城市下界固定，限于本城采集；跨城联合补数可能改变需求。严格不等式保留平局，不能把边界相等当作排除。连续偏好检查复用现有二次多项式根分区算法，无需新增权重抽样。

[脚本](../../scripts/task4_current_acquisition.py)检查25城的退化偏好范围与固定权重枚举一致、连续偏好的需求不小于固定偏好、输入矩阵未改变，并逐城复现 V26 的30分钟分数与排名（绝对容差1e-12）。
