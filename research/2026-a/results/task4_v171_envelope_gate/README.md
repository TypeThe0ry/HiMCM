# V171：确证SSP计量定义，保留城市包络的未证条件

2024/25原始手册确证：SSP为强制公私立学校逐项普查，教师FTE按教学工作量除以对应全职基准计算，长学制高中义务／后义务年级须分码。这使V170公私教师表的指标定义与采集范围有了直接方法依据。它与STATENT工资模型估计是不同统计活动，不能把后者的估算说明套到SSP教师FTE上。

## 已证实的来源条件

[SSP原始手册](https://dam-api.bfs.admin.ch/hub/api/dam/assets/32010182/master)第6–8页规定公私校覆盖与责任，第7页要求最终缺报在基础发布中标明；第19–20页给出C.7/C.8的FTE公式及相同单位要求，第21页规定高中学段分码。第10页允许州在开学至12月31日之间选统计日，要求尽可能协调学生／教师日期；第34页排除纯远程教学人员。实际缺席者的临时代课处理遵循岗位／活动统计定义，不能把该FTE解释成某天实际到课教师数。方法第20页已完整渲染实看，关键公式、日期与分码经主agent另行定位核对。

官方统计profile说明持续回溯修订。手册与profile未提供本次一位小数发布量的明确向外舍入或数值误差包络。本结论限于已取得原件，不断言所有来源都没有此说明；未取得个体记录也不单独构成拒收理由。

## 一侧包络需要证明什么

若同一目标活动和本地统计日下，学生子集S_L≤S_city，教师超集T_city≤T_U，且教师数为正，则

    PTR_city ≥ S_L / T_U
    u_city ≤ 15 T_U / (15 T_U + S_L).

因此合法子集／超集足以形成一侧界，不要求先拿到完整精确城市总量。全国私校汇总的其他州可以采用不同统计日：只要Zurich目标活动确实被相应Zurich组件包含、其他组件非负，日期不同本身不破坏超集论证。真正需要核对的是本地目标组件的包含关系与日期，以及T_U的数值方向；不能用“全国各州不完全同日”笼统否定这条路线。

[准入条件表](admission_gate.json)分别记录三项已有支持及两项尚未成立的条件。当前没有认证的S_L／T_U，因此不生成候选PTR、不把10242.2等发布量直接称为保证上界，Zurich师资格仍[0,1]。这些条件专用于拟议的单侧包络，不改变用户已有点值假设和区间规则，也不建立新的通用数据拒收标准。
