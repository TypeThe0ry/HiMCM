# V204：成组信息撤回揭示推荐对哪些资料有依赖

在保留的V204矩阵中，固定权重按最大遗憾推荐Oslo，等权推荐Zurich。本次在三组预先指定的点值上做完整信息撤回，发现推荐对不同组的依赖不同：固定权重单独撤回成本／住房或PM组会转向Zurich；等权单独撤回宽带组会转向Oslo。继续联合撤回其他组后，等权又选择Zurich。这不是数据改善，也不能据此认为联合撤回更稳健。

## 预定义组与实验含义

- 成本／住房组：两项共32个点。既有Numbeo三版本核查中，28个原点至少精确匹配一个版本，另4个没有匹配；版本与原始提取链仍有区别。因此，该组是待核查的出版系列候选，不代表已证明全部点有同一来源。
- 宽带组：16个点。已有官方存档字段核查匹配15个固定宽带中位数和Singapore的一个国家固定宽带均值；原始提取与市界仍未认证。
- PM组：16个原始2024年、MODELLED标记的点。标记和年份相同不证明相同模型或数据提供方。

对三组的全部八个子集分别使用固定权重和等权。选中的点效用扩为完整定义域`[0,1]`，其他V204区间、权重、锚点、TOPSIS和自排除最大遗憾保持。这是资料整组不可依赖时的条件检验；没有估计共同测量误差、跨城市误差相关性、现实概率或新的预测分布。矩形域保留独立极值组合，不保证它们在现实中可同时实现。

全部情景仍有16个可能冠军、0个必要冠军。完整撤回只扩大原来的不确定集合，不会排除原来可行的冠军。每座城市的最大遗憾在嵌套撤回下不减，但最小遗憾城市的身份可以改变后再次返回；推荐身份返回不代表区间变窄。

“包含关系下最小的改变集合”仅针对这三组：固定权重为`{成本／住房}`或`{PM}`，等权为`{宽带}`。它不表示现实中一个提供方失效就会产生这些结果，也不是输入误差容忍阈值。后续数据核验应区分原始来源认证、字段／版本选择和完全信息撤回；三者不能相互替代。
