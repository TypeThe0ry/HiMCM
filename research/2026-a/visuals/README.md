建议正文优先使用01、02、03、06；04放附录，05放敏感性部分。01与03分别对应实验A与实验B，必须写清权重设定不同；不能拿实验A确定榜首代替实验B的未知教育证据。

## 从获奖图中借鉴什么

- 2025 / 16739 / PDF p.8：矩阵用色标、数值和轴标签共同解释；相邻子图服务同一分析问题。我们的04采用单向色标，因为值不是正负相关系数。
- 2024 / 14995 / PDF p.6：并列面板、统一大小和字体。我们的03将前后区间放在相同尺度下。
- 2025 / 16442 / PDF p.9：横向排序适合较长名称。我们的01、02、03都保留城市标签。
- 2024 / 15041 / PDF p.11，以及2025 / 16738、16442 / PDF p.4：流程以阶段与箭头表达模型关系。我们的06使用简单矩形、直线和短文本。
- 2024 / 15504 / PDF p.7：多类别横向对比。只借鉴排列结构；本题不同单位的代理不直接堆叠成总量。

获奖论文中也存在颜色过多、文字过小、双轴难读等问题，不因获奖就照搬。新图统一白底、衬线字体、细轴线、浅网格，以蓝灰为主，橙色强调机制；点形同时区分含义。没有使用生成式插画、城市剪影、发光背景或无数据意义的3D装饰。

## 输出与使用

每张图都有 PDF（推荐插入LaTeX）、SVG（可编辑矢量）和240 dpi PNG。图内为英文，方便用于英文参赛论文。最终排版按当前标准保证缩放后的图例和说明不少于9 pt、主标签10–11 pt；25城长图宜占半页至整页，不建议挤进小双栏。

[LaTeX 插入片段](figure_inserts.tex)仅作为备选，尚未接入正文。原论文裁剪图只作为研究参考，不直接充当本队原创结果。图表输入来自本仓库归档分析，本轮只重绘，未重新核验外部数据或重新计算完整模型。

复现：安装 pymupdf、matplotlib、pandas、Pillow 后运行本目录 extract_reference.py、curate_reference.py、draw_figures.py。extract_reference.py 会生成约130MB的可再生图页缓存；无需为了使用六张新图将整个缓存上传 Overleaf。
