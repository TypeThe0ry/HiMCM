## 六张新版的使用

1. **01_framework**：仿14995的四分区结构，显示四项基准代理、TOPSIS、空间效用与低尾、两个不同实验。图中结果属于当前研究版本，团队尚未冻结指标时不能称为最终方案。
2. **02_spatial_access**：Copenhagen、Toronto、Dubai真实存档六边形网格，统一效用色标，三幅图各有比例尺。三个案例分别说明榜首稳定、排名上升、排名下降；不是随机或代表性抽样。空间图是新绘制的，不是原获奖图的换标签版本。
3. **03_access_mechanism**：人口加权累积分布、均值/低尾/综合效用、低尾权重作用。三种城市在线图中始终使用藏蓝/金黄/玫红；柱图用另一套浅色编码三个统计量，避免混淆。
4. **04_city_ranking**：完整25城排名与三个阶段的名次。没有为美观删去不利或低排名城市。右图点的轻微纵向错位只帮助区分阶段，没有数值意义。
5. **05_evidence_uncertainty**：所有25城的前后可行区间、可能冠军12→3、代理误差压力。新增观察前后权重保持不变，区间不是置信区间。
6. **06_indicator_matrix**：把原来的竖长矩阵改为横向五行，保留25城。适合横向附录；普通竖版正文不建议缩得太小。

前三张更适合建立论文视觉风格；04、05承担主结论。每张都有可编辑SVG、矢量PDF、300 dpi PNG。图内注释精简，解释与边界保存在 figure_manifest.json、展示页和 LaTeX 图注。

## 数据与验证

- 原图出处、裁剪坐标：style_selection.json；保留原水印。
- 新图对应数据和图注：figure_manifest.json。
- 三城空间原始ZIP的SHA256、网格数与重算结果：spatial_checks.json。
- 全部绘图输入的SHA256：input_provenance.json。
- 三城效用按 u=exp(-t/30) 计算；以保留网格人口加权。最低20%包含分位边界处的部分人口权重，计算结果与现有分析CSV一致。
- 空间面板显示范围不同；比例尺使用局部经纬度近似转换。空白表示不在保留的正人口网格内，不能直接解释为水域或设施缺失。
- 图中的“学习设施可达性”是全年龄居民的模型代理，不是高中质量、入学资格或学生真实通学时间。三城空间数据没有非正/无效时间；原25城中的缺口仍以原分析的区间处理。
- 当前改图不重跑完整排名模型，也不重新核验外部网站。不得将重绘本身描述为新增教学质量证据。

已视觉检查六张新版，修正了排名图图例与标题重叠、最低分城市区间被坐标范围裁切、地图统计标签覆盖网格等问题。检查完整25城、区间嵌套、可能冠军数量、PDF页数与本地链接。审美是否达到你的偏好仍以实际图为准，不承诺客观“超过获奖图”。

## 复现与插入

安装 numpy、pandas、matplotlib、pymupdf、Pillow。依次运行 redraw.py、build_stylebook.py、package_and_check.py。survey.py仅用于重建筛选联系表。当前版本字体使用本机 Times New Roman；在其他平台复现需安装该字体或选相近衬线字体。PDF已嵌入字体，SVG文字在编辑环境需有对应字体。

压缩包内有 figures/、figure_inserts.tex、CAPTIONS.md；上传到 Overleaf 后按需要引用，不自动改正文。原图摘录、参考图库和研究脚本不放进论文上传包。
