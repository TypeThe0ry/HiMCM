# Jakarta MA 2025/26：补充宗教高中范围

官方BPS省级表的索引正文列出100所MA、24,672名学生和2,008名校长及教师；全国表中的DKI Jakarta行一致。六个行政区的公私立分项分别加总吻合。统计为2025/26学年上学期EMIS，截至2025年12月31日；表页更新时间为2026年2月26日。

标题包含校长与教师，数值列仍沿用Guru标签，因此2,008不能直接当作纯教师人数或教学FTE。将MA纳入高中范围时，须保留教师角色分配的未识别部分。其截止日比SMA/SMK的11月30日迟一个月，合并只能解释为同学年分项目报告，不能声称同日普查。
