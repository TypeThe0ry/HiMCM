# 印度NHTS2025–26：取得官方原件，未准入高中通学值

官方MoSPI于2026-10-05发布首轮National Household Travel Survey事实表，调查期2025-07至2026-06。本目录下载并归档官方factsheet与正式调查表（Schedule NHTS25，收录于Volume II），原件哈希、大小和URL见manifest.json；TXT为pdftotext派生。

## 学段识别的实际限制

正式NHTS25 Block3第6列记录**最高已完成教育程度**，不是当前年级。第8列Current Weekly Status=4仅识别学生；第9列是否远程/函授学习区分线下，仍没有当前高中学段。不能用年龄或已完成secondary推断所有人正在读高中。

Block5.1确实记录到教育机构单程平均分钟、返程平均分钟及是否在过去90个travel-days实际到过校，但此变量能力不能弥补高中群体识别缺口。

## 覆盖与公开汇总限制

事实表印刷p5（教育段落）说明只统计1公里及以上教育旅程，6岁以上学生，90个travel-days参考期；小于1公里的行程没有作为travel记录。公开年龄组为6–14、15–29及6岁以上。Appendix A表10是各State/UT全体6岁以上学生通学时长分布，不是高中生分布。Delhi州/UT也不能直接与Mumbai城市作同口径比较。

因此不能把全国87.6%在30分钟内到校或全国平均23分钟填入Delhi/Mumbai高中生通学。即使获得更细年龄微数据，还需承认当前学段未直接观察及短途未覆盖；本轮新增可准入观测0，两城未知区间不变。
