# V8 新用户数据准入审计

只读 `../city_matrix_25_audit/` 与 `../homicide_2023_secondary_ratio_updated/`，没有修改或覆盖原文件。`input_snapshot.json`记录本轮读取文件的SHA256，`audit_intake.py`离线复算审计；国家数据目录9份原始来源哈希全部核验通过。

## 结论

**这两组输入本轮没有新增可直接缩小既有25城高中生模型区间的观测。** 这不表示数据无用：国家比较资料、城市价格新版情景和错误定位都已保留，但不以扩大代理范围制造冠军集合收缩。

- 新用户城市矩阵共250格，48格非空、202格空白；`matrix_cell_audit.csv`逐格说明是否准入及原因。
- 两套25城只有9城重合：Lagos、London、Mexico City、Mumbai、New York、Sao Paulo、Shanghai、Singapore、Tokyo。另16城不是当前固定候选集合。本轮不自行换城市或删除旧城。
- 未发现真实高中生通学新观测。London和Tokyo的t10都是10公里汽车时间，不能替代学生到实际就读地点的通学时间。
- Tokyo原表15.22来自初中313,944/20,622；同一官方表高中为302,411/19,325=15.6486934，已在V5。因此纠错有效，但没有新增独立信息。
- 国家表217行各两项共434个单元另有`country_cell_audit.csv`。教育量为ISCED2+3总体中等教育，即使学生与教师同国同年也不是城市高中。国家凶杀率也不能填城市；Singapore城市国家例外，但2023的0.0690954942050905与V5已用值完全相同。
- Singapore官方PTR API明确Series为Secondary School，2023=12.0、2024=12.2；不能用其覆盖V5的Pre-U匹配高中子群。原矩阵12.7的doc标注也未提供同高中学段分子分母。
- Tokyo“杀人”案件率缺少死亡者与未遂区别核验；不当故意凶杀死亡率。外部城市的泳池、宽带等doc点检同样不自动入主模型。

## 价格版次问题与可用派生

原矩阵标成Numbeo2026，但对照其已经归档的**2026固定版**HTML，30个价格单元数值不一致。不能把未标明的当前版、中期版、旧版混写成年初2026固定版；原目录其他工作可能继续核对版次，本审计不覆盖它们。

`price_2026_separate_scenario.csv`从两份固定2026版归档重新提取当前固定25城的CLI与PIR，按原V5的完整城市来源字符串精确匹配，50格中48格有值，剩余保持空白。它是**独立年份情景输入**，`main_admit=False`。主模型已有2025价格不是“缺失”，不能将两个年份简单交集，也不应只替换有利于某城市的少数价格。若主任务开展2026价格情景，应整套替换并显式说明时间变化。
