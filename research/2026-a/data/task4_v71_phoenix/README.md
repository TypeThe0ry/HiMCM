# Phoenix：高中公交优先级研究的时间数字不是通学观测

新取得[Valley Metro官方StoryMap](https://storymaps.arcgis.com/stories/067e3f9d1c974d418f1ccdf06b1044c1)的原始JSON及项目、组织元信息。所有者和组织均为Valley Metro，组织资料链接其官方网站；创建于2022-03-17，修改于2022-05-03（UTC）。[manifest](manifest.json)保存原响应、URL与哈希。

该研究选择六个学区的41所公立高中，以2019 ACS社区人口、贫困、车辆拥有情况及公交站点／服务里程等九项指标确定免费乘车项目优先级。这里的学校数量和学生规模是研究范围，不是回答旅时问卷的样本量。

“Benefits of youth ridership”段落以每天去程10分钟、回程10分钟、180天算出家庭每年节省60小时。这是利益算例，没有学生回答记录、调查旅时分布或该数字的样本分母；不能把10分钟当作Phoenix高中生平均单程时长。整个地区还包含其他城市和学区，不能直接作为Phoenix市域总体。

本轮按任务搜索了学区气候／需求／交通调查及相关资料，没有取得可准入的高中生通学联合记录。新归档研究是一个可复核的排除证据；未改变Phoenix通学区间，也未以其公交供给评分替换实际通学。原始资料中的后续联系建议属于来源内容，没有据此联系任何机构。

运行 `python3 research/2026-a/data/task4_v71_phoenix/audit.py` 核验来源、范围与相关原文。此脚本验证归档内容及主张出处，不声称穷尽所有公开数据。
