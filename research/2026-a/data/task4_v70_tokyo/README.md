## 60名专攻科学生阻止使用全部17983作为本科师资下界

新取得的学年表`grade_students2025.xlsx / 135(8-1) / row23`报告Tokyo学生总303528，其中本科303468、专攻科60、别科0。原模型分母只取本科，但岗位人数是整类学校人数，因此只做岗位筛选还不足以证明17983全部属于高中本科。

同表国立／公立分表的专攻科与别科均为0，60人全部来自私立全日制。新市町村表`municipal_students2025.xlsx / 東京都`的所有市区町村行加总核验60人全部在江戸川区，别科总数为0。该区私立岗位表`municipal_private_roles2025.xlsx / 東京都 / row28`的选定岗位为1+1+127+0+37=166；该行全部本务人数175。两表通过江戸川区代码123对应，而非依靠行号相同。

令江戸川私立池内归属于本科的选定岗位量为G，保留G∈[0,166]。主条件计算将没有非本科在校生的其余学校池选定岗位解释为本科资源，得到普通高中岗位界[17983−166,17983]=[17817,17983]。这一学校池归属条件不证明每位教员实际授课的课程，也未排除零在校生专攻科可能保留岗位的情形。因此保留两项敏感性，不把主下界说成无条件实际本科授课人数。

- **更粗分配界**：只保留国立196+公立8587=8783作为普通高中基准，私立9200全部分配未知。此情景不依赖私立学校池按当前在校课程归属的较细判断。
- **只筛岗位情景**：用17983为普通高中基准，假定私立本科／专攻科的岗位混用不影响分母匹配。这是更强假设对照，不能取代主界。

## 与既有学生覆盖组合

学生数继续采用[V69经原件复算的界](../task4_v69_tokyo/README.md)N∈[312711,312920]，不增删学生、不与旧效用界相交。六年制后期岗位H∈[0,515]，特教高中本科岗位K∈[0,6680]仍未知：

$$T=17817+G+H+K\in[17817,25178],$$
$$u_E=\frac{15T}{N+15T}\in[0.460645494894,0.547045761688].$$

更粗分配情景T∈[8783,25178]对应效用[0.296279221436,0.547045761688]；只筛岗位情景T∈[17983,25178]对应[0.462950408897,0.547045761688]。这些是不同归属条件下的资源外包，不是概率分布或置信区间。混合学校教师任教学段、兼职工时、未覆盖学校类别与14—18岁筛选仍未解决。岗位筛选改善统计口径可比性，不证明各国岗位职责完全相同或教育质量提高。

`extract.py`验证9份本轮原件哈希，读取岗位标签而非按列序猜含义，核验三个总数、岗位加总、国公私立分解、私立专攻科60与地域唯一性，再调用V69源提取复算原学生界。输出[summary.json](summary.json)保留每个岗位的原单元格、主界与两个敏感性界。
