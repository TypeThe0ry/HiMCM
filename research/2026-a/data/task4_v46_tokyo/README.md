## 大学资源提供有依据的下界，尚无完整高教上界

官方大学参考表`gk25qvc0311.csv`报告143所大学：国立11、公立2、私立130。表内注1明确学校数按**大学总部所在地**统计；注2明确学生数按学部／研究科所在地统计。因此不把143称为全城实际教学点数，不用其学生数证明总部校园容量。

同一时点東京都官方人口发布页报告2025-05-01人口14,254,039，为2025-05-28发布、以2020人口普查为基期的估计。此处保留原发布口径，未声称这是后来人口普查重估后的最新数值。大学总部密度为`143/14254039×100000=1.0032244194`所／10万人。

若高教资源指标接受“认可大学总部所在地”作为独立机构定位依据，则143个大学提供部分已确认机构数，高教效用条件下界为`0.5008048073`，上界仍1。人口估计外推和总部位置规则是该下界解释的条件。它不是覆盖所有高中生可实际入读大学的保证。

另保存官方短期大学32所、高等专门学校3所、专修学校383所的原始表用于范围审核。本轮不直接把它们相加：专修学校同时包含不同入学层级的课程；全部校址、总部与独立机构去重尚未统一。大学表不是完整高教机构清单，不能把143当全体机构上限，也不将这几个表相加宣称穷尽所有高教类型。
