# Istanbul safety follow-up: no new admissible bound

The new 2025 Crime Incident Database for Turkey provides a distinct source check, but its Istanbul press-documented count is 186 deaths, below the 307 police-jurisdiction deaths already used in V7. It cannot tighten the existing lower count. The methodology reports only 61% coverage against those 307 deaths. It describes a model-based national coverage correction, which is not a measured Istanbul upper bound. Both aggregate pages are preserved byte-for-byte with SHA256 and URL in manifest.json; no individual incident records were downloaded.

The existing main safety utility [0,0.5064951825] remains unchanged. Neither counts from different overlapping sources nor modeled coverage corrections were added to the police count.

Other bounded checks on 2026-11-08 found national 2025 homicide figures expressed as incidents rather than death victims; these cannot bound the number of victims from above. The Jandarma 2025 public statistics route exposed traffic statistics, not a new Istanbul intentional-death total. TUIK death statistics describe residents and vital registration, whereas the current Istanbul indicator uses provincial crime events; their counts cannot be intersected without matching the population/event universe. No successful raw TUIK table was obtained, and a JS shell was not archived as data.

Education follow-up did not establish a complete 2025/26 Istanbul list of vocational middle-school campuses or corresponding teacher allocation. New MEB feedback surveys are not teacher counts. The V53 educational interval therefore remains unchanged.

This package records a new aggregate-source rejection and independently reviews the facilities source in facilities_crossaudit.json. It contains no model admission and does not establish an upper limit for unreported homicide.
