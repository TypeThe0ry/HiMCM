## Zurich：既遂行为不是受害者人数

PKS2025原PDF第117页标题“5.1.26 Stadt Zürich gesamt”，2021–2025列中的既遂分别3、4、4、1、2，未遂14、14、18、17、20。因此2024的既遂行为数为1、2025为2。第118页定义Straftat为可区分的犯罪行为，独立于受害人数；受害人另统计。第120页保留地点／计数方法。实际表头、年份列及单位定义共同定位，不用目录或搜索片段代替原表。

用户2024点率0.14与numerator1保持。原件提供的是注册行为数，不直接认证其受害者率；原率的人口分母／统计口径仍未建立。不能以行为数除原2025人口440935制造“校正后同年受害者率”，也不以1→2推断未来趋势。独立敏感性只撤回点utility的信息，保留其他格及所有补充。
