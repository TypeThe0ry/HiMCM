# Vienna pupil–teacher ratio: bounded source check

No official source checked here establishes the original Vienna 9.4 value or its provenance. The intake CSV records 9.4, year 2023 and flag `ok`, without an original URL. A different national value does not establish that the city entry is wrong.

Eurostat dataset `educ_uoe_perp04` reports **9.8** for Austria, 2023, upper secondary (ISCED 2011 `ED3`), and **10.3** for primary and secondary combined (`ED1-3`). The raw JSON response specifies `freq=A`, `unit=RT`, `geo=AT`, `time=2023`; the category index gives `ED3=7`, `ED1-3=3`, which locate the values. None of the returned Austria 2023 categories has value 9.4. Eurostat's accompanying news article states that its 2023 primary and secondary pupil–teacher ratios use full-time equivalents for both pupils and teachers. These are national values, not Vienna city validation. The year is the provider's data label; this check did not establish the corresponding school year. Austria's UOE metadata explains the general t/t+1 reference convention, which alone does not establish the year mapping for this observation.

The official Vienna schools page returned HTTP 403 to the direct request; its saved response is the error response, not the source table. Statistics Austria's *Bildung in Zahlen 2023/2024*, section 4.1, figures 6–7, presents national ratios for reference year 2022; its PDF download did not complete and is not used to validate the entry. `receipts.json` records direct requests and the incomplete download. `scope.json` gives machine-readable scope and match status. An exact numerical match, if later found, would not itself establish the original CSV's lineage.
