# Warsaw真实高中学生人数与教师分母界

官方《Statistical Yearbook of Warsaw 2024》给出2023/24学年普通高中青年学校学生87999人、成人学校学生5773人；两者合计93772。普通高中教师6079 FTE包含青年与成人学校，不能把93772/6079或87999/6079当成青年高中师生比点值。

本目录保留真实青年高中分子，利用教师集合包含关系构造单侧界。为整FTE发布精度预留1 FTE（覆盖截断或四舍五入），假设青年教师FTE不超过全部普通高中教师：

$$0<T_y\le6080,\qquad PTR_y=87999/T_y\ge87999/6080=14.47351974.$$

成本效用为15/(15+PTR)，故效用界为[0,0.5089314114]；青年教师分配未知，保留下界0。1 FTE为发布精度保护，不是额外观察；若发布值误差超出1 FTE，该界需重新核验。

范围为Warsaw市内普通高中青年学校（含特殊教育），不包括成人高中、技术及职业教育路线，也不限定实际年龄14–18。该范围是一般高中条件情景，不能宣布覆盖所有高中教育。师生比衡量师资配置，不能替代考试成绩或教育因果质量。`main_admitted=false`。
