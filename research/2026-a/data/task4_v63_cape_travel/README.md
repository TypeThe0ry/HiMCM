# Cape Town：GHS2025真实高中生通学

从Stats SA官方已认证浏览器下载2025年原始微观数据、字典和问卷，见[原件与哈希](manifest.json)。没有使用全年龄劳动者通勤代理，也没有在时长分箱内填中点。

PERSON2025.csv共67748名个人，Cape Town（metro_code=2）3953人。限定14—18岁、目前就读formal school、非远程、当前10—12年级后，目标为182人、171户、120个目标PSU；年龄与学段资格全部可识别，未知时长0。时长五箱人数依次82、68、25、5、2，原题为通常从家到学校单程、含全部通常交通方式。

效用exp(−t/30)的加权样本识别区间为[0.4271795264,0.7294728319]。使用全部城市样本的216个PSU、14层（包括没有目标学生的PSU），比率线性化与两个端点Bonferroni区间给出近似抽样包络[0.3922371575,0.7798278718]，自由度202。时长区间用[0,15]、[15,30]、[30,60]、[60,90]、[90,∞)的保守闭包，未知时间仍按[0,1]处理。

2025原字典仍说明2013主样本、两阶段分层PPS设计；不能沿用2023的PSU数或标准误。程序检查相关层没有其他metro记录、PSU只属于一个层、所有权重正，且每层至少两个PSU。校准权重视为固定，未加入有限总体校正、校准估计或抽样框外学生；源文件排除无法加权记录、学生宿舍等覆盖限制见独立审计。包络不是精确置信集，也不提供250指标联合覆盖保证。

2023与2025为不同年份调查，不把两年区间取交集，也不宣称同一批学生的因果变化。旧原件与结果保留用于时间敏感性对照。
