# V59：Dhaka普通高中阶段的市级计数界

原始[BANBEIS Bangladesh Education Statistics 2025](../task4_v59_secondary_sources/bangladesh_education2025.pdf)的表4.1.10（PDF215页、印刷182页）明确列出Dhaka City Corporation，而非Dhaka全区或全分区。市级334所学院共426900名学生、12016个公布教师角色；这些总数包含高等教育，不能直接计算高中师生比。

| 学院类型 | 学生 | 公布教师角色 |
| --- | ---: | ---: |
| School and College的学院部 | 103904 | 4837 |
| Higher Secondary College | 37191 | 2238 |
| Degree Pass | 12965 | 396 |
| Degree Honors | 36057 | 967 |
| Masters | 236783 | 3578 |

表4.3.3（PDF297页、印刷264页）进一步说明：全国School and College学院部402723名学生中，401970为高中、152为Degree Pass、601为Honors。因此该类别在Dhaka可能混入的非高中生最多753人。Higher Secondary College类别在该表全部属于高中阶段。用全国同类别计数作上限可得

$$N_L=37191+\max(0,103904-753)=140342,\qquad N_U=426900.$$

教师不能随学生比例分摊。跨阶段学院的教师归属保持未知。表4.4.2（PDF304页、印刷271页）显示全国纯高中学院有1195名校长、78名副校长，这两类角色在Dhaka至多1273。因此不要求全部管理角色提供教学，也能给出

$$T_L=\max(0,2238-1195-78)=965,\qquad T_U=12016.$$

这里全国数据承担的是城市子集合的**污染人数上限**，不是城市均值或城市观测。其余教师角色包括讲师、示范教师及图书信息教师等，不能解释为全部课堂教师、唯一授课人数或FTE。角色和阶段端点未必同时可实现，当前界是保守包络。

地域采用原表的Dhaka City Corporation标签，尚未独立对齐南北两市的边界；范围为表列学院中的普通高中11—12年级，不含全体14—18岁居民、宗教及技术教育的完整总体。报告和表标题标2025，方法页却印2024-10-20至2024-11-21采集日期，这个日期矛盾尚未消除；结果按该版报告条件分析，不称已核验的2025同日普查。

`extract.py`从原PDF抽取市级和全国表格，校验总计、阶段分类、角色列及哈希；关键市级页另经图像核对。[独立审计](../task4_v59_dhaka_review/README.md)指出并纠正了把学院部全部当高中阶段的错误。[模型与排名结果](../../results/task4_v59_dhaka_stage/README.md)。
