# Phoenix：October 1统计准入条件核查

新增官方说明明确区分学校提交记录与最终计入人数。ADE的FY2026资助申请说明（2025年1月2日修订，第5页）要求使用通过校验的学校October 1人数；提交记录中可能包含被其他单位计数或未通过数据校验的学生。FY2025备忘录（2024年6月10日，第1页）明确统计日期为2024年10月1日，使用通过AzEDS校验的数据，提交截止日为2024年12月11日。

这些资料支持保留V50的包含关系条件，尚不能证明Hope的目标学生全部纳入SAFR的学区去重总数。尤其不能把学校提交记录总量与最终计入人数混用。官方学校人数本身也经过去重；本次没有断言NCES记录必然跨校重复。需要核实的是Hope学校统计与SAFR学区统计的具体归属及校验结果是否一致。

因此，1180人的学区上界仍是条件情景，不升级为无条件Phoenix教育界；现有模型输入不变。物理及线上学生的目标子集映射也未得到新证据。
