# 队友城市表独立核验

本表16城、45列、11项指标；当前模型25城、10项指标。重合城市仅London、Warsaw、Singapore、Tokyo。其余12城可作为扩展研究材料，不自动换入既定候选集。原件未修改；脚本读原样副本并校验运行前后SHA-256。

## 可以使用的内容

原始城市名称、年份、计数和风险flag可作为检索线索。16行的indicators_present及按现有flag推算的usable_present均算术一致；后者只是标签计数，不代表已经达到模型准入条件。16城高教密度均与给定高校数/人口在显示精度内一致；接入模型的每10万人尺度需把he_per_million除以10。

## 需要补来源和分母

23组凶杀或泳池密度无法用本表分子/人口复算到显示精度（逐项见issues.csv）。这不必然是源数据算错，也可能原率采用不同年份或地理分母；表中没有给出这些分母。不能直接把重算结果当作已校正真值。例：Paris115/2103778×100000=5.466，表值1.11；泳池339/2103778×100000=16.114，表值3.27。

全部数值缺原始URL、表号/行列及提取规则。CLI/PIR须核验同一发布版次；PM2.5标为MODELLED须说明模型和空间聚合；高教计数须核验独立机构资格及地理；泳池须去除池槽重复并确认公开可用；宽带须核验固定网络中位数。2026值不能伪装2025观测，旧年份替代也须保留时间差。

## 不可直接映射

- transit_share_pct是方式分担率，不是公共交通物理站点密度。
- commute_min没有当前高中生单程时长分布，不能替换学生通学效用。
- early_leavers_pct不是当前十指标之一，也不是学生/教师比。
- Tokyo人口口径为23区，与当前Tokyo-to目标不一致，不能混配都域分子。
- Singapore宽带667.71已被现有V100原始Ookla字段核验为fixedMean；该组fixedMedian为476.02。城市国家采用全国统计的地理问题与均值/中位数问题要分开。

## PTR真实来源核验

**Tokyo15.22确认为初中指标。** 日本统计局《統計でみる都道府県のすがた2026》PDF62页/印刷38页、FY2024Tokyo-to行：小学16.79、初中15.22、高中15.65。原始PDF已归档；高中15.65是正确阶段的可核验候选，仍需核验教师分母及学校覆盖，并与现有模型定义比较。不能只在队友原表中替换数值后直接提交。
