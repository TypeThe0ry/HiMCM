# Melbourne：实际中学生通学日记与未观察人群

V23已保存维多利亚州交通与规划部门的 VISTA 2024–25 官方人员、家庭、教育行程及2026年说明书。本轮核对哈希并复用这些原件，新增实际Stops停靠记录，用以核验教育旅程的具体终点。原件、下载URL与SHA256保存在[清单](manifest.json)，字段字典保存在完整官方[目录响应](catalog.json)。这批资料同时识别当前`studying=Secondary`、居住地、行程起讫和时长。

## 可核验的人群

地域为ABS **Greater Melbourne**，不是仅Melbourne市政府辖区。工作日调查包含322名当前中学生；其中205人有208条从家到教育地点的日记行程。按人选择首次出发，避免同一人多次到校得到重复权重。117人当天没有这类行程；其中5人拒绝完成日记，全部人员权重缺失。这些人不能填入零分钟或分配一个猜测权重。

公开年龄仅有五岁组。15—19岁当前中学生共171人，其中107人记录了教育行程、64人没有；1名无行程者缺少人员权重。精确14—18岁及高中年级无法从这些公开变量恢复。因此以下是**15—19岁中学生的条件诊断**，它不能作为已识别精确14—18岁人群的证明；V23既有的条件口径保持明确。

## 识别通学终点和总耗时

教育行程表示从最后离家到第一次教育地点到达的完整链。首次行程205人中，190人终点明确为`Secondary School`；另15人的终点类别为School NEC、Primary、Tertiary或Bus Stop。尽管其人员表显示当前就读中学，不能把这些终点都当成已验证的中学旅程。因此这15人的通学效用保留[0,1]。15—19岁组对应100个明确终点、7个未明确终点。

主计算采用`journey_elapsed_time=end_time−start_time`，包括换乘等待及途中停留；`journey_travel_time`为各段移动时间，另作敏感性对照。两者都来自日记原记录。转换为效用u=exp(−t/30)，不对分钟数先取平均再转换。

最后两行把没有记录行程的人保留为[0,1]，对应需要估计其通常通学负担的条件分析，不声称他们当天实际通学。五名缺权重者不进入加权分母；若要求覆盖全部人员且其权重无界，严格效用区间仍为[0,1]。15—19岁组同理保留一名缺权重者，不能用170人的窄区间替代完整171人的无条件界。

只计移动时间时，15—19岁有权重全体的识别区间为[0.339490,0.741515]，抽样包络[0.254694, 0.796449]。与完整耗时配对后，识别区间两端均下降约0.01066，揭示漏算中间等待会高估便利度；人数、权重和未知成员处理完全相同。

## 加权与复现

目标是人的首次旅程效用，使用人员表的`perspoststratweight`及10组公开人员jackknife权重。不能把教育行程单一权重与人员重复权重混搭。工作日的7/5权重缩放在加权均值中抵消。

说明书第8页给出logit变换下的jackknife方差 `(R−1)/R Σ(λ_r−λ)²`，R=10，原文临界值约2.26；代码使用精确t(9,0.975)=2.262157。本计算将同一公式用于[0,1]效用端点均值，保存各重复估计和端点区间，再取下端点区间下限、上端点区间上限。同时保留V23采用的线性尺度jackknife包络`linear_sampling_envelope`，以分开终点审计与推断变换的影响。该近似包络不是所有城市与全部场景同时覆盖的置信保证。

[extract.py](extract.py)核对全部原件哈希、人员及停靠键唯一性、跨表匹配、地域一致和完整时间差，输出[首次行程](first_weekday_journeys.csv)及[摘要](summary.json)。在仓库根目录运行：

```sh
python3 research/2026-a/data/task4_v44_melbourne/extract.py
```

资料支持实际中学生通学的条件分析；年龄、地域、缺权重和缺行程问题均保留，不自动写入主模型或论文。

本轮实质修订为终点验证：V23将107名15—19岁中学生的首次教育行程全部视为已知通学；本轮有7个终点无法确认为中学，故回到未知效用。固定V23线性jackknife算法时，新全名册包络为[0.239800,0.792787]，可与V23的[0.278896,0.781095]作同方法对照。完整耗时在V23已采用，移动时间比较属于新增诊断，不能宣传成首次纠正旧模型漏算等待。
