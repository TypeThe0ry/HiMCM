# 职业路径与设施可达性：瑞士学徒的一手辅助证据

EHB 两份官方报告提供了从设施供给转向实际选择范围的可核查案例。2024 年报告按居住与企业所在地及公共交通时间矩阵近似通勤，企业单程均值约 39 分钟；职业学校单程约 46 分钟。后者使用最快可达的合格学校、并优先本州学校进行分配，并非每位学徒实际就读学校。2026 年报告进一步以假设的 60 分钟交通范围构造搜索空间。两者说明目的地资格、交通联系及人群范围为何需要独立于城市设施数量记录；没有测量 Zurich 城内学生资源公平性。

原件为 EHB [2024 年报告页面](https://www.ehb.swiss/news/mobilitaetsmuster-von-lernenden-der-dualen-beruflichen-grundbildung)及其12页报告、[2026 年报告页面](https://www.ehb.swiss/news/der-wohnort-beeinflusst-den-zugang-zu-lehrstellen)及其16页报告。四份 HTTP200 原响应保存在本目录，精确 URL、UTC、长度和 SHA256 见 `retrievals.json`。报告作者为 Andreas Kuhn、Jürg Schweri；分别为 OBS EHB Trend im Fokus 13 和 15。报告出版年份与底层2021/22学徒数据年份分开记录。未取得底层个人记录或作者交通矩阵，不能声称重现其原始链接分析。

## 使用范围

- 2024 报告第3页：原始188,284人，剔除地点缺失后184,964个关系，再按青年界定保留174,868个学徒关系。全日制学校路径不在该双元学徒范围内。该页同时写入学时至多25岁与从25岁起成人；2026第4页写入学时不大于25岁，第5页起点规则写居住有25岁以下学徒。保存原文差异，不自行统一边界，也不推成14岁与18岁的精确比较。
- 2024第5—7页：两类通勤来自市镇间公共交通平均时间与学校估配。约85%／77%在60分钟以下；约1.4%／2.1%超过120分钟。图未展示超过120分钟的尾部，不能将横轴截断用作最大旅时或确定支持上界。
- 2026第4—7页：搜索范围基于已签订的2021/22双元学徒关系及假设60分钟公共交通可达性；没有未填补岗位的信息，因此合同数不是当前可申请空缺数。Olten与Brusio的搜索范围分别覆盖242／2个市镇、12,704／24家企业、49,484／38份已填补关系及227／18种职业。
- 2026第7页：84%的搜索空间能覆盖100种以上职业，与4.4%的青年学徒居住在100种以下职业的范围内，分母不同；不能将市镇等权比例当学生人口比例。

本包保留16条带页码、单位及资格条件的公布指标。全国或其他市镇的通勤／搜索范围不匹配 Zurich 的2024 greater-city工作旅时39.9分钟，不能转移到主矩阵或把2021/22重新标注为2025。新主模型准入和实际主区间收窄均为0，原CSV、V204与论文保持。
