# Phoenix：学校运输系统新线索

本轮核实PXU学校在2025年7月24日发布的[新校车系统通知](https://www.pxu.org/o/cchs/article/2323171)：家庭通过My Ride K-12登记运输服务，连接具体学生后可查看分配路线和实时到站信息。该公开通知没有学生实际旅时分布、作答分母或Phoenix居民筛选，因此不改变通学效用[0,1]。

原始公开HTML已下载，字节数及SHA256见[清单](manifest.json)。它说明可能存在有用的运营信息渠道，不证明该系统已公开可用于全市推断的旅行记录。校车用户也不覆盖步行、家庭接送、公共交通等所有学生。

此次仅阅读公开通知；未注册、连接学生、提交表单或联系机构。若以后取得按高中阶段、地域和覆盖范围定义的去标识汇总，才可评估准入；不能把线路或预计到站时间直接当作完整家到校实际时长。

同时检索PXU学生调查及公开报告，未找到新的旅时与目标分母联合表。未重试已有MAG/NHTS受限路径或采购项目；ACS工作通勤、未来服务要求、全国K12和员工调查继续排除。有限检索记录见[audit.json](audit.json)，不宣称全网无可用资料。模型和论文未修改。
