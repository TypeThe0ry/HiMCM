# Toronto：新增高中学校通学调查线索

取得Forest Hill Collegiate Institute的2016/17学校通学计划摘要原件（1,162,167字节），由调查项目运营方Ontario Active School Travel / Green Communities Canada发布。PDF第2页记录June2016和March2017两轮学生调查，第8页说明从该校各年级抽取班级调查。它提供实际高中在读者的通学调查证据，但不代表Toronto全市。

[TDSB完整版](https://schoolweb.tdsb.on.ca/Portals/foresthill/docs/Forest%20Hill%20CI-%20School%20Travel%20Plan%20FINAL.pdf)的搜索索引第26页显示单程时间分箱：<10分钟42%、11—20分钟29%、21—30分钟16%、>30分钟13%。这四个百分数仅保存在明确标记的`index_transcription.json`；完整版当前返回HTTP200的IIS404.1 HTML，未取得原PDF，不能将索引转录当原始归档。已取得的摘要没有这张时间分箱表，亦未给出该问题的作答人数。

原件、访问响应与SHA256见`manifest.json`。摘要来自[项目运营方下载](https://ontarioactiveschooltravel.ca/wp-content/uploads/2018/05/Forest-Hill-CI-School-Travel-Plan.pdf)，学校板块的[项目样例页](https://ontarioactiveschooltravel.ca/sample-school-travel-plans/)列出此报告。它是项目方原始报告，非全市官方概率调查。

## 准入结论

保留为历史单校真实学生通学资料和后续完整版获取线索，当前不进入Toronto城市评分。尚缺时间题实际分母、年龄14—18筛选、居民地域、调查权重、非应答及学校对全市目标总体的覆盖。即便恢复完整版，也不能直接把四个百分数赋给全市高中生。未计算城市效用界或修改现有缺失区间。

本轮避开已审计的2022TTS同类公开汇总；该汇总缺高中身份×旅时联合记录。London检索到LTDS学校阶段请求及一般居民报告，未取得新的高中×实际旅时城市表，不再归档重复泛化资料。
