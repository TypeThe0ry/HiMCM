# Singapore泳池：取得完整发布文件，尚无当前公共场所上界

下载了Sport Singapore的2024全国体育设施普查公开CSV，并核对实际文件与发布页内嵌统计：本次快照为16,595行，其中Swimming Pool为3,533行。搜索摘要中的16,597／3,532属于不同快照，未沿用。原件及来源哈希见[manifest.json](manifest.json)，公开下载接口返回的临时签名查询参数未保存；[download_route.json](download_route.json)记录不含临时凭据的路径。

这是完整发布文件，不是完整公共泳池名录。其五列仅有名称、邮编、经纬度与设施类别，没有公众准入、运营状态或全年开放标识。实际含公寓、酒店、学校和其他私人场所；一场所也可能有多行泳池。3,533行去重完整字段为2,114组、名称邮编组合为2,111组、经纬度组合为1,666组，均不能直接当公开场所数量；坐标仅保留约三位小数，合并坐标会把相邻地点混为一处。

在“目标场所均进入该普查且每处至少对应一行泳池”的条件下，3,533可作为**该枚举框内**公开场所数的宽松上界。尚未取得漏报覆盖评估、2024以后新增／退出记录或当前全年开放名录，因此不把它认证为2026年全新加坡的硬上界，也不修改模型区间。下一步可用此表逐场所核验公众准入和年份，不能先把公寓记录全数计入公共设施。

另核查官方许可路径：2021-08-03 MCCY议会答复给出约2,700个获许可泳池及27个ActiveSG泳池，这是历史近似量，不能充当2026年的精确上限。NEA 2025-04-21 FAQ说明住宅内水上设施无需许可，许可类别还包含水上游乐及水疗池，且许可可按共用循环系统计。没有取得当前完整许可登记表，许可数量与公开场所数量也不应直接等同。NEA五页FAQ已下载并校验为PDF原件；MCCY历史数字来自明确标识的网页工具摘录，见[许可审计](licensing_web_audit.json)。

运行`python3 research/2026-a/data/task4_v46_singapore_pools/extract.py`可验证三个原件哈希、抽取全部3,533条泳池记录并重建[汇总](summary.json)。本轮未改主模型或论文。
