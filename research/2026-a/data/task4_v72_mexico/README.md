# Mexico City：把通学年龄口径改为14—18岁

原有2020年普查记录可直接筛选报告年龄。将V23的3—17岁口径改为14—18岁后，条件性高中分类样本从7,655人增至9,217人；成员资格不明的可选样本从330人变为86人。通学效用区间由 **[0.284942, 0.557210]** 变为 **[0.283284, 0.543641]**。两端同时下降，不能把这次人群修正说成同一总体的信息精度提高。

原来已分类学生实际上都在14—17岁。新筛选补回1,562名18岁分类学生（展开人数51,677），并将已知年龄3—13岁者移出目标年龄群。未知年龄999仍作为可能成员保留；未知在读状态、教育阶段或已完成年级的宽泛可选规则保持不变。移除已知不属于目标年龄的人，不是人为收窄缺失区间。

## 高中学段仍为条件性重建

INEGI变量ASISTEN询问目前是否在读；NIVACAD和ESCOLARI记录**已完成**的层级和年级。字典明确要求在读者填上一已通过年级。因此，这里沿用原规则：当前在读且已完成初三，或在层级4、5、7完成0—2年，作为条件性高中分类。留级、转学、不同学制可能违反进阶假设。精确年龄筛选没有让当前高中学段变成直接观测，当前区间也没有覆盖该分类误差。

测量为2020年家庭成年人代答的通常直接家校时间，覆盖CDMX全部16个行政区的私人住户，不是2026年GPS行程。代码6（不出行）和9（时长不明）仍保留效用[0,1]。数据年份、疫情时点、家庭代答与抽样误差限制继续适用；此处是加权样本的时间分箱与成员资格识别区间，不是设计型置信区间。

## 计算与核验

对分类群体的总权重N、效用加权和端点A_L、A_U，以及可选成员权重w_r和效用端点a_r、b_r，沿用已验证的排序前缀算法计算：

`L=min_z (A_L+Σ z_r w_r a_r)/(N+Σ z_r w_r)`；
`U=max_z (A_U+Σ z_r w_r b_r)/(N+Σ z_r w_r)`，其中`z_r∈{0,1}`。
