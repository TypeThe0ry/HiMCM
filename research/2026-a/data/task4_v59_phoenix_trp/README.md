# V59 — Phoenix TRP数据存在行政填补，仍缺高中生时长

取得Maricopa官方2024年2月TRP手册原始PDF（1712944字节）。手册明确调查覆盖达到驾驶年龄、每周到校至少三天的学生；这不是全部14—18岁高中生。

新增关键发现是统计处罚规则：达不到回应要求时，部分缺失问卷会被按单人驾车、单程15英里、每周5天加入合规分析。这个默认值不是实测距离，更不能换算为学生通学分钟。后续取得汇总时必须区分实际回应与处罚填补。

手册的Summary Analysis由协调员通过邮件接收；Table VI列站点平均通勤距离和时间，但说明以员工为对象。本次未取得PXU或具体高中学生的该表、时长分布及回应分母。不能把示例表、员工时间或计划审批名单填入高中生通学格。没有发送邮件、申请数据或进入协调员后台。

另查[FY2025年报](https://www.maricopa.gov/DocumentCenter/View/110701/FY2025-TRP-Annual-Report?bidId=)：官方阅读器显示跨员工及学生的参与和方式统计，没有Phoenix高中时长交叉表。直接原件请求404，因此只留[阅读器核查记录](annual_report_reader_audit.json)，没有伪造PDF原件。

`audit.py`核验原始手册哈希、学生限制、处罚填补及汇总表定义。`manifest.json`区分成功原件与失败下载。新增可准入通学观测为0，Phoenix通学效用继续保留[0,1]；未修改模型或论文。

缺失的具体材料已定位为：高中站点的学生Summary Analysis／原始匿名时长分布，附实际回应分母、填补标记、年龄或年级与Phoenix居民/学校地理范围。即使取得站点均值，也应保留未覆盖学生的区间。
