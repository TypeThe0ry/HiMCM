# NYC：直接用已观察学生旅程重算时间尺度

本轮从官方 2010—2011 RHTS 原始 ZIP 重建 V21 名册、直接旅程和运输停靠链，再分别计算 `u=exp(-T/tau)`，tau 为 15、20、30、45、60 分钟。没有新增观测或更换人群，也没有把聚合后的均值直接取幂。

603 条名册记录、410 条已观察首个学校方向旅程和 193 条未知旅程全部保留。全年龄组为 476 名已知当前9—12年级学生、127 名可选成员；under19 条件组为 460 名已知成员、33 名可选成员。未知时长仍为 [0,1]，未知资格仍使用同一可选成员极值算法。

| tau（分钟） | under19 识别区间 | under19 探索性抽样包络 |
| --- | --- | --- |
| 15 | [0.122312,0.365000] | [0.101571,0.419441] |
| 20 | [0.171660,0.414801] | [0.146562,0.466231] |
| 30 | [0.255976,0.499566] | [0.223951,0.546644] |
| 45 | [0.349590,0.593361] | [0.312645,0.633610] |
| 60 | [0.415536,0.659194] | [0.375659,0.694236] |

每个尺度都复用 V21 的县内家庭 bootstrap：全部 5,766 个 NYC 样本家庭，包括没有高中生的家庭；1,000 次、种子 20261107、固定最终个人权重。相同抽样次数在各尺度一一对应，避免蒙特卡洛随机差异混入尺度比较。包络包含原样本识别界。这仍是探索性重采样，不是官方设计置信区间，也没有重新校准权重。

30 分钟结果与 V21 两个人群口径的四个端点逐项一致至 1e-12。重建名册的个人键、成员类型、年龄组、缺失原因、权重、时长和原效用均与归档 V21 校验；8 条运输链恢复与原规则一致。各尺度保持所有非效用字段及缺失区间不变。

历史年份、学段识别、学校活动目的码、未知年龄、家庭自报与权重限制沿用 [V21 数据说明](../task4_v21_nyc_chains/README.md)。under19 不是精确14—18岁样本；这里的“直接重算”指对已观察记录重新计算函数，不能把缺失旅程或真实总体效用称为精确已知。

- [结果与源哈希](summary.json)：`scenarios` 每行含 `tau_minutes`、`age_scope`、`utility_lower/upper`、`sampling_lower/upper`。
- [全部10个情景](scenarios.csv)；[测试](test_extract.py)。
