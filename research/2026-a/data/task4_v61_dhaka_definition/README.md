# Dhaka：教学角色与独立教师人数

V59–60的965下界是从2238个市级纯高中学院教师角色减去全国1195校长及78副校长得到的角色计数，不能直接认证为独立、实际承担高中教学的教师人数。BANBEIS详细方法（PDF81/印刷48）以机构为测量单位，问卷包含NID（PDF573、575），但原件未提供跨机构去重规则或实施证据。

原始依据是复用的[BANBEIS原PDF](../task4_v59_secondary_sources/bangladesh_education2025.pdf)，SHA256由[audit.py](audit.py)验证。表4.4.2跨PDF304–305，其中纯高中类别还包括1678名Demonstrator、440名Library and Information Science教师和34名Junior Instructor。职位名称不足以证明每条记录的直接授课职责；也不足以把该类别全部判定为非教学。

## 可识别的条件边界

若把Professor、Associate/Assistant Professor、Senior Lecturer、Lecturer与Physical Education Teacher列为合格教学角色，其余上述五类（含校长、副校长）的职责保留未知，则全国女性不明确角色上限740、男性2685。Dhaka纯高中学院女性角色970、男性1268，所以：

$$T_{roles,L}=\max(0,970-740)+\max(0,1268-2685)=230.$$

满足全部已用性别上限的一个反例是：男1268人角色记录分配为1060校长、59副校长、149示范；女970分配为135校长、19副校长、416示范、165图书信息、5初级指导、230讲师。所有类别与性别均在全国上限内，仅230记录属于上述合格角色分类；这是可行计数反例而非真实城市分布。

只按总数扣除会得零，但忽略了性别约束；230仍然只是有条件的**角色记录**下界。若再假设每位人员在每校至多出现一次，95所学校给出独立人数下界ceil(230/95)=3。原件未验证该假设，也未验证每个角色都符合统一直接授课定义，因此不将230或3自动准入主模型。对统一的独立授课人员目标，现有证据未建立正的下界，可保持0，计数上界13960仍是保守上限。

该修正不声称Dhaka实际没有老师，也不声称Demonstrator或图书信息教师不教学。它区分公布职位、教学职责与唯一人员这三层证据。若模型明确采用机构报告的教学资源角色，则可以保留角色条件分析，但不能与独立headcount悄然混用。一般国际教师定义取直接教学职责，参见[UNESCO UIS 2024调查说明](https://uis.unesco.org/sites/default/files/questionnaires/UIS_ED_M_2024_EN.pdf)和[OECD教师定义](https://www.oecd.org/en/data/indicators/teaching-staff.html)；本次未取得能将BANBEIS角色逐项映射到此定义的官方交叉表。
