# 上海2025职业教育质量年报：原件年份与覆盖核查

已通过官方网页的Chrome PDF阅读器下载完整121页原件 [quality2025.pdf](quality2025.pdf)，11,151,698字节；[manifest.json](manifest.json)记录官方URL和SHA256。网页工具超过文件读取限额、直接HTTP返回403；普通浏览器成功，未把失败页存为PDF。

[市教委发布入口](https://edu.sh.gov.cn/pt-zyjy-ndbg2025/)指向本PDF。核查结论：新增可准入模型单元为0。

- PDF第15页（正文第2页）明确9.59万在校生属于**2024年**，虽年报标题为2025年度。已视觉核对原页，不能当作2025数据。
- PDF第14页定义53所为2025年独立设置且招生的中职学校，第62页限定普通全日制中职年报覆盖集合。100%报送覆盖不等于覆盖所有中职机构、附设班或全部高中阶段学生。
- PDF第25–27页师资章节讨论培养与获奖案例，未提供可和该学生数匹配的全市教师存量。本年报未解决[V64口径缺口](../task4_v64_shanghai_stage/README.md)。

这些事实由另一agent独立核查。2024学生数不能配2025教师数；53所集合也不能直接当作此前70机构统计表的同一总体。继续保留当前普通高中观测及其职业教育覆盖限制；未将新数字写入全市高中阶段指标。

下一步需要53校名单与统计表机构逐校对应，以及同一年度、当前课程阶段的学生和授课教师数。学校年报名单可用作查找入口，不能凭发布覆盖率推定总体完整。
