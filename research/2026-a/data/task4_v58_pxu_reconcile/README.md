# V58 — PXU人数差异分解到性别组

V57重新下载的同届公开响应显示，学校合计超过学区2人的差异同时出现在两个公开性别组：

| 2024届队列组 | 19个学校实体合计（含Digital） | 学区公布 | 净差 |
| --- | ---: | ---: | ---: |
| All | 6287 | 6285 | +2 |
| Female | 3118 | 3117 | +1 |
| Male | 3169 | 3168 | +1 |

19个学校各自的Female加Male均等于All，学区内部也相等。这定位了跨层汇总差异：本次计算没有遗漏一个公开性别行，也没有将公布百分率四舍五入后反算人数。上述数值来自整数队列字段，不涉及毕业人数受保护单元格的恢复。

Desiderata与Educator Preparatory没有All行，仍为未知，不能填零。两个性别组的净差不识别具体人员、学校、重复原因或重复人数上界。当前仍不能据此采用学校集合求和后的城市毕业界。

独立查阅官方[Accountability Data Guide FY22](https://www.azed.gov/sites/default/files/2021/08/Accountability%20Data%20Guide%20FY%2022.pdf)的完整6页网页阅读器文本：其第3页说明小计数及可逆推小计数的补充抑制，并将极端百分率显示为区间；未提供可以解释本次整数差异的跨层加总规则。该旧指南不替代FY2025产品规则，亦不证明误差为零。访问结果及简短转述见[规则核查记录](guide_audit.json)，未声称已取得PDF原件。

[audit.py](audit.py)离线核验22份V57响应的哈希、年份、实体与分组唯一性，再验证内部性别加总和跨层差异。[逐校数值](school_sex_counts.csv) · [核验输出](audit.json)。未修改模型、排名或论文；下一步仍需同届官方工作簿或说明明确学校与学区的统计关系，不能凭净差设定重复预算。
