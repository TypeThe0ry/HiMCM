# Singapore：全学段平均不能界定高中生子群

旧通学输入来自真实人口普查，但其分组与目标人群不一致。原表[通学时间数据页](https://data.gov.sg/datasets/d_e87b21cfebae1a77150eccded58ab116/view)的Secondary包含初中和高中；2020官方完整报告PDF第232页／印刷215页明确为Secondary 1–5及部分职业、技术和商业课程。V68取得的UIS映射将普通Secondary 3–5对应高中阶段，因此全Secondary均值不能直接用于14—18岁当前高中生。原件、字节数、SHA256和失败下载记录见[manifest.json](manifest.json)。

## 哪一步不成立

原算法分别计算Secondary与Post-secondary non-tertiary完整分组的效用均值界，再取二者包络[0.244826,0.614811]。若目标总体确由这两个**完整组**按未知份额混合，该包络有意义；目标是组内未识别的年龄及当前高中子群时，没有理由要求子群均值落在组均值之间。加入第二个宽学段的组均值也不能修复这种筛选缺口。

设原分箱人数为 $c_b$，目标子群在各箱的人数为 $z_b$，该箱效用界为 $[a_b,b_b]$。已有证据只给出 $0\le z_b\le c_b$；若目标人数为 $n$，则 $\sum_bz_b=n$，目标均值的界应由

$$\min_z\frac{\sum_b a_bz_b}{n},\qquad \max_z\frac{\sum_b b_bz_b}{n}$$

计算，不能用全组 $c_b/\sum c_b$ 的权重代替。当前没有同一通学总体下目标年龄与当前年级人数的正下界，允许子群只占最快或最慢箱的一部分。最快箱效用上确界为1，最慢开放箱下确界为0，所以现有约束对目标均值仅支持闭包 **[0,1]**。零端点表示未识别，不表示实际学生通学无限久；原分组实测数据仍保留。这里以Secondary这个包含普通高中课程的宽组构造识别反例；并不声称全体目标高中课程都属于该统计组。各课程与年龄的目标权重仍未识别。

## 可复算反例

Secondary原始五箱人数为[46434,71367,31872,17246,5568]。即使额外**假设**目标质量为80000，以下两组分配均不超过各箱人数且都加总80000：

| 分配 | 五个时间箱中的目标人数 | 目标效用极值 |
| --- | --- | ---: |
| 偏向慢箱 | [0,25314,31872,17246,5568] | 0.234476 |
| 偏向快箱 | [46434,33566,0,0,0] | 0.834910 |

二者均超出旧包络的一端。80000不是已观测高中人数，表中分配也不是实测旅次；它们只证明“全组均值包络约束任意子群”这一算法命题不成立。端点按原时间箱边界的保守闭包处理，不填中点。

UIS映射的`Sheet1!R18:R19`将Nitec和Higher Nitec分别编为453和454（ISCED4），不能仅因其学生年龄接近高中生就归入ISCED3；Census Secondary中另外包含的ISC也不能由Nitec代码直接替代判定。

## 新表能否恢复目标份额

新取得的[2020年龄×在读学段官方表](https://data.gov.sg/datasets/d_f4312e4611f135d5a8638e8daf76f53e/view)有Secondary总数174298，其中10—14岁99841、15—19岁74241、20岁及以上215；分项存在公开取整差异，未擅自改数。年龄箱不能区分14或19岁，也没有Secondary 1–2与3–5年级字段。此外，它的Secondary总数不同于通学表172487；通学表排除了居家学习者及海外至少六个月者。不能将74241直接当作目标高中份额，更不能以2024 MOE学生数混入2020居民通学分母。

还取得[官方GHS2025报告](https://www.singstat.gov.sg/files/1559c94a-efc1-4262-84fd-042c9bd96e68.pdf)。PDF第130页／印刷115页仍将Secondary定义为1–5年级和部分职业课程，使用SSEC2026；其粗学段统计没有解决当前子群识别。该页部分PDF字体文本提取缺字符，已渲染目视核验定义，没有靠残缺文本猜数字。本轮不把2025粗学段中位数替代目标高中平均效用，也不将两年的区间取交集。

恢复非平凡目标界需要同总体的年龄×当前年级×通学分箱联合记录，或至少能验证的目标人数下界和覆盖关系。保留[summary.json](summary.json)的`revised_travel_interval=[0,1]`供主模型修订；原Secondary和Post-secondary统计值仅作为明确标记的宽人群描述。
