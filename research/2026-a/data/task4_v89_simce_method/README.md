# V89：SIMCE等级比例的官方方法核查

已取得[2024技术报告原件](Informe_Tecnico_2024.pdf)和[2017技术报告原件](Informe_Tecnico_2017.pdf)。来源、年份及哈希见[manifest](manifest.json)；2024考试报告封面内页标示出版年2026，未混同考试年。

## 2024方法已确认的内容

- 印刷第48页（PDF第50页），第3.4节及表3.6：依据学生个人分数划分不足、基础、充分三个学习等级；高中二年级阅读分界为250、295，数学为252、319。充分等级包含满足基础等级要求的学习者。
- 印刷第49页（PDF第51页）：聚合均分来自所含学生分数的平均，等级统计为聚合中学生处于各等级的比例。该页另将考试出席率定义为参加考试者相对于该阶段注册学生，两个分母不能互换。
- 印刷第50页（PDF第52页）：聚合分析受比较总体筛选和发布限制约束；发布限制在聚合计算后应用以保障保密与稳健。并未在此列明2024小样本抑制的具体门槛。
- 印刷第47、51页（PDF第49、53页）：感官障碍适配测试DS使用不同处理和尺度；不能自行把它与普通测试拼接。

## 仍须作为条件的内容

本次核查未找到明确声明：公开学校CSV的`nalu_*`（参加考试人数）一定等于等级比例的精确分母。也未找到2024发布百分比的舍入规则。因此，整数反推只能描述在“该人数为分母、所示一位小数按最近舍入”条件下的可行计数，算术兼容不能独立证明这两项语义。

2017报告印刷第62页（PDF第64页）明确：某学科、年级少于10名受测学生的学校不发布等级结果。这为2024中8/9名考生且三级比例全零的现象提供历史解释线索，但不能未经核验将历史规则认定为2024规则，更不能把全零当作真实学习等级分布。

[V88字段词典与质量标记](../task4_v88_pisa_regions/README.md)仍有效：`marca=2`说明该结果因机构外原因不具代表性。新方法资料不删除这些标记，也不把考试成绩推断为全部14—18岁居民教育质量。
