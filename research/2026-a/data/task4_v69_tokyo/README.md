# Tokyo：补入特教高中本科，区分专攻科与地理范围

本轮取得2025年官方特教学校总表和公立学校名册，识别至少5808名此前遗漏的高中本科学生。没有把全部高等部学生或全校教师直接当成高中数据。新增原件和复用原件的URL、SHA256、字节数见[manifest.json](manifest.json)；可复算结果见[summary.json](summary.json)。

$$N_{special}\in[5854-46,6063-46]=[5808,6017].$$

这是按官方课程分类匹配2025观测的条件界；没有把UIS旧参考年当作2025原始人数。学校调查共同日期为2025年5月1日，参见复用的V46调查方法PDF。

## 都外学校核验

特教总表脚注说明大田、板桥、葛饰带＊的区数包含都外区立学校。不能直接依据行政归属推断校址。将同年学校别学生表和地址表按学校编号连接，查出三所位于千叶县的区立学校：天津わかしお、保田しおさい、館山さざなみ；三者高等部人数均为0。学生单元格分别为`ichiran1!AC84:AC86`，地址为`ichiran2!AX86:AX88`。因此这些都外学校没有混入本次高等部人数；其教师仍留在保守上限池中，未把他们称为境内高中实际教师。旧普通高中及中等教育学校CSV没有都外＊脚注，本次未据此更改旧人数。

## 教师口径与扩展界

沿用旧模型的官方“教员数（本务者）”学校归属人数，新增特教目标学段的分配量只设 $H\in[0,7018]$，不按学生比例分配。MEXT《2025特教学校调查手引》PDF第7页／印刷5页说明本务按辞令及工资／授课时数归属，包含休职、产假、育儿照护假者及替代者；兼职讲师按兼务处理。PDF第56页表式明确教员栏目包含校长、副校长、教头等以及养护、营养教员。该资源指标不是仅课堂授课教师、当前到岗教师或FTE，不能改称教育质量。学校本务归属规则防止将普通、六年制和特教学校之间的兼务人数重复相加。

在原V47普通高中加六年制后期学生306903、本务教师19446及待分配六年制教师池555的基础上：

$$N\in[312711,312920],\quad T\in[19446,19446+555+7018]=[19446,27019],$$
$$u_E=\frac{15T}{N+15T}\in[0.482443227866,0.564466932963].$$

端点取最大分母／最小教师和最小分母／最大教师，属于保守矩形外包，未声称极端配置能同时实现。新增覆盖总体与旧总体不同，不能与旧区间取交集。高专前三年、通信制、专修学校高等课程及本法定学校类别外国际学校尚未覆盖；本数据并非全城高中教育的完整识别界，也未按14—18岁筛选。

原有高专表只给五年本科3330人和全校教师246人，未分前三年，因此本轮不把它加入高中阶段。已纳入的六年制学校后期3435人继续保持，不重复增加。
