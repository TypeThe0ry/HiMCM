            Further education and skills: July 2026
                       underlying data

                                Metadata specification

Description

This document describes the additional supporting files that accompany the ‘Further education and
skills: July 2026’ accredited official statistics publication. It is provided to allow users to interrogate
the data themselves.

The underlying data files cover England and include Further Education and Skills learner
participation/achievements and aim enrolment/achievement figures. Some tables also include
further breakdowns; by provision type (e.g. education and training, tailored learning, or
apprenticeships), by learner characteristics (e.g. age, sex, ethnicity group) or subject
characteristics (e.g. sector subject area, level, learning aim).

The Further education and skills statistics: methodology document published alongside the main
release should be referenced alongside this data. It provides information on the data sources, their
coverage and quality as well as explaining methodology used in producing the data.

    •   Underlying data - aims achievements by provision type
    •   Underlying data - learner demographics by provision type
    •   Underlying data - Free Courses for Jobs Starts and Achievements on Individual Courses
    •   Underlying data - Free Courses for Jobs course list starts by provider and academic year
    •   Underlying data – advanced learner loans applications - top 10 qualifications
    •   FE and skills (FES) provider participation by provision type and learner characteristic
    •   Geography Region - starts, achievements, participation, population by age, level (2023

Navigate to the ‘Explore data and files’ section of this release to find several useful
underlying and supporting files for the data on the publication.

The underlying data files and meta data information can be found under the ‘All supporting
files’ sections. Once expanded you will see a list of all the files available for you to
download and use.

Due to the size of some of these files follow these steps to download and access the data.

Click the data file link you wish to view; this will automatically start a download of the file
through your internet browser. Once this step is complete, click the file, or open your
downloads folder on your file explorer.




The data files will download as CSV files which you can create a connection to and build a
pivot table for your analysis.

Save the file from the downloads folder into a suitable location of your choice.

In excel on the ‘Data’ tab click the ‘From Text/CSV’ button in the top ribbon of excel.




Navigate to the folder the underlying file is saved to and select the file to ‘import’
