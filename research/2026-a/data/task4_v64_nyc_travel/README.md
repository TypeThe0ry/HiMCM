# NYC更新通学来源：2020智能手机试点与公开入口核查

本轮取得NYMTC官方智能手机试点原报告，实际调查期为2020年11月2—30日，共264名参与者、1848个出行日、4843条旅程；其中66人为17岁及以下。报告封面为2021年演示、文件名带2022最终版日期，这些都不是2023/24调查。

原PDF第15页明确其小规模试点结果不应用于区域分析。公开报告没有当前高中学段、NYC市界与学生到校时长的联合统计；年龄≤17不能直接代替高中在读。报告也有合并的Work/School目的展示，不能据此提取纯学生通学均值。

截至本次核查，[NYMTC调查入口](https://www.nymtc.org/travel-surveys)仍列2010/11 RHTS、该智能手机试点及2023 RFI规划材料。未找到更新RHTS公开微观数据不等于证明新调查不存在。保留既有真实高中生通学历史数据与年份限制，新增准入观测0，不人为收紧区间。

较新的[CMS2024资料](../task4_v20_nyc_school_survey/README.md)已由V20核验：未成年高中名册成员没有本人出行日记及正个人权重。此次复查官方2024用户指南再次确认成人加权总体，因此不重复下载既有原件或用成人权重扩展未成年人。
