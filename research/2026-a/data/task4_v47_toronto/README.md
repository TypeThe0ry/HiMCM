# Toronto：真实毕业率已取得，城市队列人数仍缺失

Ontario官方2026年5月版本学校董事会进展工作簿提供2023–24毕业结果，包含服务Toronto的四个学区。原件和目录响应已保存，字段、来源及SHA256可离线复核。

| 学区 | 四年毕业率：2020–21进入9年级 | 五年毕业率：2019–20进入9年级 |
| --- | ---: | ---: |
| Toronto DSB | 81.8% | 87.4% |
| Toronto CDSB | 88.4% | 91.5% |
| CS Viamonde | 92.9% | 93.7% |
| CS catholique MonAvenir | 94.0% | 94.5% |

这是实际高中毕业结果，具有明确队列定义，不能与师生比混称。但原工作簿18列只有学区识别、比例及变化量，**没有毕业人数或队列分母**。因此不能按规模合并四个学区，也不能用学校总在校人数加权。四年和五年列的进入9年级年份不同，二者之差不是同一批学生第五年的新增完成率。

地域限制与V39审计一致：两个法语学区超出Toronto市界，整学区毕业率不能分配给市内七所学校；公立学区也不覆盖全部私立学校及所有城市居民。目录中的City字段是学区信息，不是学生居住地或仅市内学校的筛选。各学区单列，缺失分母保持空值，未进入跨城教育评分或改变冠军范围。

本次新证据是官方毕业率文件及明确的双队列字段；没有重新下载V41 EQAO。另定位的TDSB替代学校2022–23调整毕业率报告未成功下载原PDF，不采用其网页片段推导人数或跨年变化。当前所需的下一份材料仍是同队列毕业人数、起始/调整队列人数，以及市内学校或居民地域分解。
