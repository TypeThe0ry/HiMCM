# Tokyo：全国PT 2021公开旅时表的范围核查

新取得国土交通省2021年全国都市交通特性调查的平均旅时原始XLSX，以及2024年3月修订的数据使用指南原始PDF。该来源不同于此前已核查的Tokyo2018都市圈PT，也不同于一天累计通勤／通学时间表。

[官方数据目录](https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_fr_000024.html)直接链接[旅时XLSX](https://www.mlit.go.jp/toshi/tosiko/content/c001_R3.xlsx)和[使用指南](https://www.mlit.go.jp/common/001229430.pdf)。原件字节数、URL及SHA256保存在`manifest.json`。

## 不能填入Tokyo高中生通学格

工作表`c001_R3`的维度是平日／休日、城市类型、性别、出行目的及交通方式。其“都市”实际是10类城市分组加全国总计，没有Tokyo单独一行，也没有当前高中阶段维度。比如平日男性通学的“三大都市圈中心都市”平均26.8443分钟，是多个中心城市及各学校阶段的组值，不能当Tokyo高中生旅时。

指南PDF第5页分别列Tokyo区部、稲城和青梅为样本地区；这些也不是整个Tokyo都域的全数覆盖。指南第31页说明精度标记1对应少于70次旅程的类别，并未给出可用于本模型的Tokyo高中学生分母。即使取得合适范围的均值，也不能直接将指数作用于均值冒充平均通学效用。

因此本包新增城市准入观察为0，Tokyo通学仍保留原缺失区间。下一步应寻找具有Tokyo目标地域、当前高中在读及单向实际旅时联合信息的发布数据，而非继续从本分组表中取近似值。
