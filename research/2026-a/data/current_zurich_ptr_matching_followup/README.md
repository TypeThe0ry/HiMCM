# 苏黎世高中师生比：匹配口径补充

本次新增州教育统计局数据集 524（distribution 989）原件及其说明。2024 年 Sekundarstufe II 四类合计 63,925：Mittelschule 14,618、Heim- und Sonderschule 275、Brückenangebot 2,160、Berufsfachschule 46,872。提取包含全部提供方和融资分类；公立承办 48,551、私立承办 15,374。数据是**学校位于整个苏黎世州**的人数，而非苏黎世市、学生居住地或仅 Gymnasium；州说明将 2024 对应 2024/25 学年及 2024-09-15，且覆盖公私立。Sek I 的长制 Gymnasium 已按原数据的学段分开，未加到 Sek II。州内城市学校显然属于州地理范围，但目标学生定义、学校类型以及可用教师统计的人群和计数惯例是否完全嵌套，仍需逐项证明；这个总数是潜在宽松上界的材料，尚不是已准入上界。

另一条官方路线是州教职工就业分析，确有学校和市镇信息，但所发布分析针对公立义务教育，城市结果至 Sek I，不提供目标 Sek II 市级教学 FTE。它证明采集包含地理信息，不证明可公开取得目标交叉表。既有城市数据仅提供 Mittelschulen 的 Sek II 8,581 人，不能当作包含 Berufsfachschule 的城市总数。先前 BFS T10 私校总量仍是有价值的既有证据：本次没有新增证据证明其覆盖失败，也没有证明它覆盖每项目标教师活动或足以构建保证性的上界。已发表数字精度和目标范围不能自行补足。

因此本次新准入 0，无可靠的城市教师教学 FTE 下界与匹配学生上界组成的完整证据对，不计算 PTR 或效用。收入学年的定义、学校所在地、学段、职务和公私立覆盖在构造任何界之前须共同满足；无法假设未核实变量可用。`retrieval.json` 记录原始字节、状态、时间及哈希；`dataset_524_metadata.Rmd` 的 404 是首次错误地址回执，不作为事实来源。`dataset_524_metadata_989.Rmd` 为州开放数据官方 starter-code 元数据；具体原始 CSV 和州网页分别保存在同目录。离线运行 `python research/2026-a/data/current_zurich_ptr_matching_followup/verify.py` 重现提取和校验。
