## Reproducible bridge rules

`extract_crosswalk.py` reads the existing national roster, complete ROR JSON and DBH campus/student summaries without modifying them. It accepts an exact normalized DBH/NOKUT name; or a DBH name in an active ROR record whose names or website also match the NOKUT entry; or the exact DBH name in a successful page on the NOKUT-linked institution's own website. Normalization uses Unicode accent removal, case-folding and whitespace collapse. Website comparison strips only `www.` and requires matching hostnames; no fuzzy matching or number-based identity is used. Twenty identities follow the direct-name/ROR routes; five additional identities have the successful official-page bridge. `crosswalk.csv` retains all27codes, proof objects, national categories and explicit unresolved decisions.
