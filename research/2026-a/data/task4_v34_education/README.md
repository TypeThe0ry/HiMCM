# Delhi真实高中学生与任课教师人数

官方UDISE+ 2024–25表5.1（PDF/印刷p85）给出Delhi NCT的11–12年级学生603437人；表4.7（p58）给出只教高中教师26766人、兼教9–10及11–12年级教师3420人，两者合计30186名高中任课教师。所有管理类型合计，非仅公立学校。

按任课教师人数计算：

$$PTR=603437/(26766+3420)=19.990624793,\quad u=15/(15+PTR)=0.4286862578.$$

表4.12（p63）公布高中PTR整数20，与重建结果四舍五入一致。由于已经有分子分母，未采用人为的整数精度区间。p188定义PTR为对应教育阶段学生数/在该阶段教学的教师数。

教师是人数，不是FTE；兼教学段教师被完整计入任课人数。因此另保留敏感性端点：只计只教高中教师时效用0.3995215573；兼教教师全部计入时0.4286862578。该范围是“兼教教师贡献从0到1”的资源分配情景，不是官方FTE、已识别的真实资源区间或抽样置信区间。模型若只用教师人数指标，应采用任课人数点值并明确其含义。

地理为Delhi NCT，不是New Delhi行政小区或整个NCR。人口是学校在读者而非按学生居住地统计；并未把各人的年龄限定14–18岁。统计覆盖UDISE+报告学校，不能宣称包括所有未登记教育活动。师资配置不等同教育考试成绩或因果质量，条件分析标记main_admitted=false。

## 来源与复核

- 原始11.76MB PDF来自官方UDISE+ dashboard；URL、字节数和SHA256在manifest.json。
- 数值页58与85已渲染并目视核对表头、Delhi行、管理类型及学段。
- extract.py先核验原文件SHA256及字节数，再从PDF提取。校验全部教师类别之和、学生阶段合计、elementary等于小学+初中，并以p63整数PTR交叉检查。
- observation.json保留完整Delhi原始行、页号、人数、精确比率和敏感性端点。
- 最初尝试教育部镜像及议会附件返回404，因此使用官方UDISE+ dashboard成功下载的原文件。另下载Delhi Economic Survey2025–26作为背景资料（未用于本观测），也列在manifest。

复现：`python3 research/2026-a/data/task4_v34_education/extract.py`。
