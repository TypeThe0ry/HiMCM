# Oslo author-platform grid

`6494_hexes.zip` is the original response from the author-platform current grid endpoint recorded in `download.json`, captured 10 November 2026 UTC. It has 4,321 polygons; 1,615 have positive population and all those `c_f` values are finite and positive. Total population 686,862.09056 agrees with the archived index's rounded 686,862.09. Coordinates were checked within a broad Oslo-region bounding box; this is not an independent municipal boundary or population completeness verification. The source population and input reference years are unspecified, and the population differs from the V203 model denominator 727,797. `capture_imagery.py` records the three bounded NASA WMS requests separately in the current visual's `oslo_imagery_manifest.json`; all three responses are fully transparent.
