## 来源和复现

发现路径：[教育部开放数据入口](https://www.minedu.gov.gr/diafaneia-dedomena/anoikta-dedomena) → 2026文件 → 战略规划与电子治理总司 → 战略规划协调司。原件URL、下载日期与SHA-256见[manifest.json](manifest.json)。目录发布年份2026与数据学年2024/25分开记录。

运行`python3 research/2026-a/data/task4_v105_athens/extract.py`。脚本仅用Python标准库读取OOXML，核验ZIP CRC、原件哈希、表头、逐行求和并生成[summary.json](summary.json)，不依赖Excel公式计算或核心模型函数。

已先复核V74–76材料：新原件解决了本次资料的学年标签，但不能反向解释旧2018/2019学生导出的年份，也不能将旧市内学生子集与新2024/25区域人员配对。下一步需要同学年市内校级学生与高中教师清单，以及公私立、特殊教育、跨校任职和统计时点定义。
