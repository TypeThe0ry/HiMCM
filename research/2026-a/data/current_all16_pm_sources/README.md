This package preserves a historical geographic-code route for15of the16cities, while current numeric source verification remains unresolved. Singapore has no country root in the archived codelist. The two new v1.5structure/data API requests returned403and are retained as failures; they supply no concentration observations, years, current code validity or evidence that data do not exist. The original2024MODELLEDpoints remain unchanged.

`map_areas.py` reads the unchanged OECDv1.2structure archived at `../current_oslo_pm_model/structure.xml`. It selects `CL_FUA_CITY`v1.1, follows city-to-FUA-to-country Parent/Ref chains, matches the userCSVcountry through an explicitISO2/ISO3crosswalk, and uses exact declared labels/aliases. The city/FUA pairs are recorded separately; Helsinki/Helsingfors,Wien,Zürich,Milano,PrahaandWarszawaare explicit source-label aliases rather than fuzzy matches. `area_map.json` includes all16original values/years/flags, country-root labels and parent chains. It is historical metadata routing, not a claim about v1.5coverage, municipal boundary equivalence or the source of any submitted point. Singapore is retained in the analysis rather than replaced by national data or dropped.

The [official current catalogue](https://data-explorer.oecd.org/?bp=true&fc=Topic&fs%5B0%5D=Topic%2C0%7CRegional%252C+rural+and+urban+development%23GEO%23&pg=0&snb=94) indicated v1.5as a newer flow; this motivated the two recorded requests. Their status403cannot be reinterpreted as the older dataset's time coverage. The prior archived Oslo v1.2response contains2021–2023rows; only that response supports its stated latest year2023. No2024data or new cross-city numeric matches were obtained here.

The previously reviewed definition is modelled population-weighted exposure from pollutant grids/GHS-POP. CITYapproximates an urban centre via administrative units; FUAincludes a commuting zone. A station average, country average, CITYandFUAare different statistics, and a matching or rounded number alone cannot identify the original model, date or perimeter. The source version, population-grid vintage and geographic scope require a compatible source record before a replacement or model admission.

`retrieval.json` captures requested/final URLs, actual status, requestUTC, content type, size andSHA256for both failures. No retry, authentication or external message is used after the blocked route. The source routing audit is combined with the separately prespecified PMcriterion withdrawal diagnostic in `../../results/current_pm_block_withdrawal/`; the diagnostic does not depend on inventing any missing concentration data. Primary admissions and actual primary width reduction are zero.
