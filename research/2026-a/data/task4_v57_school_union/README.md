# V57 — Phoenix同届学校与学区人数核对

新取得20所非Digital学校的官方实体响应，并重新下载这20所学校、Digital及学区的22份FY2025毕业响应。GetEntity请求2025却返回2026，因此只用于核对官方实体与NCES编号；历史学校位置来自[V56的2023–24官方课程目录](../task4_v56_pxu_roster/README.md)。19个编号匹配，Desiderata的NCES字段为空，保留为未识别，不纳入求和。微型项目按实体编号去重；PXU City的混合教学不构成新的排除条件。

18所学校公布了2024届队列人数，共5802人；12所学校公布精确毕业人数，共毕业3782、未毕业1260。其余6所已知队列的毕业数保留[0,n]；Educator Preparatory没有All行，不能记为零学生。这里的未毕业包括多种状态，不等于辍学。

**5802+Digital的485=6287，比学区同届6285多2人。** 同一轮重新请求后，参与求和的学校All行与归档一致，学区和Digital数值也不变。分批公开请求不代表数据库原子快照，但重取结果没有消除差异。学校责任集合、跨层汇总或更正版本仍需对账；净差2不是重复人员的上界。

[当年规则全文核查](../task4_v57_ade_aggregate/README.md)支持按最后学校解释行政责任，然而这项具体数据差异使本次求和结果仍不能成为已核实城市界。原始技术手册PDF未下载，保存的是官方阅读器核查记录。

`collect.py`核对身份并记录原件哈希；`refresh.py`为显式联网重取脚本，刷新时间及请求地址见`refresh_manifest.json`；离线[计算脚本](../../scripts/task4_school_cohort_union.py)重验身份、原件、All行、抑制值及跨层人数条件。原始API响应按字节保存。读取`school_bounds.csv`时，零下界表示没有可用正下界，不能解释成实际零毕业生。
