# Phoenix: dated district enrollment ceiling

The Arizona Department of Education FY2024–25 Superintendent Annual Financial Report, Volume2, reports **1,180 Fall2024 pupils** and one active school for Maricopa County Regional School District (CTDS070199000), printed pageI-113. The district-specific definitions on pageI-5 identify fall enrollment as an unduplicated district count on **October1,2024**; the staffing summary also refers to October1. This is a headcount distinct from the previously reviewed ADM1145.5429.

The existing official NCES2024–25 roster links Hope Academy (040386003535) to this district (0403860, AZ4234). It also lists Southwest Key Transitional Learning Center with membership0. Hence the financial report's one-active-school figure should not be represented as proof that NCES has only one directory record.

Provided target Hope pupils are included in the district's unduplicated count, **0≤Hope target pupils≤1180** is a conservative containment bound. It does not assert that Hope has exactly1180 pupils, that all district pupils attend in person, or that the ADE chart's1178 uses the same snapshot. Other district grades/programs may enlarge the ceiling without invalidating containment. Cross-district dual enrollment or exclusion from the district count would require revisiting this inclusion condition. The national roster's school-level population and district unduplication are not independently reconciled here.

This evidence supports evaluation of a conditional public-school target bound. It does not by itself harmonize public/private coverage, teacher allocation, or the canonical cross-city education indicator. No model input was changed by this acquisition task.
