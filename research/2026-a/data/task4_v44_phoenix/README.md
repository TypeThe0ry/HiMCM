# Hope：现行目录与历史人数口径分开核查

本轮取得学区四份2024–25学年会议附件及当前官方网页，但仍未证明ADE FY2025的1,178人与NCES October 1人数兼容。原[条件情景](../../results/task4_v42_phoenix_public/README.md)不能转为已确认的城市输入。

## 新取得的证据

- **请求年份不等于返回年份。** 官方`GetEntity?id=969999&fiscalYear=2025`实际返回`fiscalYear:2026`，学校名为Hope College and Career Readiness Academy，CTDS为070199008，地址为Tempe的1938 E Apache Blvd。原始响应已保存。该响应可确认学校标识和当前页面信息，不能独自证明2024–25学年地理位置。此前NCES坐标的年份应继续单独核查。
- **财务学生计数不等于October 1人数。** 2024年10月11日官方会议附件第16页，FY2024学校财务表列出292.4083的`Unweighted Attending Student Count`，学校CTDS匹配070199008。这是前一财政年度的分数计数，不作为FY2025学生人数或上界。2024年11月12日、2025年1月7日及2月10日附件未给出所需的同日高中年级人数。
- **现行招生容量不是历史观测。** 官方招生页列出100人的招生上限，当前地址位于Tempe；页面没有证实该上限适用于2024年10月1日及同一教学项目。因此不把100写入历史学生上界，也不把广告师生比例当FTE观测。

## 后续核实线索

第三方Poliscopic收录的2025年1月27日县监事会会议纪要第20页，分别提及58名现场学生和1,180名在线学生。其链接指向县议事系统，但原PDF下载返回403。本轮把它保留为**待官方原件核验的项目范围线索**，未作为模型数据，也未宣称1,178就是在线人数。核对人数时除日期外还需要核对现场／在线项目覆盖。

学校当前网页中的“online enrollment”本身只是线上办理注册，不能据此推断线上授课；上述在线学生线索来自不同的会议纪要转录。
