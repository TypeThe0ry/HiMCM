## 为什么不能直接用全部58463名教师

原PDF第65页（印刷34页）明确：设在Imam Hatip高中内的初中教师计入高中学校教师数。因此其中真正归属高中教学的教师H保留在[0,9871]。

同PDF第124页（印刷93页）还记录全国27所职业初中、556名学生，而教师字段为横线。[MEB原始课程工作报道](https://mtegm.meb.gov.tr/www/meslek-ortaokulu-ve-yeni-acilacak-alanlara-ait-program-gelistirme-calistaylarimiz-devam-ediyor/icerik/3698)说明这类初中项目设于职业技术高中内。本轮取得该官方HTML原件。现有材料尚未独立确认Istanbul职业教师的高中／初中分配，故将V保留在[0,20156]；这不表示Istanbul全部职业教师都服务初中，也不把全国556名学生扣自Istanbul。

保守扩展使用

`N=751598, T=28436+V+H, V∈[0,20156], H∈[0,9871]`，

所以资源效用`15T/(N+15T)`为 **[0.3620458724,0.5384843999]**。普通高中旧值为0.5108141122。若额外假定全部职业教师可归属高中，条件界为[0.4923274780,0.5384843999]；该假定单列，不作为已验证事实。一般高中28436名教师继承既有同阶段统计口径。

这种修订增加实际学生覆盖，同时显露师资分配不确定性；不能将区间变宽解释为城市教育恶化，也不能声称已完全统一跨城所有高中项目。
