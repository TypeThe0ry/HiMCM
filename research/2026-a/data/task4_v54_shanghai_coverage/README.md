# Shanghai：中职教师与同年学生总量的条件配对

上海市教委[2025中职统计入口](https://edu.sh.gov.cn/xxgk2_zhzw_tjsj_01/20260611/c897f67471e14043bba186253eaf04d7.html)的[原始PDF](https://edu.sh.gov.cn/cmsres/ac/ace05e5dc9f8440797e18652e91e871b/0b77e2feb511feec5d999a836230034f.pdf)由网页工具成功读取，列出中职专任教师7273人：普通中专4164、职业高中2344、技工学校317、成人中专59、附设中职班389。五项相加与总数一致；排除成人中专后的教师池为7214人。PDF只列机构及教师，没有学生分类人数。

上海市统计局[2025统计公报](https://tjj.sh.gov.cn/tjgb/20260330/e0772941e8e041eaaad2df850b44ef98.html)第十一部分列2025学年普通中职学校64所、中职在校生10.90万人，附注1说明数据存在四舍五入。若按公布精度0.01万人取四舍五入闭包，学生数为[108950,109050]，不将109000当精确计数。

## 尚缺口径连接

机构数64等于教师表70所减去6所成人中专，但这种数值关系不能单独证明学生总量排除了成人中专，或技工、附设班及贯通项目的高等阶段处理完全一致。教育部2025全国公报的中职定义也不能直接替代本市包含技工学校的表。因此7214名教师与10.90万学生只形成**条件情景**，不替换当前普通高中235542学生／23999教师的主模型记录。

若额外接受以下条件：学生总量与非成人教师池覆盖同一高中阶段人群，技工与附设班不混入高等／成人教学，2025学年快照兼容，则合计学生[344492,344592]、教师31213，教育资源效用为[0.5760365262,0.5761074067]。条件撤回时不能保留这一窄区间。这是学校课程统计，不是实际14—18岁居民年龄筛选或教育成果。
