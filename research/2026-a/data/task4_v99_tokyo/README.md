后期课程教师分配仍未知。设普通高中本务教师为T、六年制全校本务教师为H、两类高中阶段学生合计N，则本次条件界为 `[15T/(N+15T),15(T+H)/(N+15(T+H))]`。2026年的H=565不能直接全部认定为高中部教师，也未按学生比例分配。

本表沿用历史V47的学校归属人数资源口径，**不替代当前V96模型的Tokyo格**。当前模型已在后续版本加入其他学段覆盖及教师职能分配；2026速報尚未提供对应全部细分。2025与2026配对可以检验同一较窄口径下的年度变化，不能把较窄口径当成主模型精度改善，也不能拿两年区间求交。两行均不包含通信制、特教高中部和专修学校高等课程；学校所在地不等于学生居住地。本务人数不是FTE，当前年龄14—18岁也未单独识别。

2026定义PDF第1页规定学生为本科在籍者、教师只计本务者，第2页明确速報以后续文部科学省确定值为准；方法PDF规定2026年5月1日及学校全数调查。新取得的MEXT2025中等教育学校手引第8页（印刷6）说明本务归属及休职、产育休、替代者计入规则，第49页附录项10收集全校教员数，未提供本次所需的前后期教师分配值。该手引为2025年原件，未用其断言2026未公布细项的数值。

运行 `python3 research/2026-a/data/task4_v99_tokyo/extract.py`，验证所有原件哈希，按年份／所有制／地域总数提取唯一行；核对普通高中地域、年级、性别合计，六年制所有制、学校地域、年级和性别合计，并用既有2025确定值原件检查新表的2025对照。普通高中CSV没有单列国立总数，因此未把公私立相加冒充全体。
