# Mexico City：2024新调查的学段与通学时间不能跨调查拼接

取得三份[INEGI官方原件](manifest.json)：ENUT2024问卷、ENIGH2024数据字典及访员手册。这是新的资料审查，未替换现有2020普查条件性通学界，也未下载或合并两项调查的个人微观记录。

| 原件位置（PDF页） | 原始测量内容 | 对高中单程通学指标的限制 |
| --- | --- | --- |
| ENUT问卷第10页，4.2 | 最后通过的年级／学段 | 不能直接当当前高中年级 |
| ENUT问卷第14页，6.2第3项 | 上周往返学校的总时间，分别报告周一至周五及周末 | 不是单程分钟；没有据此假设每天往返次数或直接除以10 |
| ENIGH字典第23、87页 | 当前就读学段nivel及年级grado，与nivelaprob等已完成学段字段分开 | 提供当前学段定义，但不是ENUT受访者的字段 |
| ENIGH字典第94页、访员手册第261页（印刷258页） | 每周学习时间包括上学路程、作业等 | 总学习时间不能作为单独通学时长 |

ENUT可为未来带频次约束的周通学负担研究提供线索，ENIGH提供当前就读定义。两份独立调查并没有可用于个人联合识别的跨调查连接，因此本轮不将一项调查的年级与另一项调查的通学时间拼成高中学生记录。也不从周总量、学校课程时数或假设出勤天数制造精确单程分钟。

原件保留字节与SHA256，`audit.py`校验原件并直接核对上述页的关键定义。问卷文字与录入日期不替代微观数据的城市样本、权重和缺失审计；本包新增可准入城市观测为0，排名输入不变。

复现：`python3 research/2026-a/data/task4_v71_mexico/audit.py`。
