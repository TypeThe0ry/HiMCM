# V61 Phoenix: school-travel source scope audit

No new admissible high-school travel-duration observation was established. Preserve the current missing interval.

The [ASU original research repository](https://doi.org/10.48349/ASU/JTGD1I) exposes a newly located 2025 dataset with 276 observations and 48 variables. Its official metadata identifies the universe as parents of K–5 pupils and repeated cross-sectional waves in fall2021/fall2024. It therefore cannot supply current high-school travel data. The description concerns school travel modes and attitudes. Direct API access returned403 and the dataset page required JavaScript verification; no raw data or row-level duration fields were inspected.

The [City of Phoenix walking-plan guidelines](https://www.phoenix.gov/content/dam/phoenix/streetssite/documents/Safest%20Route.pdf) concern elementary pupils and recommended routes. They are not observed high-school travel times. Official indexed text was inspected; direct original download returned403, so no original is archived here.

[Audit metadata](audit.json) records provenance and access limits. These are explicit source exclusions, not an exhaustive claim that Phoenix data do not exist. No model, manuscript, or existing evidence was edited.
