# V57：Copenhagen历史微数据与Toronto高中校车研究核查

本轮没有取得可纳入城市评分的新通学时长观察；两城原有缺失区间保留。

丹麦国家档案馆的[TU存档12455](https://digidata.rigsarkivet.dk/aflevering/12455)覆盖1992—2003年。取得目录和人员字段页原始HTML，字段含年龄、居住市镇、权重及学习天数，但目录明确提供的是申请访问入口，未取得人员或行程记录。`Uddan`是最高已完成学历，不能识别当前高中阶段；亦不能将现代TU的职业编码直接套给这套旧库。这个路径不能绕过[V41公开工具的市级权限限制](../task4_v41_copenhagen/README.md)。

另外核查2024年发表的[Toronto与Ottawa校车及学业研究](https://onlinelibrary.wiley.com/doi/10.1111/cag.12957)。出版商索引文本显示其分析学校层面的校车乘坐比例与标准化考试成绩，包括9、10年级。摘要对较长通学时间的解释不能转化为已测得的时长分布。本次没有取得高中生时长表；出版商全文直接下载返回403，索引核查记录明确保存在`audit.json`，不冒充原始论文归档。未由校车比例推算分钟数，也未发送资料申请。

## 验证

`manifest.json`记录两个原始HTML的URL、访问时间、字节数和SHA256。运行`python3 audit.py`核对文件完整性、档案时期、申请入口及关键字段。此验证仅确认来源与访问条件，不证明任何城市通学估计。
