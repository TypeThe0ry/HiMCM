# Nairobi：取得TSC年度原件，尚无可配对的城市教师分母

本轮从肯尼亚议会机构库取得TSC《Annual Report 2024–2025》完整104页官方PDF（约32.8 MB）。师资章节的Table 2.1是全国新注册流量，Table 2.2是全国招聘／替补／实习转任流量；已检查目录、师资章节及Nairobi索引位置，未找到Nairobi在岗Secondary教师存量。招聘人数不能替代师生比的教师分母。本轮不改变Nairobi教育区间。

新增历史线索是政府《Presidential Working Party on Education Reform 2023》附录4.6及4.8。网页PDF阅读器可读NGO镜像中的表头和Nairobi行：102所公立中学、90名校长、111名副校长、2,650名教师，总计2,851；3,792是课程编制需求、941是缺口，均不能冒充实际教师人数。正文将相关TSC数据标为2023年3月。

该历史表尚未取得本地PDF原件：教育部原链接连接超时，NGO镜像的本地请求实际返回HTML挑战，另一路KHRC法庭附件下载超时。网页阅读取得的事实单列在`audit.json`，不称为原件下载成功。即使后续取得原件，仍需匹配同日期、同公私范围的学生数，并明确学校领导和BOM／私立教师是否纳入；不能将2,851直接与V40的2024年129,988名全范围学生相除。

## 已保存文件

- `tsc2024_25.pdf`：议会官方机构库原件；`tsc2024_25.txt`为pdftotext派生文本。

- `manifest.json`：两个实际响应的来源、字节数、SHA256及状态。
- `audit.json`：已检查章节、历史表事实及不能准入的具体原因。
