# V28 Istanbul: additional official household-survey routes

Accessed 2026-11-07. **No new admissible commute observation or model bound.** Prior V7/V8 Istanbul rejection audits were checked first. Existing high-school commute utility remains [0,1]. This package archives new official source checks, not repetitions of PISA or the 2007 attainment table.

## Verified official observations, excluded from model

1. [Istanbul SUMP report](https://skup.istanbul/wp-content/uploads/2024/11/SKUp_Asama-I_Rapor.pdf), March 2022, Table 3, PDF page 33 (zero-based page 32; printed spread 66–67): school journeys average **23.3 minutes**, attributed to the **2012 household travel survey**. The adjacent 41.9-minute figure concerns work. The 15-minute school figure is a **2040 target**, not an observation. The table gives no upper-secondary stratum, distribution or student denominator. Its wording refers to journeys to/from work or an education institution; it does not establish the required first home-to-school one-way person measure. No transform of this aggregate is admitted. Web PDF text verified the table, but local download returned HTTP 403 HTML, preserved honestly as `sump_report.html`.

2. [JICA preparatory report, annex](https://openjicareport.jica.go.jp/pdf/11819281_06.pdf), PDF page 20 / printed annex page 54, displays an Istanbul Metropolitan Municipality–BİMTAŞ **2005 household questionnaire**. The roster separately has age, education level, professional status, and an **“If Student” code**; the education/student legend assigns **Senior High School = 2**, while the professional-status legend assigns **Student = 5**. This is a more promising identification route than treating completed education as school attendance. However, a questionnaire proves neither available microdata nor completed survey results. We have not established person/trip linkage, actual time fields, weights, coverage or missing-trip treatment from this page, and have not assumed that this 2005 instrument is identical to the 2012 survey.

## Specific acquisition route and blocker

[B40 municipal open-data catalog resource](https://opendata.b40cities.org/tr/dataset/istanbul-transportation-master-plan-household-survey/resource/c8d21288-3026-461f-b913-c2e02e016617) is indexed with an IBB source link and metadata date 2023-05-18. It is **HTML metadata**, not microdata. It points to [IBB dataset](https://data.ibb.gov.tr/en/dataset/istanbul-ulasim-ana-plani-hanehalki-arastirmasi). The original report URL and CKAN package-show endpoint are recorded in `manifest.json`; both timed out locally, and the browser-fetch service could not obtain the report. Thus this run cannot audit the 2012 report's school-stage fields or tables. B40 API also timed out. We do not infer the source lacks these data merely because acquisition failed.

Next concrete step: obtain the IBB household-survey report plus deidentified roster/trip files and codebook, or an official weighted high-school tabulation. Verify current upper-secondary attendance, Istanbul target geography, first home-to-school elapsed duration, person weights, and retain eligible pupils without measured trips as missing bounds. The 2005 questionnaire identifies a potential stage field; the 2012 school mean identifies a duration-bearing survey. These two documents cannot be joined as if they described the same records.

`web_verified_checks.json` is a manual transcription of verified official web text, not original PDF bytes. `manifest.json` separates failed acquisitions and HTTP error HTML from successful documents. No model files edited and no bounds row generated.
