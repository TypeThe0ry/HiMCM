# V184：Helsinki年报人员数不转作教学FTE

新取得市府2024教育年报与OPH教师统计指南原件。年报第32—33页给出芬兰语市属高中教学人员684、瑞典语103，合计787；列名为人员数，不是教学FTE。第33页脚注注明包含休假者、替代人员、实习生及学徒，排除兼职按小时授课教师。两页已渲染核读，不能由该数直接构造市域高中师生比或未经证明的FTE包络。

第40页学生数芬兰语9374、瑞典语1377；第16页脚注明确学生数为20.9与20.1两次统计的加权平均，另列芬兰语成人学位生216。它不能自动与V163的2024全市StatFin18661名学生组成同参考日的师资比例。合法子集／超集界仍需要匹配的实际教学工作量及参考人群。

全文定位到的`henkilötyövuosina`在第40页青年工作坊活动，2024值98，单位是青年活动人年，不能误当作高中教师FTE。OPH指南指向Vipunen就业教师职业／年龄人数报告，并说明教师专项收集最近数据为2019；该指南未给出Helsinki匹配教学FTE。
