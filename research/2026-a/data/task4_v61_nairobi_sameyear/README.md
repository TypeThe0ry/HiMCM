# Nairobi：同日历年学生列取得，普查时点仍未配对

2024版KNBS官方教育工作簿已取得原件58,665字节，Table15.6的Nairobi City 2023年中学生为123,566（H50，表头2023*）。它与已存2025版的G51数值一致；这排除了直接把2023教师与2024学生129,988配对的年份错误。

PWPER2023的TSC县级表仍只取得网页索引转录：102所公立中学，2,650名非校领导教师，90名校长、111名副校长，总计2,851。本轮教育部原件连接超时，AfricaCheck报告镜像返回403；没有把失败响应保存为PDF。该表为TSC公立师资，BOM、私立教师未知，而且2023年3月师资与KNBS全年口径的共同参考时点尚未建立。

若另行接受三个条件——教师转录可靠、3月教师在学生统计时点仍属该县高中教师子集、县入学数覆盖目标学校——则可作条件下界15×2650/(123566+15×2650)=0.243393，教师上界仍未知。此值仅用于说明配对尚缺什么，不写入主模型。当前教育区间仍[0,1]，修改模型单元0项。

运行 `python3 research/2026-a/data/task4_v61_nairobi_sameyear/extract.py` 可核验两个工作簿哈希、表头、城市行和同年数值。`audit.json`记录条件及计算，`download_manifest.json`区分成功原件与失败请求。2025版原件复用[V40目录](../task4_v40_education/README.md)，历史师资转录见[V45审计](../task4_v45_nairobi/README.md)。

来源：[KNBS统计摘要表入口](https://www.knbs.or.ke/statistical-abstracts/)；[2024版教育原始工作簿](https://www.knbs.or.ke/wp-content/uploads/2025/02/Education-Training.xlsx)。查阅日期2026-11-07。另查县CIDP2023，相关4200教师属于小学、1037属于ECD，未当作中学师资；新检索未建立2024或2025县中学教师存量。
