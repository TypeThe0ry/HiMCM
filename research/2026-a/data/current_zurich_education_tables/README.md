# Zürich education chart data leads

**Admissions: 0.** The archived official HTML embeds chart loader endpoints rather than numeric tables. Two official `zh.ch` snippets were retrieved: the instructional FTE chart and the first Mittelschulen pupil chart. Each response is a short HTML/JavaScript wrapper containing an Observable notebook module URL; neither response contains observations, field schemas, geographic breakdowns or stage/provider partitions. Both directly linked Observable module URLs returned HTTP 403 to the standard client; a separate web open also reported them inaccessible. The modules were not available to inspect for file attachments or schemas. No access controls were bypassed. Thus no city upper-secondary teaching-FTE lower bound or matched all-provider pupil upper bound was established, and no ratio or utility bound was calculated.

The parent official [FTE page](https://www.zh.ch/de/bildung/bildungssystem/zahlen-fakten/entwicklung-des-schulpersonals-an-mittelschulen-und-berufsfachschulen.html) describes its FTE chart as covering publicly funded Mittelschulen and vocational schools in the canton; it does not establish a city-school-only series. The [pupil page](https://www.zh.ch/de/bildung/bildungssystem/zahlen-fakten/lernende-an-mittelschulen.html) covers Mittelschulen with varying stages and financing. A useful future extraction would need actual values and schema, city-school geography, teaching-only FTE and pupil/provider/stage nesting at matching dates; canton staff totals or residence-based pupil counts cannot fill those roles.

`provenance.json` records the exact official snippet URLs, UTC retrieval, HTTP 200, content type, byte counts and SHA-256. The original snippet response bytes are preserved here. Failed module requests are also recorded in `provenance.json`; no error page is treated as data. Neither existing source captures nor the model or manuscript were changed.
