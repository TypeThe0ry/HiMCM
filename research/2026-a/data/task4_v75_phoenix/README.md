## 毕业统计方法检索

Arizona State Board的2024年11月、12月会议纪要搜索摘录讨论了并行入学的CC退出码、线上学校毕业归属，以及按FTE处理的建议。11月摘录特别指出，毕业归属可能由最后提交的退出码决定，而不由最后上课地点决定。这说明行政毕业归属与实际就读地点需要分开识别。

两份纪要的原PDF下载及web-open均返回403，本轮**未取得完整原件**。[检索笔记](methodology_search_notes.json)明确标为官方页面的搜索索引摘录及释义，不作为完整业务规则审计。委员会讨论中的FTE建议没有被当作已实施规则，也没有写入模型。
