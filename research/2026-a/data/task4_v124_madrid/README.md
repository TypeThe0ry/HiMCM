# Madrid：市域地铁清单的真实补充

CRTM的2026登记记录支持**191个市内地铁站群**这一保守子集。原293条地铁记录中，按省28／市079筛出242条；去除2条无名称、无线路的记录，再按提供方的地铁网络站代码合并240条具名记录，得到191个站群。Noviciado／Plaza de España和Embajadores／Acacias各合为一个联通站群，避免把换乘线路记录重复计数。51条市外记录全部排除。INE官方元数据独立确认Madrid市的代码28079。

采用冻结用户表人口3,527,924（2025，不另行核验或替换），得到每10万人5.414站群、交通效用下界0.09770010875，上界继续为1。这是2026-05-29登记库存与固定2025人口的条件密度，不是共同2025年普查、当前实时运营清单、全模式站点总数或青少年可达性。没有加上公交、近郊铁路及轻轨，以免跨模式重复计数。`SITUACION`字段不被擅自解释为开闭状态；临时停运无法从该登记库存重建。

官方CRTM域名入口的本机DNS失败后，原始提供方ArcGIS服务可访问，保存了完整293条记录、图层定义、服务和项目元数据及INE代码说明，均有URL、访问日和SHA256。它们是实际HTTP原件，非搜索摘要反推的站数。`extract.py`离线核验哈希、完整响应、筛选和合并，输出逐站群CSV、候选观测及审计。`candidate_only`表示主模型需独立复核准入；提取本身不修改CSV、区间或注册表。

教育线索本轮未准入。市教育页与区域开放数据提供了教师数据入口，但本机原始下载超时；检索中的Bachillerato标题不能证明教师数包含兼教其他学段人员或使用FTE。没有将区域教师、全学段教师、人头或不完整记录与市域高中学生强行相除。所有失败及成功入口均保留在`retrievals.json`，失败不生成数值。
