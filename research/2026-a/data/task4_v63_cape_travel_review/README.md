目标为182人、171户、120个目标PSU；分箱人数82、68、25、5、2，没有目标内未知时长。独立复用资格逻辑检查得到0个optional成员。全城3953条人员记录、216个PSU、14层，每层至少4个PSU，全部person_wgt正且有限；城内设计层不含其他metro记录，PSU全文件不跨层。人口记录以uqnr/personnr唯一。
