# Tokyo：38个具名大江戸線车站的供应下界候选

东京政府开放数据原CSV提供38个大江戸線车站名称、地址及JGD2011坐标。38名称、地址、坐标对均唯一；都庁前只出现一次。全部地址在Tokyo23特别区中的10区，因此与保留人口9,983,365（2026）的既有23区解释相容。其他线路、运营商及交通方式不计，当前候选交通密度效用为`[0.0075551488587997356,1]`。

这是一份“都営地下鉄 窓口一覧 大江戸線 > 駅一覧”窗口／售票服务目录中的具名车站子集，不是全市站点普查、站台数量或定期券机器数量。原CSV中“定／自”是定期券人工／自动售票设备标记；按具名车站行计数，不对设备标记求和。最近两站坐标距离约409.8米，只作为别名／同址复查诊断，不用距离聚类重写原生车站身份。具名与地址去重足以避免该单线路内的环线及换乘重复，跨线路合并没有发生。
