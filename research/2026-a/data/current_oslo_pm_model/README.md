# OECD Oslo exposure source check

OECD's [Air pollution – Cities and FUAs](https://data-explorer.oecd.org/vis?df%5Bag%5D=OECD.CFE.EDS&df%5Bds%5D=dsDisseminateFinalDMZ&df%5Bid%5D=DSD_FUA_ENV%40DF_POLLUTION&df%5Bvs%5D=1.2&lc=en) describes Plume Labs pollutant grids weighted using GHS-POP. Its cities approximate urban centres using local administrative units; FUAs add commuting zones. Population-grid vintage and exact Oslo boundary vintage were not verified here. These definitions do not establish equivalence to EEA's viewer or to a fixed 2015 estimated area; they do not establish the original CSV's source.

`oslo_exposure.csv` is the exact OECD API response selecting NO001C and NO001F, annual frequency, PM25_POP_EXP and MCG_M3, all available periods. `structure.xml` is the official dataflow structure with references, whose code labels name both areas Oslo. Select rows by REF_AREA and TIME_PERIOD: the latest returned year is 2023. The city (NO001C) row is 8.506857989031039; FUA (NO001F) is 7.934470167063854 µg/m³. The latter rounds to 7.9 at one decimal but is **2023**, not 2024, and a numeric match cannot establish lineage. Neither is an admissible 2024 Oslo row. DECIMALS is 1 in both rows; the long values are the API's OBS_VALUE. `receipts.json` records retrievals and hashes.

WHO's [SDG 11.6.2 description](https://www.who.int/data/gho/data/themes/air-pollution/modelled-exposure-of-pm-air-pollution-exposure/1000) describes national exposure estimates broken down by urbanisation class; it does not establish an Oslo-specific row. No new 2024 source admission is supported.
