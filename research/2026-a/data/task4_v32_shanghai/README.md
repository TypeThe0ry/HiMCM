# 上海2025学年普通高中师资更新

上海市教委[2025学年普通中学统计](https://edu.sh.gov.cn/xxgk2_zhzw_tjsj_01/20260610/890926a33cbf443d9abf07c6f65b7734.html)提供全市16区高中在校生235542人、高中专任教师23999人，师生比9.8146589441，成本效用15/(15+PTR)=0.6044814089。

两份原始PDF已通过官方网页下载并保留字节、URL和SHA256。teachers.pdf末列为高中专任教师，不能误用初高中学生或全部中学教师。students.pdf高中在校生列对应三个年级总和。extract.py重新从原PDF提取，核对16区合计、每区三个年级合计、初高中教师合计；独立agent另已目视核验原PDF表头。

范围为全市普通高中阶段，含不同学校类型中的高中部分，排除中职。专任教师是人数，不是FTE；此指标衡量师资配置，不是考试成绩或教育因果质量。2025值替换2024的224186/22686，不跨年取交集。原2024教师数仅官方索引转录，本轮完整原PDF改善了来源追溯。

复现：`python3 research/2026-a/data/task4_v32_shanghai/extract.py`。
