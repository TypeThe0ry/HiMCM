# Tokyo：补入六年制中等教育学校的真实高中部学生

2025年5月1日官方中等教育学校表确认：8所学校共有前期学生3,564人、后期学生3,435人，全部课程合计555名本务教师。后期课程对应高中课程标准，因此可将其3,435名学生纳入原303,468名普通高中的条件比较；不能把555名全校教师全部当成后期教师，也不能按学生或年级比例猜分配。

| 官方学校类型 | 学校数 | 后期学生 | 前后期合计本务教师 |
| --- | ---: | ---: | ---: |
| 国立 | 2 | 727 | 105 |
| 公立 | 6 | 2,708 | 450 |
| 合计 | 8 | 3,435 | 555 |

原表脚注明确私立中等教育学校不存在。后期学生均为全日制；男女合计、三学年合计和国公立合计均已核验。

## 学校类别、阶段和教师口径

[2025调查定义](../task4_v46_tokyo/gk25qf0001.pdf)第2页第9项说明，中等教育学校是将初中与高中整合为一所学校的法定学校类别，前期按初中标准、后期按高中标准。原高等学校表7与本次中等教育学校表9属于不同法定学校类别；没有把“附设初中的普通高中”再次加入。

同文件第1页第3项规定，本务教师按主要任职学校计；兼任多校时按薪资来源、金额或授课时数确定本务学校。因此将两类学校的本务教师池分开核算，不把跨校兼务者重复加入。该口径是按学校归属的教师人数，不是FTE或完整授课工作量。

调查方法文件确认统一日期为2025年5月1日，并采用学校全数调查。旧高中表303,468名学生／19,446名本务教师和两份定义PDF按原哈希复用，未复制或改写旧原件。

## 不猜测教师分配的覆盖扩展

设六年制学校中可归于后期课程的本务教师人数为H。当前没有按前后期分拆的教师统计，保留H∈[0,555]。此为保守外包络；下端点不宣称学校实际上没有高中部教师。

    扩展学生数 = 303468 + 3435 = 306903
    对应教师人数 ∈ [19446,19446+555] = [19446,20001]
    u(H) = 15(19446+H) / [306903+15(19446+H)]
         ∈ [0.4872927014,0.4943254278]

旧普通高中范围效用为0.4901051485，落在新扩展范围区间内。新旧覆盖总体不同，不把区间与旧点相交来人为收窄。新增的是3,435名真实高中阶段学生的覆盖，同时显式保留教师阶段分配缺口。

本次仍不宣称覆盖全部高中阶段：通信制、特教高中部、专修学校高等课程继续另列。下载的通信制表8实际为11,793名学生、244名教师，含4所独立校和7所併置校；它的远程学习人群、校址共用及教师归属需要独立审核，未直接并入本次人数。
