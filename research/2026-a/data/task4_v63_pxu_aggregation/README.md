# V63 — Phoenix毕业队列：排除不适用的转校重复解释

本轮新增证据未解释学校队列6287与学区6285相差2人；无新增毕业人数，原有区间不变。

[官方2025–26+ FSI业务规则](https://www.azed.gov/sites/default/files/2025/08/FSI%20Business%20Rules%20SY%202024-2025%2B_0.pdf)的Static File章节（页19，索引页脚标记10/2/2025）说明转校者可能进入两个学校的static file，但同时明确毕业率、辍学率使用单独报告，不包含在该static file内。因此这一“两校记录”机制不能直接解释毕业队列加总差异。该来源只排除一种错误解释，没有证明毕业记录绝不重复。

[官方毕业率训练材料](https://www.azed.gov/sites/default/files/2021/09/Grad%20Rate%20Training.pdf)对五年队列说明：转校者进入新校队列，并行在读者归发文凭的学校。它没有给出本次2024届四年队列的实际交叉计数，不能据此把观察到的净差2当作重复人数上限。路径年份不是已核验的材料生效日期。
