# Shanghai 2025：高中与中职师生口径复核

本轮下载了两份新的官方原件，确认“学校类别”不能直接等同于“学生所读课程类别”。没有找到能够配对的2025年全市成人中职在校生数及同课程教师数，因此不新增模型观测、不缩小缺失区间。

## 新的可核验事实

1. [上海市教育考试院：2025年成人中等职业教育招生工作实施细则](https://www.shmeea.edu.cn/page/21000/20241224/18990.html)规定：普通中专、职业学校、技工学校也可以经批准开展成人中职教育；成人中职并非只由独立成人中专提供。页面发表于2024年12月，规则适用于2025年。原件：`adult_admission2025.html`。
2. [长宁区2025年国民经济和社会发展统计公报](https://zwgk.shcn.gov.cn/xxgk/tjxx-tjjzdgz/2026/201/81949.html)第五节教育表列出职校1所、在校生1716人，并明确注释“职校在校学生数包括职校生和成人中专学生数”。原件：`changning2025_bulletin.html`。这是区级口径实例，不能当作上海成人学生总数，也不能据此断言全市10.90万必定包含成人。

两份原件均成功HTTP200下载，字节数和SHA-256载于`retrieval.json`；`extract.py`验证原件散列、表格人数、注释和招生范围，并生成`audit.json`。

## 对V54条件计算的影响

V54中职教师总数7273人，扣除成人中专学校59人，得到7214人。这个扣除动作仅排除一种**机构类别**，尚未排除普通中职机构内服务成人课程的教师，也不能证明其与全市公报10.90万学生属于同一课程覆盖范围。新证据使这一未决条件具体化，但没有提供可用于替换的全市同口径师生总数。

继续保留既有普通高中观测：学生235542人、专任教师23999人；这些是V54继承值，本轮没有重新估计。中职并入高中阶段的条件值仍不得作为正式输入。不能用区级1716人倒推出成人人数，也不能用2024年学生数扣除2025年总数。

## 其他检索与待补数据

上海市社会综合统计报表制度（2025年统计年报）分别设置ISJY02“普通中等职业教育基本情况”和ISJY11“成人、网络（开放）教育基本情况”，后者含成人中等专业学校。但表式不是填报结果，也未给出可完成两项数据配对的映射。官方PDF直接请求返回403，记录于`retrieval.json`，未将错误页面保存为PDF；它不作为本目录数值提取依据。

仍需2025年全市普通/成人中职在校生存量分表、明确覆盖说明，以及同课程范围的教师配置数。只有取得这些数据，才能决定是否扩大当前普通高中师生比的覆盖范围。
