# Phoenix：首次接入2023/24私校原始记录

从[NCES官方数据页](https://nces.ed.gov/surveys/pss/pssdata.asp)下载完整PSS2023/24公开CSV压缩包（22510条学校记录），并结合[原始手册与问卷](../task4_v83_pss_docs/README.md)提取高中年级人数。原件ZIP及页面逐字节保留，下载地址与SHA-256见[清单](manifest.json)。

按物理州代码PSTANSI=4筛选307条Arizona记录，再将2024坐标叠加此前保存的Phoenix市界，得到76条市内记录，其中33条有9—12年级学生，公布人数合计6109。对应年级人数及开设标志均未标为插补或人工调整。本次记录汇总未剔除线上或混合教学学校，位置记录不等于实际到校。该市界是现有边界，未独立核实2023历史边界。邮寄城市与边界选择不一致的记录有13条，另存[对照](mailing_boundary_disagreements.csv)；不能只用PCITY筛选。

## 教师单位的实质修正

这33条记录的NUMTEACH合计888.6，是全K—12及无年级教学人员的档位中点折算FTE，不是高中专属FTE。问卷Q10五类人数为全职、3/4至不足全职、1/2至不足3/4、1/4至不足1/2、不足1/4，记为 $n_1,\ldots,n_5$。其公开折算为

$$T_{mid}=n_1+0.875n_2+0.625n_3+0.375n_4+0.125n_5.$$

保留档位信息可得闭包外界

$$T\in[n_1+0.75n_2+0.5n_3+0.25n_4,\ n_1+n_2+0.75n_3+0.5n_4+0.25n_5].$$

33校合计为 **[867.25,909.50]**，这些工作档位字段没有插补或调整标志。该范围仅处理档位内未知工作份额，未处理高中学段分配、未响应学校或城市总体覆盖。脚本按每校最多0.05舍入差核对公布FTE与中点公式。

## 为什么尚未改变全市指标

PSS采用名单与地区双抽样框，公开响应记录不能作为完整学校普查；手册报告保守覆盖估计73.14%，Arizona未提供名单更新，不得据此把未观察学校当零。人口总量推断需PFNLWT及88个BRR重复权重；本目录只报告未加权的公开记录合计，没有把权重当确定性的总体上限。

此外，这份私校数据属2023/24，已有公校数据属2024/25；跨学段教师不能直接除以高中学生数。保持两个年份和覆盖状态，不相加制造全市总量。`main_admitted=false`，Phoenix教育界仍[0,1]。本轮实质进展是取得私校微观原件、明确遗漏来源和教师档位不确定性，为同年公私校覆盖分析建立可复核输入。

复现：`python3 research/2026-a/data/task4_v83_phoenix_private/extract.py`。脚本验证ZIP CRC与哈希、学校ID、开设标志与结构性空值、地理筛选、插补标志及FTE折算；输出[公开记录清单](released_city_records.csv)与[汇总](summary.json)。记录是公开学校资料，不包含学生个人信息。
