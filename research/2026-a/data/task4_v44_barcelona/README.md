# Barcelona FRESC：取得真实分学段通学方式表

官方公共卫生机构ASPB的FRESC 2025公开查看器包含按当前课程分组的学校通学方式数据。下载的原始制表符文件`tp_anar_a_3.csv`显示：2n Batx组公共交通“是”467、“否”492、合计959；2n CFGM组分别698、129、827。这里保留发布表的计数，未将其解释为城市全体学生人数，也未把不同课程合并为精确14—18岁人群。

该表测量是否使用公共交通到校，不能换算分钟。2021方法手册列出分方式到校分钟变量，但已检查2021及2025查看器公开变量目录，交通模块仅公布方式和环境感受，未列分钟统计。字典有变量不等于取得了学生原始记录。本轮不改变Barcelona通学时长区间。

`viewer.html`及三个公开JS文件记录表格访问路径；两年菜单JSON、2025原始表和2021方法手册均保持下载字节，来源及SHA256见`manifest.json`。2021手册只用于定位该年变量，不作为2025抽样口径的替代证明。未提交数据申请或发送联系消息。
