# Oslo current stop-place candidate

Entur's current Oslo NeTEx export supplies native StopPlace identities and parent references. The reproducible consolidation produces 517 provisional spatial basins from 829 mode-bearing roots. With the fixed population 727,797, the corresponding diagnostic density is 71.0363 per 100,000 and the transformed interval is [0.586901, 1]. This is an exploratory candidate: the 250 m rule does not prove that two separate basins cannot be parts of one physical interchange. Independent identity and geographic review is required before using this as a lower bound. Do not add it to the earlier 89 metro stations.

The original response is `03_Oslo_latest.zip`; `download.json` records the exact URL, capture time, HTTP status, server headers, size and SHA-256. Entur's [data page](https://developer.entur.no/open-data/stops) identifies this as the Oslo regional current-stop export and documents daily publication and NLOD licensing. Its [National Stop Register documentation](https://developer.entur.org/pages-nsr-nsr/) describes the registry. The archive names a 2026-11-09 export; it is not a 2025 inventory. Boundary scope is the native `KVE:TopographicPlace:0301` reference, not an independently repeated polygon test.

Run `python3 research/2026-a/data/current_oslo_transport/verify.py` from the repository root. The script includes mode-bearing bus, tram, metro, rail and water StopPlaces, collapses their native parent references, excludes records with missing relevant coordinates or missing parents, and then merges roots transitively when any contributing centroid is within 250 m or has the same casefolded name. The latter steps intentionally merge distinct stops too. `conservative_basins.csv` records every contributing root and mode-bearing child ID; equal basin numbers are merged. Radius and name do not establish full physical deduplication, operational service, or inventory completeness. The utility formula is `d = count * 100000 / 727797`, `u = d / (50 + d)`; the upper endpoint is 1. No original data or weights changed.
