# 第二轮蒸馏：把好文章拆成可检查的论证动作

2026-11-07。第一轮说明章节功能，这一轮追到具体段落：**读者为什么应该相信这一步？这一步允许作者说到哪里？**

## 本轮范围

- 针对13篇论文的正文重点选段，建立[36张证据卡](evidence_cards.md)，每张分开记录观察、解释、对本题的迁移和结论边界。
- 补充定位并选段复核2023年九篇Outstanding的摘要与任务组织；14076摘要实际位于PDF第2页，不能把第1页封面当成空摘要。
- 将2025 B题3篇O奖与2篇F奖放在同一任务下观察。17372为扫描件，补做24页OCR，针对关键页视觉核对；OCR不是公式复算。
- 新附2023合集和两篇F奖文件都与现有文件逐字节重复，论文库仍为68篇；见[附件去重记录](../round2_attachment_intake.json)。

本轮没有复现所有计算、重新核验所有外部数据或获取评分表，不能解释奖项因果，也没有给论文打“应获什么奖”的分数。所称页码均为PDF物理页码，可能与文内印刷页码不同。

## 本轮最重要的六个结论

1. **复杂方法之前，先给出有意义的现实分解。** 16738将环境影响组织为过程环节；11135将资格、偏好和成本分开。学的是分工与接口，不是复制模型名。
2. **理由、证据和假设承担不同责任。** “为了比较方便”能解释简化动机，不能证明简化无害；15041的代理清单与8992的假设正好用于训练这一区分。
3. **验证有不同对象。** 17372的方法间排序一致性不等于现实有效性；15504的拟合/交叉验证协议也不能替代对切分、依赖结构和修正步骤的检查。
4. **敏感性必须追到决策。** 16442展示参数、得分、名次和首选的闭环；16742与17372的相关段落主要展示权重变化。权重稳定与推荐稳定是不同主张。
5. **重大修订应有可定位的失败机制。** 14140从简单散播到路径与存活过程，提供了叙述次序的例子；但新增机制本身仍不证明现实精度更高。
6. **获奖身份不是逐句背书。** 14323第4页存在可直接核对的乘法不一致；8992的所读段落出现样本数口径差异。赏析结构时仍需独立校验数值、单位与前后称谓。

## 对当前五指标方案的直接启发

“容易取得”“公式简单”“没有问卷”分别只回答可得性、计算性和一种主观来源问题，尚未回答概念覆盖、跨城可比和权重合理性。五指标能否代表高中生生活，需要另行论证；本轮不代队伍决定最终指标。

四位成员的生活城市可以帮助发现遗漏、解释反常结果和提出反例，但个人经历不能独立验证全球榜单。当前截图仅明确上海，其余城市仍待用户提供。

## 与Overleaf的关系

这些是研究与编辑辅助材料，不是替换正文的指令。本轮没有改动`main.tex`、`ref.bib`或`mcmthesis.cls`，也没有声称编辑了在线Overleaf。待队伍采用具体做法时，应先回到Overleaf最新正文，并用实际已完成的计算支撑文字。
