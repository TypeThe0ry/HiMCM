# 任务4：建立、解释并修正城市评估模型

> 后续进阶方案：见[基于获奖队伍与昨晚提交的大胆修订](task4_bold_revision.md)。本文件保留为透明基准及技术细节。

日期：2026-11-07。状态：可执行的候选研究方案；尚无完整、经核验的真实城市数据矩阵，不产生城市得分、排名或修订成效。本文为本地研究笔记，不修改 Overleaf 正文。

## 1. 模型具体做什么

在团队选定的至少10座城市中，比较普通14—18岁高中生的生活条件，给出主情景下的排序和首选；进一步说明首选适合哪些偏好、是否受数据误差影响、其他城市输在哪里，以及什么变化会使推荐翻转。

采用“PCA诊断 + 固定参照TOPSIS + 蒙特卡洛情景分析 + Kendall排序检验”。这些方法各有职责，不宣称组合本身是原创算法。

| 环节 | 要回答的现实问题 | 应交付的结果 |
| --- | --- | --- |
| 指标与口径审查 | 我们是否真的测量了高中生生活？ | 指标定义、方向、来源、年份、空间边界与遗漏说明 |
| PCA诊断 | 是否把同一类城市优势重复算了几次？ | 相关矩阵、主成分解释方差、载荷与冗余判断 |
| 固定参照TOPSIS | 按预先公开的偏好，哪个城市更接近理想生活？ | 主情景得分、全排序、各城短板 |
| 蒙特卡洛分析 | 偏好和输入变化后，推荐还成立吗？ | 第一/前三名占比、名次区间、两城胜出占比 |
| Kendall tau-b | 排序对修订、删指标或误差有多敏感？ | 全榜一致性，同时单独检查头部翻转 |
| 修订与复核 | 发现的缺陷是否得到修正？ | V0/V1对照、单项消融和未解决局限 |

## 2. 先保证评估对象成立

最新五指标稿涉及凶杀率、PM2.5、房价收入比、10km行车时间及宽带速度。它们可作为数据试算入口，但还不足以完整代表高中生生活。

- 凶杀率仅覆盖安全的一个方面，不能代表全部青少年安全。
- 房价收入比是住房负担代理，不能直接等同学生家庭日常参与活动的成本。
- 10km行车时间是道路机动车通行代理，不能改名为学生通学时间或公共交通体验。
- 宽带测速反映参与测速样本的连接性能，不能直接代表所有学生的数字资源可及性。
- 五项缺少直接的教育与课外成长测量。应补充可靠指标，或明确缩窄评价对象；不能据此无条件声称完整评估“最适合高中生”的城市。

原始五指标稿的来源主张与数值示例仍待核验，本文不将其作为实测数据使用。特别是无主观打分并不意味着跨城市口径一致。

权重先分配给概念维度，再分配给维度内指标。若一维有三项、另一维只有一项，不能仅因数据更多就让前者自动获得三倍影响。保留等维度权重作为透明基准；不同偏好作为单独情景。

## 3. V0：建立可以解释的基准

### 3.1 固定参照转换

对原始指标 x_ij，预先指定下界 a_j、上界 b_j，且 b_j>a_j：

正向指标：z_ij = clip((x_ij-a_j)/(b_j-a_j), 0, 1)。

负向指标：z_ij = clip((b_j-x_ij)/(b_j-a_j), 0, 1)。

所有 z 越大越好。参照界优先来自有解释力的外部范围；若不得不从样本确定，须冻结后用于后续情景，并披露初始样本依赖。不要每次增删城市都重新计算min–max或向量归一化。对超过边界后被截断的城市，报告饱和情况并检查参照界合理性。

宽带等指标可讨论边际收益递减的效用转换，但拐点需要依据或公开情景，不能为改变冠军临时设定。

### 3.2 固定理想点的加权距离

令权重 w_j≥0 且 Σ_j w_j=1，理想点为全1，负理想点为全0：

D_i+ = sqrt(Σ_j w_j(1-z_ij)^2)，

D_i- = sqrt(Σ_j w_j z_ij^2)，

C_i = D_i-/(D_i+ + D_i-)。

报告 100C_i，按其递减排序。这是采用固定参照、加权欧氏距离的TOPSIS变体；等价于对 sqrt(w_j)z_ij 计算普通欧氏距离，不能与“先乘w再计算平方距离”的权重约定混用。正负理想点是参照目标，不要求存在某座真实城市同时达到。

由于尺度、权重和理想点在同一情景内固定，一座城市的得分不随其他候选的加入而改变；新候选仍可能插入榜单，所以名次编号可能变化。单调性允许截断造成相同分数，不能保证任何改善都会严格加分。

解释：C是相对理想点的接近程度，不是生活满意概率；80分也不表示比40分的城市生活质量高一倍。

## 4. PCA如何帮助，而不是替代价值判断

PCA用于检查变量共同变化与潜在冗余。将待诊断指标标准化到均值0、标准差1，再做PCA；零方差指标不进入PCA并单独记录。PCA输入标准化与主评分的固定参照效用转换是两个不同步骤。

应报告：主成分解释方差、特征向量/载荷所采用的具体定义，以及每个主成分由哪些指标主导。若使用“载荷=特征向量×特征值平方根”，须明确，不能和特征向量混用。

例如多个经济条件指标共同主导某个主成分，这是重复测量的线索；再检查它们是否测量相同概念。相关不等于重复，住房负担和教育机会即使相关，也可能各自不可缺少。

不建议直接以解释方差为生活重要性权重：城市间差别大的变量未必对学生更重要。主成分的符号可整体翻转，不能把正负号天然解释为好坏；将混合好坏含义的主成分直接送入TOPSIS也可能失去可解释性与原指标单调性。

若证据支持冗余，优先合并同概念指标、保留代表指标或固定维度总权重，再用原有可解释指标评分。仅有五项且概念不同，不必强行降维。25城或更少的样本中，应以留一城分析检查载荷稳定性；很小的样本不支持把一次PCA结果当成稳定结构。

## 5. 蒙特卡洛如何把单次榜单变成有条件的推荐

每轮抽取一组偏好与输入，转换指标并重新计算同一模型。示例起始轮数为10,000，最终检查增加轮数后头部占比是否稳定，保存随机种子与抽样规则。

先分开三组实验，再考虑合并：

1. 仅改变权重，固定数据：检验偏好敏感性。
2. 仅改变输入，固定权重：检验数据不确定性。
3. 同时改变：检验共同作用。

权重可在明确的可接受范围内抽样；Dirichlet(κw0)是围绕严格正的基准权重w0取样的一种选择，κ控制集中程度。κ及边界需做情景比较，不能把一种分布称为所有高中生偏好的真实分布。若有维度层级，应先抽维度权重，再抽维度内权重，保留原来的概念结构。

输入分布优先根据来源误差、原始样本或合理上下界建立。有上下界但没有分布依据时，先报告区间/压力情景；若采用均匀抽样，明确它只是分析假设。不能对所有指标统一加“±10%正态噪声”后称为真实误差。有关联的原始输入或共同来源误差应联合处理，避免抽出互相矛盾的城市状态。PCA诊断修订后的结构通常先冻结，重新拟合PCA可作为额外结构敏感性检查。

每座城市报告：

- 基准得分与名次；
- 第一名情景占比 b_i1、前三名情景占比 b_i,top3；
- 中位名次及情景名次的5%—95%分位区间；
- 关键竞争城市之间的胜出占比 p_ih。

占比均针对声明的抽样分布，不是“城市客观上最好”的概率、学生支持率或统计置信区间。得分差可配合一并展示，避免把很小差距包装成明显优势。

同分按预设数值容差识别；并列城市均分其占据的名次概率质量。两城胜出占比中，平局贡献0.5。名次分位数应由该分摊后的名次分布计算，避免以名称决定冠军。

## 6. 如何分析结果

| 结果现象 | 可以作出的解释 | 下一步 |
| --- | --- | --- |
| 基准第一，且广泛情景仍居前 | 推荐对所测试假设较稳健 | 指出适用人群与未覆盖条件 |
| 基准第一，但第一名占比低 | 冠军依赖特定偏好或输入 | 找出翻转权重、关键数据与竞争城市 |
| 很少第一，但经常前三 | 更像稳妥候选 | 与追求特定优势的候选分别解释 |
| 两城频繁互换且分差小 | 数据/偏好不足以支持强烈优劣判断 | 仍给出预设主情景排序，同时报告头部集合 |
| 某城一删指标就大幅变动 | 结论集中依赖该指标 | 审查代理效度、来源与是否重复计权 |
| 放宽某项数据范围后名次很散 | 不确定性来自测量 | 优先补这项数据，而非调权让其稳定 |

城市短板可用理想距离的平方项 A_ij=w_j(1-z_ij)^2 诊断，并报告其占 Σ_j A_ij 的比例；分母为0时表示达到理想点，不计算该比例。该比例解释“理想距离来自哪里”，不是最终C得分的加法分解。

建议输出五张图表：基准排名及维度表、PCA载荷图、名次分布热图、头部两城偏好翻转图、V0/V1变化及原因表。

## 7. Kendall系数如何使用

使用 Kendall tau-b 比较同一组城市的两组得分或按城市ID对齐的名次向量，处理并列。不要把两个按名次排列的城市名称列表直接当数值向量输入。某一榜单全部并列时系数可能未定义，应如实报告。

比较对象包括：V0与V1、基准与各轮情景、完整指标与删一指标版本。另可与概念接近且来源独立的青少年城市评价作有限外部比较；成人宜居榜与本题对象不同，不能充当标准答案。

tau接近1表示两两顺序较一致，接近0表示总体一致性弱，接近-1表示大体反转。它检验排序一致性，不证明评价正确；也没有通用的“tau>0.8即合格”标准。

全榜一致性可能掩盖冠军变化。例：25城无并列，仅前两名互换，tau=1-2/300≈0.9933，但首选已改变。因此必须同时报告冠军翻转率、前三名重合情况与两城胜出占比。模型产生的多次排名不是独立抽样的学生意见，不应将常规p值当作模型正确的证据。

## 8. 如何修正：由具体失败决定修改

| 可观测缺陷 | 有针对性的修订 | 如何证明修订有用 |
| --- | --- | --- |
| 同概念多项重复支配得分 | 合并/删去重复项，或固定维度总权重 | 用相同城市与数据做单项消融，解释哪些重复优势被削弱 |
| 教育和成长内容缺失 | 补充可比指标，或缩窄研究结论 | 展示内容覆盖及数据口径；将内容变化与算法变化分开 |
| 高宽带等优势掩盖基本健康/安全短板 | 比较边际收益递减效用；有依据时加入基本要求 | 在同一输入上检查补偿行为、门槛敏感性及排除代价 |
| 加入无关城市使原有城市顺序改变 | 冻结尺度和参照点 | 加入受支配候选，检查原有得分与两两顺序 |
| 权重稍变就换冠军 | 扩展偏好情景并公开推荐条件 | 找出翻转区间；不以“调到稳定”为修订目标 |
| 缺失城市被均值填补成假稳定 | 补核心数据，或作有依据的上下界情景 | 报告缺失与名次范围，必要时排除并解释样本选择 |
| 社区差异被城市均值遮蔽 | 有一致社区数据时增设较不利学生分析 | 报告真实分布；仅有均值时保留为局限 |

冻结V0的输入、权重、代码和结果后再实施V1。结构修订优先使用共同样本与共同数据对照；新增指标或更换代理的变化另外记录。一次只改变一个关键环节，再组合保留的修改，避免无法解释排名为什么变了。

修订的成功标准是测量更贴合研究对象、纠正已识别的重复计权或候选集依赖、明确不确定性的来源。名次变化更小不是通用成功标准，符合团队个人印象也不是。若新数据纠正了旧误差，tau下降可能恰恰是必要的。

题目要求的重大修订应有真实数据诊断与前后对照。PCA确认重复测量后改变指标结构可能构成重大修订；仅附加tau数值或蒙特卡洛图、却不改变评估或推荐逻辑，不足以自动证明完成重大修订。

## 9. 写作顺序与实施边界

论文按“评估目的 → 指标如何对应高中生体验 → 基准结论 → 失效证据 → 修订 → 稳健性与适用条件”组织。公式服务于每个决策，不需要长篇介绍算法历史。

可用以下句式填入真实结果：

> 在预设主情景下，[城市]排名第一。其优势主要来自[维度]，短板是[维度]。在声明的[权重/数据]情景中，它获得第一名与前三名的占比分别为[实算值]和[实算值]；当[具体条件]时，[另一城市]超过它。我们在V0中发现[真实问题]，因此实施[修订]；共同样本对照表明[诊断变化]，但仍受[局限]影响。

当前仅完成方案设计。真实排名、载荷、tau、占比、修订效果及冠军均须在数据核验后计算，不得填入臆测数值。
