# 证据、数据与科学主张规范

[返回团队必读入口](../../GUIDELINES.md)

每项重要结论形成可追溯链：**主张 → 指标定义 → 数据与处理 → 计算结果 → 图表／文字**。

## 主张与证据的对应

| 主张 | 对应证据 |
| --- | --- |
| 样本中的描述性差异 | 同口径原始值或可复算汇总 |
| 模型排名与推荐 | 指定版本、指标方向、权重、缺失处理和结果文件 |
| 某机制带来改善 | 固定共同输入的基准／修订对照或合适的消融 |
| 对误差或偏好稳健 | 明确扰动范围、运行结果与推荐变化 |
| 空间形态解释 | 有来源、日期、坐标系和比例尺的地理资料 |
| 预测或因果判断 | 与主张匹配的验证设计或识别依据；相关图本身不足以支持 |
| 假设情景结果 | 明示假设输入与模型输出，区分实测资料 |

结果与基准使用不同数据时，将数据变化和方法变化的作用分开。比较范围不能只留下有利样本。全国数据用于城市分析时，明确其尺度和在模型中的角色。

## 数据记录

记录来源 URL 或文件、提供方、原始变量、单位、年份、空间范围、人群、访问日期、处理步骤及结果版本。原件保持字节不变；派生文件与脚本关联。缺失、零值、未覆盖与不适用分别处理。

“最新”必须指向已检查的具体版本或时间。历史 README、早期冠军和旧图注不能自动代表当前结论。跨版本引用在同一段或图注中注明对应版本；最终稿使用选定版本的一致输出。

引用关键数值时核对分母与筛选范围。居民人口加权结果使用“居民”表述；学生总体推断需对应学生数据。模型值、观测值、参数假设与合成示例保持可辨。

## 多源空间数据

- 道路、水系、边界和人口格网按坐标系对齐，核对实际范围与单位；放大窗对应真实区域。
- 卫星资料记录产品、观测日期／合成窗口、源分辨率、渲染尺寸、覆盖范围与缺测信息。
- 卫星 RGB 支持地理背景解释；光谱指数与面积统计需使用适当原始波段、质量标识和处理方法。
- 背景影像与模型输入分别注明时间。跨年空间对照不自动构成变化分析。
- 背景道路不自动成为重新计算旅行时间的路网。重新计算需另记网络、速度、出行方式和目的地定义。
- 图层署名与许可要求保留；源数据完整性可用哈希与请求清单核验。

## 可复核交付

保存主张所需的数据版本、脚本、参数和输出入口。图中数值与源结果一致；对于关键结论检查公式、单位、筛选条件及人口权重。报告已完成的验证和实质性未验证事项，避免把漂亮地图或运行成功当作科学有效性的证明。
