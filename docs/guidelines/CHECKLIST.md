# 写作与制图交付检查

[返回团队必读入口](../../GUIDELINES.md)

执行适用于本次改动的项目。此清单用于内部核验；论文正文保留论证内容，交付说明简洁报告检查结果。

## 写作与证据

- [ ] 已阅读本次任务对应规范，确认主稿和数据版本。
- [ ] 每节有明确职责，主要段落先给判断，再提供证据与解释。
- [ ] 摘要、正文、结论、图表的对象、数值、单位和排名一致。
- [ ] 重要数值、来源和公式能定位到文件或具体出处。
- [ ] 代理变量、假设情景和实测结果命名准确；比较对象同口径。
- [ ] 修订效果、稳健性或因果措辞有对应证据。
- [ ] 已删除重复辩解、过程流水账、泛泛赞美；关键反例和条件保持完整。

## 图表与地图

- [ ] 每图回答一个明确问题；正文解释图中实际发现。
- [ ] 标签、图例、刻度及来源在最终插入尺寸均至少 9 pt，无重叠或裁切。
- [ ] 配色含义、分级、单位、缺失标记与图注一致。
- [ ] 地图投影、范围、比例尺、放大窗与空间数据对齐。
- [ ] 卫星产品、日期、源分辨率与输出像素分别记录。
- [ ] 已检查实际尺寸 PDF／最终论文渲染；300 dpi 和屏幕放大不能替代可读性检查。
- [ ] 图文件、数据、脚本、出处与许可可追溯；没有占位影像或生成式地理内容充当真实数据。

## 协作与交付

- [ ] 保留团队内容、原件及无关修改；未把研究笔记自动写入主稿。
- [ ] 修改正文前已按 AGENTS.md 检查 Overleaf；本地修改与线上状态准确区分。
- [ ] 文档内部链接有效，规范入口和专项文件一致。
- [ ] 交付说明写明成果、验证与必要的未完成事项，不声称未执行的检查。
