# 写作规范

[返回团队必读入口](../../GUIDELINES.md)

本规范用于论文正文、摘要、结论、新闻稿与图注。采用 [anti-defensive-writing](https://github.com/TypeThe0ry/HiMCM-research/blob/main/research/2026-a/visuals/guidelines/anti-defensive-writing/README.md) 的结果优先原则，同时遵循[证据规范](EVIDENCE.md)。

## 主线与段落

先确定本节最值得传达、且已有证据支持的判断。全文围绕“问题 → 可测定义 → 方法 → 证据 → 决策含义”展开。各节承担不同论证职责，避免重复介绍动机和反复宣称方法优越。

段落通常采用“判断 → 数值、公式或来源 → 解释 → 下一步”的次序；仅在理解需要时交代适用条件，不机械套用句式。先说明现实含义，再引入必要术语。一个句子集中表达一个主要判断，主语明确，比较对象具体。

## 各类内容的职责

| 内容 | 必须交代 | 写作重点 |
| --- | --- | --- |
| 摘要 | 对象、问题、方法的关键机制、真实结果及意义 | 结果可定位到正文；摘要数值随最终结果更新 |
| 引言与问题定义 | 为什么重要、已有表达遗漏什么、本文解决什么 | 尽早说明高中生、人群条件与“最好”的定义 |
| 数据与指标 | 概念、测量量、口径、来源、处理方法 | 区分设施供给、可达性、教育质量等不同概念 |
| 假设 | 简化什么、理由是什么、如何影响计算 | 只列实际进入模型的假设 |
| 方法与公式 | 现实机制、数学定义、变量单位、选择理由 | 说明方法如何解决本题问题，而非介绍算法百科 |
| 结果 | 核心发现、幅度、差异来源及决策含义 | 先给发现，再解释图表；不逐格朗读表格 |
| 重大修订 | 基准诊断、修改机制、同口径比较、效果 | 用已运行的版本与结果解释修订 |
| 验证与敏感性 | 改变什么、检验什么、推荐何时变化 | 区分实现正确、外部一致、排序稳定等命题 |
| 讨论与适用条件 | 影响结论的具体条件及后果 | 集中讨论实质问题，避免在每段附加同一免责声明 |
| 结论 | 回答问题、最有分量的发现与使用意义 | 不引入新结果；重要适用条件在相关分析中先交代 |
| 新闻稿 | 谁受益、推荐及其依据、生活含义 | 使用普通读者能理解的语言，保留关键比较口径 |
| 图注 | 对象与发现、指标、单位、口径、来源 | 可独立阅读；细节放正常字号图注或方法段 |

## 反防御性写作的具体应用

以明确、可检验的陈述替换情绪判断、重复辩解和工作过程：

| 待改表达 | 改写方向 |
| --- | --- |
| “我们先尝试了很多模型，最后选择……” | 说明最终机制、选择依据及支持它的比较 |
| “遗憾的是，我们只有代理数据……” | 直接定义所测变量、适用人群及它承担的分析任务 |
| “结果非常优秀，具有高度创新性……” | 给出相对哪个基准、在哪项任务、改善多少 |
| “本图不是……也不是……”反复出现 | 用准确图名与指标定义表达范围；关键差异集中说明一次 |
| “所有变化下都稳定” | 给出实际检查的参数范围及首选或名次变化 |
| “这个局限不影响结果” | 给出检验或界限；尚无证据时保留待验证状态 |

“结果优先”不等于只报告有利结果。相关负面结果、替代解释和不确定性如实呈现，说明其具体后果；不能为了措辞积极而改变结论。缩小主张必须忠于研究对象，不事后换评价标准来制造胜出。

## 语言、公式和引用

- 中英文术语一一对应；城市／都市圈、学生／居民、通学／通勤等用词保持固定含义。首次出现缩写写全称。
- 用具体动词和事实，删除空泛过渡、堆叠形容词和无证据的最高级。避免模板化“首先、其次、最后”占据论证位置。
- 每个符号首次出现即定义，说明单位和收益／成本方向；正文解释公式的实际作用。
- 数值精度与测量相称；比例、百分点、均值、中位数、分位数明确区分。
- 引用靠近其支持的判断；使用已核验来源。获奖身份支持案例选择，不替代对原论文结论的核验。
- 样本数、版本号、排名和关键数值在摘要、正文、表格与图注保持一致。不要从旧 README 推断当前模型结果。
- 图内小字不是容纳方法细节的办法。长说明移到正常字号图注或方法；最终图中文字按配图规范核验。

## 编辑顺序

先检查结论与证据，再调整结构和段落，最后润色句子。完成后按[交付检查](CHECKLIST.md)验收。语言编辑保留团队实际推理、数据含义和必要条件。
