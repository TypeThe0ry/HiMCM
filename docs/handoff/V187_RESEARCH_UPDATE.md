# V187：十二项通勤均值的联合敏感性边界

Zurich的保守推荐在声明的联合均值变化下有可复算的稳定范围：原权重半径为7.1473304991%，等权为51.4235691502%。两者首先与Oslo并列。主分析保持V181，16城×10指标；本轮0项新数据准入、基准平均区间宽度变化0。

令每项保留均值m独立位于[(1−δ)m,(1+δ)m]，0≤δ≤1；十二项均值同时允许变化，继续用Jensen下界exp(−m/30)、上界1。Singapore保留历史学段分箱；Vienna、Warsaw、Tokyo三项未知不变，其余九指标、权重与锚点全部保持。δ是声明的相对变化范围，未由实测误差校准，也不代表未来趋势、概率或联合现实可实现性。

所有城市分数上界不变，每城自排除最大遗憾只随本城分数下界变化。均值增大使该城下界下降、遗憾增大。因此Zurich均值取上端、其他十一项取下端，同时最大化Zurich遗憾减最优竞争者遗憾的差；这个角点给出整个连续盒的最不利差值。

在边界处Zurich仍是每个允许情景的最小遗憾选择之一，但最不利角点失去唯一性。超过边界存在排除Zurich的允许情景，不表示所有情景都切换。原基准的16个可能冠军、0个必要冠军保持；本文没有把该计数泛化到整个均值参数域。
