# Paris 生师比来源：连接全市记录，保留机构与校址层级

本轮取得七份官方 JSON 原件，将此前 Henri-IV 单校口径核查扩展到2025 Paris 教师及两类高中学生记录。普通／技术高中122个 UAI，职业高中59个，交集27个、并集154个；153个匹配教师 FTE。GT／PRO学生表各自合计57,460／14,167；未匹配教师的公立 Lycée innovant de Paris（0754401B）有117名GT学生，不补零。

匹配后的机构教师 FTE 逐 UAI 计一次，合计7,920.09；若分别连接GT与PRO再相加，会重复计入1,870.52 FTE。这是可复核的提取风险诊断，不是已发生的主模型错误或个人教师人数。教师口径仍是机构分配FTE，尚未分配到高中／高中后课程。

当前 lycée 名录243行、237个 UAI，6个编码有多行校址候选，4个编码的高中后课程标记不同。追加精确编码查询找回3个EREA：先前按类型筛选未返回，不代表学校不存在。合并后保留246行／240个编码；154个学生编码全部有名录候选。其当前标记为88个一致有高中后课程、60个一致无该标记、4个混合、2个空缺。不得以首行／末行覆盖多校址记录，也不据当前标记证明2025年的教学分配。早期临时单行映射给出的90不是保留的最终统计。

教师表为339个机构，包含初中；其中2个初中教师FTE空值不改为0，154个学生编码匹配到的153个教师值均非空。当前名录有45个HORS CONTRAT编码、8个部分班级签约编码，而教师面板覆盖公立及签约私立，并排除部分医院／医社机构。没有完整市域提供者和学段分配保证，Paris主PTR效用继续为`[0,1]`，不构造城市比率或教师硬上限。学生表的初始075空响应保留；用已归档成功记录证实的75纠正查询，名录的075则保留。年度学生数、11月人员观测和当前2026名录也不混称同日普查。
