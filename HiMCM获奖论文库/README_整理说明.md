# HiMCM 历年获奖论文库

整理日期：2026-11-05（新加坡时间）。

本库已收录 68 篇按赛季、队号去重的独立论文，其中 68 篇已与 COMAP 官方获奖名单逐队核对。公开合集原始收录55篇，另合并作者公开仓库和用户提供文件。另附2003赛季获奖论文节选合刊及历年官方资料。

**这是目前已找到并可读取的资料库，不能称为历年全部获奖论文。** 大量较早赛季及非Outstanding论文没有公开全文；COMAP的 Mathmodels 论文与点评部分需要会员。没有绕过登录或付费限制。

## 使用

- 打开「论文索引.html」可按年份、奖项和题号筛选，并直接打开本地PDF。
- 「论文总目录.csv」可用Excel打开，含来源链接、官方核对依据、页数和校验值。
- 「论文/年份/奖项/题号」保存核实后的PDF；「用户原始文件」保留用户提供的11个原件及压缩包中9份PDF。
- 「官方资料」区分获奖名单、赛题、评委点评和其他赛事附带资料。
- 「官方获奖名单_可解析队伍.csv」为官方PDF可可靠提取的行，并非所有年份完整名单；不能用其总行数当作历史参赛或获奖总数。早期无法结构化提取的名单请阅读PDF及网页快照。
- 「获奖论文缺口清单.csv」记录在已解析官方名单中尚无全文的获奖队伍（排除Successful Participant等）。名单存在不表示论文公开可下载。
- 「重复文件对照.csv」记录同赛季同队号的重复/不同版本；「下载来源及失败记录.csv」保留失败原因。

2018—2023 六个赛季的 Outstanding 论文已按官方队号名单收齐，共50篇。2017仍缺4篇，2024仍缺4篇，2025仍缺5篇Outstanding；更早年份及其他奖项仍有大量缺口。详见「年份覆盖情况.csv」。

## 核对发现

1. 用户文件2026O奖1/2/3实际为2025赛季B题：16738、16739、16442，三队均为Outstanding。文件名年份不作为获奖年份。
2. 15041、15504、15926、14995为2024赛季A题Outstanding。
3. f奖1/2分别为2025赛季B题17372、16742；扫描件17372的队号通过OCR读取后核对官方名单。
4. 第三方合集将2017年已收录的5份论文题号标反：8121、8124、8201应为B；7359、7879应为A。本库已按官方名单和摘要页纠正，来源网址保留原样。
5. 用户2023 O奖压缩包9份论文与已收录队伍重复，仅计9篇，原件完整保留。
6. 2025_HiMCM_Article.pdf是比赛总结及评委文章，归入官方资料，不计入独立论文数。Consortium86是2004出版、对应2003赛季的节选合刊，不算作完整独立论文。
